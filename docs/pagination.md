# Блок «Пагинация»

1. Добавьте блок перед списком или после него.
2. В настройках нажмите «Выбрать блок на полотне» и выберите сам Smarty-блок либо контейнер записей. Кнопка отмены и Esc завершают выбор. Пагинация должна находиться вне целевого блока.
3. Для Smarty укажите переменную полного списка, например `$auction_sites`, `$all_domains`, `$registered_domains`, `$fixed_domains` или `$side`. Знак `$` необязателен. В шаблоне остаётся обычный `{foreach}`: повторный `array_slice` не нужен.
4. Укажите число элементов на странице (1–1000) и число кнопок в начале, в конце и с каждой стороны текущей страницы — отдельно для компьютера и телефона.
5. При необходимости включите дублирование. Вторая панель появится с противоположной стороны целевого блока и будет переключать тот же список.

## Ссылки

Формат выбирается **в каждом блоке**:

- «По настройке модуля» — учитывает `ZM_PB_PRETTY_URLS`;
- `/page/2/` — номер в пути;
- `?page=2` — номер в GET-параметре.

Для путей `/page/N/` нужны работающие rewrite-правила сайта. У прямых PHP-адресов сохраняется формат GET, чтобы не создавать несуществующие маршруты вида `clientarea.php/page/2/`.

Ссылки сохраняют остальные параметры, включая фильтры и `sort`, и добавляют `count`. Языковой префикс и каталог установки сохраняются. При смене формата старое значение номера страницы удаляется из ссылки.

Если списков несколько, первый использует `page`, `count`, `sort`, остальные — параметры с суффиксом от ID целевого блока. При использовании `/page/N/` для дополнительного списка параметр `pager` указывает владельца номера в пути. Копия панели не создаёт отдельного списка.

В аукционе поддержаны `sort=domain_name`, `base_price`, `highest_bid`, `expiry_date`, `domain_rank`. Префикс `-` задаёт убывание, например `sort=-domain_rank`. Неизвестная сортировка не передаётся в SQL и сохраняет исходный порядок.

## Источники и подсчёт

- Архив, фиксированные цены, общий список и зарегистрированные домены: отдельный SQL-подсчёт и выборка текущей страницы. Если несколько независимых блоков используют одну переменную, каждый получает свой срез полной коллекции.
- «Мои ставки» и список участия на главной: сначала рассчитываются статусы и выполняется существующая фильтрация, затем делается срез на сервере. Они пока загружают полную исходную выборку.
- Остальные заранее определённые Smarty-массивы и коллекции: срез в изолированном контексте целевого блока.
- Без переменной: делятся HTML-элементы выбранного контейнера. Можно указать `.класс` повторяющихся строк или тег, например `tr`. Без селектора берутся дочерние элементы с проходом через одиночные контейнеры. `thead` и `tfoot` сохраняются. Для больших динамических списков следует указывать переменную, чтобы не рендерить весь список перед разбиением.

В связанном Smarty-блоке доступен `$zm_pagination`: `total`, `page`, `pages`, `count`, `offset`. Например, глобальная позиция записи: `{$zm_pagination.offset + $v@iteration}`.

При пустом списке или одной странице панель на сайте скрывается. Превью редактора показывает условные 20 страниц; оно не сохраняется как содержимое страницы.

Из корня WHMCS, с PHP DOM и установленным `vendor`:

```sh
php modules/addons/zmchel_whmcs_multimodule/tests/pagination.php
php modules/addons/zmchel_whmcs_multimodule/tests/pagination.php query
php modules/addons/zmchel_whmcs_multimodule/tests/smarty_blocks.php
php modules/addons/domain_auction/tests/client_page_data.php
```

Тесты не подключаются к базе данных и не меняют настройки WHMCS.

## Выбор количества и SEO

В блоке можно включить выбор 10/25/50/100/250 записей. Изменение количества сохраняет условия фильтров и возвращает текущий список на первую страницу. Нестандартное количество по умолчанию также отображается в списке. Размер панели: маленький, стандартный, большой.

При включении выбора количества внутри пагинации появляется перемещаемый мини-блок. Его можно перетащить до/после кнопок либо в другой контейнер страницы. Связь с исходной пагинацией сохраняется независимо от положения; сам мини-блок в палитре отсутствует. Кнопки и селектор сохраняются как отдельные дочерние компоненты, поэтому контейнеры, стили и положение селектора не теряются при выводе. Автоматический дубль пагинации копирует её внутренний макет; вынесенный наружу селектор не дублируется. Старая настройка расположения удалена, старые блоки преобразуются при открытии редактора.

Бэкенд ограничивает количество диапазоном 10–250 и для настроек блока, и для GET-параметров `count`/`count_<id>`. Например, `count=500` превращается в 250, `count=1` — в 10; некорректные значения используют ограниченное значение по умолчанию. Ограничение применяется перед расчётом окна выборки и формированием ссылок.

Для страниц 2 и далее в title, существующий description и последнюю хлебную крошку добавляется номер страницы, а canonical указывает на текущую страницу выдачи. Переключатель «Не индексировать страницы 2 и далее» добавляет noindex только дополнительным страницам; ограничения исходной страницы не снимаются. Текст «Страница … / …» в панели по умолчанию скрыт и включается отдельной настройкой; метаданные от неё не зависят.

## Фильтры и раскладка

Отдельный блок «Поиск» удалён из палитры; при открытии старого блока он преобразуется в фильтры. Текстовый фильтр поддерживает несколько полей записи через запятую — совпадение достаточно в любом из них.

Для расположения доступны Flex/Grid, направление, перенос, выравнивание, расстояние между полями и положение кнопок. У каждого поля есть ширина для Flex, число занимаемых колонок для Grid и кнопки перемещения выше/ниже. Настройки количества колонок для компьютера, планшета и телефона дополняют эту раскладку.

Тип «Дата: от и до» использует календарь браузера. Значения передаются в формате YYYY-MM-DD; записи со временем включаются до конца последнего выбранного дня. Доступны размеры полей, рамка/подчёркивание, подсказки и применение по кнопке или при изменении значения.
