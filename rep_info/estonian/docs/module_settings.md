# Mooduli seaded

Esmalt lülitage vajalikud keeled sisse, seejärel valige URL-ide vorming ja keelemarsruutimine ning salvestage seaded. Kui marsruudid muutusid, uuendage Apache reegleid Rewrite Manageris või vastavat Nginxi seadistust. Kontrollige mooduli lehte vaikimisi keeles ja veel ühes aktiivses keeles. Enne suuremaid muudatusi või importi eksportige varukoopia.

## WHMCS

Valige keeled, mida moodul saab kasutada. Keele väljalülitamine ei kustuta selle sisu. Kui kasutate Apache'is ilusaid URL-e, uuendage pärast keelte muutmist reegleid Rewrite Manageris.
