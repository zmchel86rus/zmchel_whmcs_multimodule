# Mooduli andmebaas

## WHMCS

- **Mooduli andmebaas:** `MISSING` → Vali → Paranda Valitud elemendid.
- **Kustuta Valitud elemendid** — Seda toimingut ei saa tagasi võtta.

Leht **Mooduli andmebaas** näitab vajalikke tabeleid ja veerge ning nende olekut. Seda saab avada ainult määratud ülemadministraator. Avage leht, kui mõni muu jaotis teatab puuduva tabeli või veeru kohta. Vaadake loend üle, valige ainult parandamist vajavad kirjed ja klõpsake **Paranda valitud**. Mõnda veergu ei saa automaatselt parandada; kontrollige pärast toimingut olekut uuesti.

**Kustuta valitud** eemaldab valitud andmebaasiobjektid jäädavalt. Enne kustutamist eksportige mooduli andmed ja tehke andmebaasist varukoopia.
