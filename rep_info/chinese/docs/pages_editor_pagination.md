# 分頁區塊

1. 將區塊放在目標列表前後，在畫布選擇 Smarty 區塊或項目容器。分頁區塊應位於目標外部。
2. Smarty 列表要輸入完整集合的變數，例如 $items。保留模板原本的 {foreach}，不要再加入第二次 array_slice。
3. 設定每頁項目數，以及電腦和手機上起點、終點、目前頁面兩側的按鈕數。可選擇在同一列表另一側顯示第二組控制項。

## 連結與多個列表

每個區塊可使用模組預設、/page/2/ 或 ?page=2。路徑形式需要有效 rewrite 規則，直接 PHP 路由則使用 query 避免不存在的路徑。連結保留篩選、排序、安裝路徑與語言前綴。第一個列表使用 page、count、sort；後續列表在參數加上目標區塊 ID。使用 /page/N/ 時，pager 指明頁碼屬於哪個額外列表。複製控制項不會建立新的列表。

## 列表來源

綁定 Smarty 變數時，模組只對該頁面已存在的集合分頁，不會從其他資料來源取得缺少的記錄。沒有變數時，會拆分選取容器內的 HTML 項目。可以指定重複項目的 class 或 tr 等標籤；thead 與 tfoot 會保留。大型動態列表應優先使用變數，避免先輸出全部項目。Smarty 區塊收到 $zm_pagination，其中包含 total、page、pages、count、offset。列表為空或只需一頁時，公開頁面不顯示控制項。

## 頁面大小、SEO 與篩選

可選項目數為 10、25、50、100、250。改變大小時保留篩選，只讓該列表回到第一頁。伺服器將 count 與 count_<id> 限制於 10–250。第二頁起會在標題、現有描述和最後一個 breadcrumb 加入頁碼，canonical 指向該結果頁；noindex 選項只影響後續頁。文字篩選可以搜尋逗號分隔的多個欄位與陣列鍵。日期範圍使用 YYYY-MM-DD，最後一天包含當天所有時間。

## 日期 YYYY-MM-DD

篩選作用於同一個分頁列表。套用或清除篩選後，只有該列表回到第一頁。確認 URL 仍保留語言與排序參數。

## Flex / Grid 版面

按裝置尺寸設定欄位寬度與欄數。每頁項目數選擇器可以移往其他容器，仍連接原分頁區塊。複製的控制項共享有效篩選與項目數。
