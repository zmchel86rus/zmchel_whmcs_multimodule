# 模組資料庫

## WHMCS

Module database 頁面顯示模組需要的資料表與欄位，以及它們目前是否存在。只有指定的 Super Administrator 能夠使用。當其他模組頁面提示缺少表或欄位時，再到這裡檢查；這不是任意編輯整個 WHMCS 資料庫的工具。

先閱讀狀態列表，只勾選你打算修復的 MISSING 項目，再按 **Fix Selected items**。完成後重新載入頁面，確認狀態確實更新。有些缺少的欄位沒有自動修復方案；管理員可以指出問題，但無法自行新增這種欄位。修復後回到原本報錯的功能再次測試。

**Delete Selected items** 會刪除所選模組資料庫物件，而且無法復原。使用前先匯出模組資料並備份資料庫。不要為了清除警告而勾選無關項目，也不要把刪除當作修復資料表的方法。
