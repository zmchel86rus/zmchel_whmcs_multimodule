# 媒體管理員

媒體庫儲存頁面區塊及其他模組內容使用的檔案。你可以上傳新檔案、搜尋已登錄項目並最佳化圖片，不必直接修改 WHMCS 佈景主題的檔案。

## 上傳與選取檔案

按 **Upload** 並選擇圖片、音訊、影片或 PDF。填寫可用的系統名稱、標題、說明及 alt 欄位。圖片 alt 應描述有意義的畫面內容，不要只重複檔名。使用搜尋與檔案類型篩選尋找項目；**Load more** 會讀取下一批結果。在圖片區塊按 **Choose image** 選取媒體庫檔案，然後儲存頁面。上傳成功後仍要檢查公開頁面的實際檔案 URL。

## 圖片輸出

管理員會為圖片產生多種尺寸。執行 **Optimize image** 後請目視檢查，尤其是含有文字或細線的圖片。如果某張圖片不應使用響應式版本，可在該圖片區塊關閉 srcset。最後檢查公開頁面的圖片地址、尺寸與 alt 文字，確認它們與編輯時的設定一致。
