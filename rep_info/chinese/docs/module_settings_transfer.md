# 匯入與匯出

## ZIP 封存檔

開啟 Module settings → Import / export，選擇全部或指定區段。匯出會建立含 manifest.json 和獨立頁面 CSS/JS 檔案的 ZIP，也支援匯入 JSON。搬遷網站或大量修改設定前請保留原始封存檔。

- **頁面與文章：** 包含設定、翻譯、GrapesJS 內容、SEO 和網站地圖設定。生成的 CSS/JS 匯入後依新的頁面 ID 重建。
- **選單：** 包含階層、翻譯標籤、位置與設定。頁面依 slug 加 auth_type 比對，選單依名稱比對。
- **設定：** 包含可編輯常數、頁面覆寫、頁首／頁尾和 robots.txt。URL 模式與最後網站地圖產生時間留在目標站。
- **重新導向與 rewrite：** 包含手動規則、頁面關聯與自訂規則。匯入後要從管理員套用 rewrite 規則。
- **媒體：** 包含已登錄檔案、變形與描述，不含無關的 WHMCS 附件。

匯入會更新符合的記錄、加入新記錄，其他記錄保持不變。封存檔沒有的選取區段會略過。若搬移選單或自動重新導向到新站，請同時匯入對應頁面。來源站的 SystemURL 會替換成目標地址，外部 URL 保持原樣。要搬移頁面圖片，媒體也應一起選擇。

ZIP 上限 128 MiB，JSON 上限 32 MiB；另外要考慮 PHP 的 upload_max_filesize 與 post_max_size，並啟用 ZIP 擴充功能。若生成的 CSS/JS 缺失或無法讀取，匯出會略過並顯示警告。版本歷史、收集的 Smarty 變數、WHMCS 帳號與機密資料、佈景主題檔案均不匯出。匯入使用現有資料表，不修改結構。

更新記錄前介面會要求確認。資料庫操作使用交易，若檔案替換失敗會還原舊檔；檔案鎖避免同時匯入。成功後重新產生網站地圖並測試公開路由。
