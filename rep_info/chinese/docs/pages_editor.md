# 頁面編輯器

先在[頁面管理員](pages_manager.md)建立頁面，再開啟編輯器。主要設定、內容、中繼資料與網站地圖分別放在不同分頁。修改翻譯內容前請選擇已啟用語言。每個分頁都有自己的儲存操作，**Save all** 則一起儲存多個部分。完成後應開啟公開頁面核對結果。

## 主要設定

確認內部名稱、slug、頁面種類、發佈狀態、存取方式和啟用語言。即使頁面已發佈，預計提供的語言仍須有內容。若 WHMCS 預設語言尚未受到模組支援，先到模組設定啟用再儲存頁面。排查缺少公開地址時，也要檢查該語言翻譯是否啟用。

## 內容設定

選擇語言，將 GrapesJS 區塊拖到畫布，再選取區塊調整設定。一般文字可直接編輯，富文字使用 TinyMCE；Sections、Columns、Flex 和 Grid 可組成版面。語言工具可複製內容或結構到另一語言，但複製後仍須翻譯目標內容。另見[分頁與篩選](pages_editor_pagination.md)、[Smarty](pages_editor_smarty.md)和[結構化資料](module_structured_data.md)的專門指南。

## 中繼資料與網站地圖

每種語言分別設定標題與描述。視需要檢查 canonical、robots、社群中繼資料、breadcrumbs 和 Schema 種類。網站地圖分頁設定已發佈非系統頁面的更新頻率與優先順序。[網站地圖管理員](sitemap_manager.md)負責產生 XML，儲存後應檢查實際 URL。

## 聯絡表單

加入 **Contact Form** 區塊，選擇 WHMCS ticket 與支援部門，或 email 與收件者。設定表單標題、主旨、按鈕、每個欄位的名稱、類型、必填與驗證。訪客工單需要將姓名與電子郵件欄位指定為寄件者角色。下拉選項每行一個，不同同意事項應分開設欄位。使用 WHMCS 已設定的 CAPTCHA。請以訪客身分真的提交測試，確認工單或郵件送達；編輯器顯示綠色不代表已送達。若 PHP mail() 失敗，請設定 WHMCS SMTP。
