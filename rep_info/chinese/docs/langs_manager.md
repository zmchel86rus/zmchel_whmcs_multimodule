# 語言管理員

語言管理員可在管理介面編輯 WHMCS 客戶端、管理端、本模組和其他已偵測模組的翻譯。需要模組的 Super Administrator 權限，PHP 也必須能寫入相應語言資料夾。基本操作順序是 Sections → Languages → Translations；每個 **Save** 按鈕只儲存一筆翻譯。

## 開始使用

先在 Module settings → Supported languages 啟用要用的語言。這份清單決定管理員可新增哪些語言，以及模組頁面可使用哪些語言。到 Sections 選擇 WHMCS 客戶端、管理端、本模組或其他模組；表格列出既有、停用與可新增語言。新語言最初顯示參考語言的字串，並不代表翻譯已完成。沒有自身翻譯的目錄會標記為 **Untranslated**。

## 編輯翻譯

**Original** 顯示所選語言原始檔真正提供的文字，不包含 override 變更。如果沒有該語言的原始翻譯，欄位改為 **Reference**，顯示基準語言內容。可以依鍵名或文字搜尋，切換原始與自訂鍵篩選，長列表使用分頁。每列分開儲存。自訂鍵可選父層後新增，也能改名或刪除；原始鍵不能用這個方式刪除。第三方模組格式無法安全寫入時只提供唯讀檢視。

## JSON 匯出與匯入

**Export JSON** 下載選定語言的鍵與目前翻譯。大量編輯前請保留副本。**Import JSON** 只更新既有鍵，不會建立新鍵；請保持區段、語言識別及鍵路徑不變。未知或重複的鍵會略過並列於結果，有效項目仍繼續匯入。上傳限制為 8 MiB。

## 語言檔與檔名

Languages 分頁可停用或重新啟用語言檔；停用的翻譯仍可編輯。英文基準檔與目前 WHMCS 預設語言不能停用。管理員建立的 WHMCS 檔案有備份，更新 WHMCS 後可還原。若發現舊檔名，Sections 會顯示共用修正工具，修正會涵蓋已偵測區段並維持舊名稱相容。要換預設語言，先在模組設定啟用新語言，再變更 WHMCS，最後才停用舊語言。
