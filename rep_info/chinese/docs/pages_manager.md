# 頁面管理員

頁面管理員列出模組建立的頁面。你可以在這裡新增頁面、搜尋既有頁面、變更發佈狀態、開啟公開地址，或讓建構器內容取代 WHMCS 原有頁面的內容。正文與中繼資料需在[頁面編輯器](pages_editor.md)另外編輯。

## 建立頁面

開啟 **Add page**，輸入內部名稱與 about-us 這樣的 slug，不要包含網域或語言前綴。選擇頁面、文章或系統頁面，並指定所有人、已登入使用者或訪客才能存取。選擇需要的語言；WHMCS 的預設語言必須先在模組設定中啟用。儲存後再到編輯器加入各語言內容與中繼資料。草稿不會公開，確認完成後才發佈。

## 搜尋、檢視與刪除

列表可依名稱、存取模式、種類、狀態與語言篩選。**Visit** 會開啟實際公開 URL，方便核對路由和翻譯。**Delete** 會先將頁面移到垃圾桶，永久刪除須在垃圾桶執行。若公開地址無法使用，請先確認頁面已發佈，而且所需語言版本已啟用。

## 覆寫 WHMCS 頁面

在頁面覆寫設定中，選擇既有 WHMCS 頁面及一個已發佈的建構器頁面。覆寫模式可取代原文、在前後加入內容、只修改中繼資料，或組合這些效果。儲存後以訪客及已登入客戶身分檢查原本的 WHMCS URL。建構器自己的 slug 在必要時可重新導向原地址。
