# 免費的 WHMCS 多功能模組

**zmchel WHMCS Multimodule 是免費的。** 它讓你從 WHMCS 管理介面使用視覺化頁面與區塊編輯、多語內容、選單、媒體庫、SEO 中繼資料、XML 網站地圖、重新導向、rewrite 規則及資料匯入匯出。日常操作請看[使用指南](instruction.md)。

## 首次使用前

**請先到模組設定 → 支援的語言，啟用需要的語言。**

每次啟用模組時，module_init.php 中的 ZM_PB_ADMIN_SALT、ZM_PB_SECURE_SALT、ZM_PB_NONCE_SALT 都會重新產生。請確認三個值已填入。

本模組在 **WHMCS 8.13.0–9.1.0** 上開發和測試。**完整支援 Apache（100%）**。Nginx 也可能運作，但首頁語言路由可能需要額外設定與驗證。

**已檢查 PHP 版本：** 7.4、8.0、8.1、8.2、8.3、8.4、8.5。所有 PHP 檔案均通過語法檢查，並執行了獨立測試。
