# WHMCS 向け無料マルチモジュール

**zmchel WHMCS Multimodule は無料です。** WHMCS 管理画面でページとブロックのビジュアル編集、多言語コンテンツ、メニュー、メディア、SEO メタデータ、XML サイトマップ、リダイレクト、rewrite ルール、インポートとエクスポートを扱えます。操作方法は[使い方](instruction.md)を参照してください。

## 初回利用前

**モジュール設定 → 対応言語で、必要な言語を有効にしてください。**

モジュールを有効化するたびに、module_init.php の ZM_PB_ADMIN_SALT、ZM_PB_SECURE_SALT、ZM_PB_NONCE_SALT が新しく生成されます。三つとも値があるか確認してください。

**WHMCS 8.13.0–9.1.0** で開発・テストしました。**Apache に完全対応しています（100%）**。Nginx でも利用できますが、トップページの言語ルートには追加設定と検証が必要になる場合があります。

**検証した PHP バージョン:** 7.4、8.0、8.1、8.2、8.3、8.4、8.5。すべての PHP ファイルで構文検査を行い、独立したテストも実行しました。
