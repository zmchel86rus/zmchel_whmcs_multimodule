# 言語管理

言語管理では、WHMCS のクライアント・管理画面、このモジュール、検出された他のモジュールの翻訳を編集できます。モジュールの Super Administrator 権限と、対象の言語フォルダーへの PHP の書き込み権限が必要です。操作は Sections → Languages → Translations の順で進み、各 **Save** ボタンは一件の翻訳だけを保存します。

## はじめに

まず Module settings → Supported languages で必要な言語を有効にします。この一覧は、追加できる言語とモジュールのページで使える言語を決めます。Sections から WHMCS のクライアント・管理言語、このモジュール、または他のモジュールを選びます。既存、無効、追加可能な言語数が表示されます。新規言語は最初に参照言語の文字列を表示するだけなので、翻訳が完成したとはみなせません。固有の訳がないカタログには **Untranslated** が付きます。

## 翻訳の編集

**Original** は選んだ言語の元ファイルに実際にある文字列を示し、override の変更を含みません。元の翻訳ファイルがなければ **Reference** になり、基準言語を表示します。キーや文字列で検索し、元のキーや追加したキーを絞り込めます。長い一覧はページ分割されます。値は行ごとに保存します。独自キーは親を選んで追加し、後から名前変更や削除が可能ですが、元のキーは削除できません。安全に保存できない他社モジュール形式は読み取り専用です。

## JSON の入出力

**Export JSON** は選択した言語のキーと現在の訳をダウンロードします。一括編集前にコピーを残してください。**Import JSON** は既存キーだけを更新し、新規キーを作りません。セクション、言語、キーパスを変えないでください。不明または重複するキーは飛ばして結果に表示し、有効なキーは処理を続けます。アップロード上限は 8 MiB です。

## 言語ファイルとファイル名

Languages タブでは言語ファイルを無効化・再有効化でき、無効な言語も編集できます。英語の基本ファイルと現在の WHMCS 既定言語は無効化できません。管理ツールが作った WHMCS のファイルはバックアップされ、更新後に復元できます。古いファイル名があれば Sections の共通修正機能で新しい名前を確認します。既定言語の変更では、先に新言語をモジュール設定で有効化し、次に WHMCS を変更し、最後に旧言語を無効化します。
