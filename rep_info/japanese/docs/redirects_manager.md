# リダイレクトとサイトマップの言語

## HTTP

Redirect Manager は元 URL → 転送先の厳密なルールを HTTP 301、302、303、307、308 で作成します。編集、無効化、削除ができ、一覧には一ページ 50 件表示します。元 URL は / で始まるパスか同じサイトの絶対 URL、転送先はパスまたは HTTP(S) URL を指定できます。

照合時には末尾のスラッシュを同等に扱いますが、転送先の表記はそのまま残します。特定の query を持つルールはパスだけのルールより優先され、パスルールは query 付きの要求にも一致します。転送先のパラメーターは元のパラメーターを置き換えます。ルールは WHMCS に届く GET と HEAD の要求に対し、ページビルダーより先に動きます。.htaccess、言語セッション、ユーザープロフィールは変更しません。ZM_PB_ENABLE_REDIRECTS_MANAGER が保存ルールを有効化します。

公開済みページの slug を変更し、公開状態が続く場合、自動の 301 が作られます。下書きを初めて公開するときは作られません。ZM_PB_AUTO_REDIRECT_DAYS の既定値は 14 日で、0 にすると待機がなくなります。続く改名では古い転送先も更新され、元の slug に戻ったときの自己リダイレクトは削除されます。手動ルールが優先され、WHMCS ページ上書きの別名は元の公開 URL に転送できます。

ルールは zm_pb_redirects に保存します。要求中には不足テーブルを作成しないため、Module database で修復してください。既存の URL カラムの上限は 128 bytes です。sitemap_pages.xml と sitemap_posts.xml は代替言語と x-default を記録しますが、リダイレクト元は除外します。URL の変更後は XML を再生成してください。
