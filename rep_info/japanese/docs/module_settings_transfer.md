# インポートとエクスポート

## ZIP アーカイブ

Module settings → Import / export で全データまたは必要な区分を選びます。エクスポートでは manifest.json とページの CSS/JS を別ファイルで含む ZIP を作成します。JSON のインポートもサポートします。移行や大きな変更の前には元のアーカイブを保管してください。

- **ページと記事:** 設定、翻訳、GrapesJS の内容、SEO とサイトマップの設定を含みます。生成済み CSS/JS は取り込み先の新しいページ ID に合わせて再作成します。
- **メニュー:** 階層、翻訳ラベル、配置場所、設定を含みます。ページは slug と auth_type、メニューは名前で照合します。
- **設定:** 編集可能な定数、ページ上書き、ヘッダー・フッター、robots.txt を含みます。URL モードと最終サイトマップ時刻は移行先に残します。
- **リダイレクトと rewrite:** 手動ルール、ページへの関連、独自ルールを含みます。rewrite ルールは取り込み後に管理画面で適用します。
- **メディア:** 登録済みファイル、派生版、説明を含み、無関係な WHMCS 添付ファイルは除外します。

インポートは一致するレコードを更新し、新しいレコードを追加します。関係のないデータはそのままです。選択した区分がファイルにない場合は飛ばします。新しいサイトにメニューや自動リダイレクトを移す場合、関連ページも一緒に選んでください。移行元の SystemURL は移行先の住所へ置き換え、外部 URL は変えません。ページ画像にはメディアも必要です。

ZIP の上限は 128 MiB、JSON は 32 MiB です。PHP の upload_max_filesize と post_max_size も考慮し、ZIP 拡張を有効にします。生成済み CSS/JS がないか読めない場合、エクスポートは飛ばして警告します。改訂履歴、収集した Smarty 変数、WHMCS のアカウントと機密情報、テーマファイルは含めません。インポートは既存テーブルを使用し、スキーマを変更しません。

更新前には確認が表示されます。データベース変更はトランザクションで行い、失敗時には置換したファイルを戻します。ファイルロックが同時インポートを防ぎます。成功後はサイトマップを再生成し、公開 URL を確認してください。
