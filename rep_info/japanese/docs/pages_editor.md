# ページ編集

[ページ管理](pages_manager.md)でページを作成した後に編集画面を開きます。主な設定、内容、メタデータ、サイトマップは別のタブです。翻訳内容を編集する前に有効な言語を選択します。タブごとに保存操作があり、**Save all** は各部分をまとめて保存します。公開ページを開いて表示結果も確認してください。

## 主な設定

内部名、slug、種類、公開状態、アクセス区分、有効な言語を確認します。公開済みでも、表示したい言語に本文が必要です。WHMCS の既定言語がモジュールで使えない場合は、ページ保存前に Module settings で有効にしてください。URL が見つからない場合は対象翻訳が有効かも確認します。

## 内容の編集

言語を選び、GrapesJS のブロックをキャンバスにドラッグします。ブロックを選択して設定を変更し、リッチテキストには TinyMCE を使います。Sections、Columns、Flex、Grid で配置を組み立てます。言語ツールで内容や構造を別の言語へコピーできますが、コピー先の文言は翻訳してください。詳しくは[ページ分割とフィルター](pages_editor_pagination.md)、[Smarty](pages_editor_smarty.md)、[構造化データ](module_structured_data.md)を参照してください。

## メタデータとサイトマップ

言語ごとにタイトルと説明を書きます。必要に応じて canonical、robots、SNS メタデータ、breadcrumbs、Schema タイプを確認してください。サイトマップ設定では公開された通常ページの更新頻度と優先度を指定します。[サイトマップ管理](sitemap_manager.md)が XML を生成するので、保存後は実際の URL を確認します。

## お問い合わせフォーム

**Contact Form** ブロックで WHMCS ticket とサポート部門、または email と宛先を選びます。見出し、説明、件名、ボタン、各フィールドの名前・種類・必須・検証を設定してください。ゲストのチケットには送信者名とメールアドレスを担当するフィールドが必要です。選択肢は一行に一つずつ記入し、同意事項ごとに別のフィールドを使います。WHMCS の CAPTCHA を利用し、ゲストとして実際に送信して到着を確認してください。編集画面の緑表示だけでは配信は確認できません。PHP mail() が失敗する場合は WHMCS SMTP を設定します。
