# モジュール設定

最初に必要な言語を有効にし、URL 形式と言語ルーティングを選んで保存します。ルートを変更したら Apache の Rewrite Manager のルール、または Nginx 側の設定も更新してください。既定言語と別の有効な言語の公開ページを開き、結果を確認します。重要な変更やインポートの前にはデータを書き出してバックアップします。

## 利用できるタブ

- **Import / export:** 選んだデータを ZIP に保存し、ZIP または JSON をインポートします。実行前に[転送ガイド](module_settings_transfer.md)を読んでください。
- **Editable constants:** URL、ルート、出力、メディア、保守、Smarty などの設定です。説明を読んでから変更し、公開ページで結果を確認します。
- **Supported languages:** ページを作成する前に使う言語を有効にします。WHMCS の既定言語を止める場合は、先に WHMCS 側の既定値を変更します。
- **Redirects と Sitemap:** 保存したリダイレクト、自動リダイレクト、XML の作成時刻を設定します。個々の項目は専用の管理画面で扱います。
- **Header、Footer、Robots:** ヘッダー、フッター、robots.txt の内容を編集し、実際のページとファイルで確認します。

Web サーバーのルートに依存する設定は、対応するサーバールールが必要です。Apache は .htaccess、Nginx は別のサーバー設定を使います。
