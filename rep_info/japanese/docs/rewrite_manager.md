# Rewrite Manager

## WHMCS

Rewrite Manager は、サイトのルートにある .htaccess 内の Apache 用ルールを確認・追加します。独自の rewrite ルールもここで管理します。ある URL から別の URL への通常のリダイレクトは[リダイレクト管理](redirects_manager.md)で設定します。両者は用途と適用箇所が異なります。

## ルールの確認と適用

管理画面で有効な言語のルート状態を確認します。**Add or update rules** はモジュールのルールブロックを .htaccess に書き込みます。再度状態を確認し、既定言語と別の有効な言語で公開ページを開いてください。**Remove all rules** は存在するモジュールのルールブロック全体を削除します。

独自ルールを作る場合は URL パターン、転送先、flags を入力して保存し、ルールを適用し直します。広すぎるパターンは関係のないページにも作用するため、適用前に確認してください。Apache は .htaccess を読みますが nginx は読みません。Nginx では同等の設定をサーバー側に追加し、既存の URL も再確認します。
