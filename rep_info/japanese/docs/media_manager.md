# メディア管理

メディアライブラリにはページブロックや他のモジュール機能で使用するファイルを登録します。新規アップロード、既存ファイルの検索、画像の最適化を管理画面で行えます。WHMCS のテーマファイルを直接編集する必要はありません。

## アップロードと選択

**Upload** を押して画像、音声、動画、PDF を選びます。利用できる内部名、タイトル、説明、alt の欄を入力してください。画像の alt にはファイル名ではなく、意味のある内容を書きます。検索と種類フィルターで項目を探し、**Load more** で次の結果を取得します。画像ブロックでは **Choose image** から登録済みファイルを選び、ページを保存します。アップロードの表示だけで判断せず、公開ページで実際の URL も確認してください。

## 画像の出力

管理機能は用途に応じて複数サイズの画像を生成します。**Optimize image** の実行後は、特に文字や細線を含む画像を目視確認してください。特定の画像にレスポンシブな派生画像が不要なら、その画像ブロックの srcset を無効にできます。公開ページで最終 URL、サイズ、alt が意図どおりになっていることを確認します。
