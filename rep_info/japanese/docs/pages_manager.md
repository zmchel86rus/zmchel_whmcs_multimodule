# ページ管理

ページ管理では、モジュールで作成したページの一覧を確認できます。新規作成、既存ページの検索、公開状態の変更、公開 URL の確認、WHMCS の既存ページへのビルダー内容の割り当てを行います。本文とメタデータは[ページ編集](pages_editor.md)で別々に編集します。

## ページを作成する

**Add page** を開き、内部名と about-us のような slug を入力します。ドメインや言語接頭辞は含めません。ページ・記事・システムページの種類、全員・ログインユーザーのみ・ゲストのみのアクセス区分を選びます。必要な言語を指定し、WHMCS の既定言語がモジュール設定で有効になっていることを確認してください。保存後に編集画面で言語別の本文とメタデータを追加します。下書きは公開されないため、完成してから公開状態に変更します。

## 検索、確認、削除

一覧では名前、アクセス、種類、状態、言語で絞り込めます。**Visit** は実際の公開 URL を開きます。**Delete** はまずゴミ箱へ移動し、完全削除はゴミ箱で実行します。公開 URL が見つからない場合、ルーティングを疑う前に公開状態と対象言語の有効な翻訳を確認してください。

## WHMCS ページの上書き

既存の WHMCS ページと、その内容を提供する公開済みビルダーページを選びます。上書き方式に応じて元の内容を置換、前後に挿入、メタデータのみ変更、または組み合わせることができます。保存後は元の WHMCS URL をゲストとログイン済み顧客の両方で確認します。ビルダー側の slug から元の URL へのリダイレクトが発生する場合があります。
