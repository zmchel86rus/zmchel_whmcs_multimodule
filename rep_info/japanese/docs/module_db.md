# モジュールのデータベース

## WHMCS

Module database 画面には、モジュールが必要とするテーブルとカラムの一覧と状態が表示されます。指定された Super Administrator だけが利用できます。他の機能が「必要なテーブルやカラムがない」と報告したときに確認する画面であり、WHMCS 全体を自由に編集するためのツールではありません。

まず状態を確認し、修復したい MISSING の項目だけを選択して **Fix Selected items** を押します。実行後に再読み込みし、実際に状態が直ったか確認してください。一部のカラムには自動修復手順がないため、その場合は不足を表示できても管理画面だけでは追加できません。修復後は元の機能に戻って動作を試します。

**Delete Selected items** は選択したモジュールのデータベース要素を削除し、元に戻せません。実行前にモジュールデータをエクスポートし、データベースもバックアップしてください。警告を消すためだけに無関係な項目を選ばないでください。
