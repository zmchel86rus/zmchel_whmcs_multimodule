# ページ分割ブロック

1. 対象リストの前後にブロックを置き、キャンバス上で Smarty ブロックまたは項目コンテナーを選びます。ページ分割ブロックは対象の外側に配置します。
2. Smarty の場合、完全な集合を持つ変数、例えば $items を指定します。テンプレートの通常の {foreach} は残し、二重の array_slice は加えません。
3. 一ページの項目数と開始・終了・現在ページ周辺のボタン数を、PC とスマートフォン別に設定します。同じリストの反対側にも操作部を表示できます。

## リンクと複数のリスト

各ブロックはモジュール既定の形式、/page/2/、?page=2 から選びます。パス形式には rewrite ルールが必要で、直接の PHP ルートには query 形式を使います。リンクはフィルター、並び順、設置パス、言語接頭辞を保持します。最初のリストは page、count、sort を使用し、後のリストには対象ブロック ID を付けます。/page/N/ では pager がどの追加リストの番号かを示します。操作部を複製しても新しいリストにはなりません。

## リストの元データ

Smarty 変数を指定すると、そのページで既に利用できる集合を分割します。別のデータ元から不足項目を取得するわけではありません。変数を指定しない場合は選んだコンテナー内の HTML 項目を分割します。繰り返し要素の class や tr などのタグを指定でき、thead と tfoot は保持されます。大きな動的リストでは全件 HTML を先に描画しないよう変数を使います。Smarty ブロックには total、page、pages、count、offset を含む $zm_pagination が渡されます。一ページに収まるリストでは操作部は表示されません。

## ページ数、SEO、フィルター

項目数には 10、25、50、100、250 を選べます。変更後もフィルターは残り、そのリストだけが一ページ目に戻ります。サーバーは count と count_<id> を 10–250 に制限します。二ページ目以降はタイトル、既存の説明、最後の breadcrumb に番号が入り、canonical はその結果ページを指します。noindex は一ページ目以外に適用できます。文字フィルターはカンマ区切りの複数フィールドや配列キーを調べます。日付範囲は YYYY-MM-DD で送り、終了日を一日分含めます。

## 日付 YYYY-MM-DD

フィルターはページ分割と同じリストに作用します。適用または解除すると、そのリストは最初のページに戻ります。URL の言語と並び順が保たれているか確認してください。

## Flex / Grid の配置

画面幅ごとにフィールド幅と列数を設定します。項目数の選択欄は別のコンテナーへ移動しても元のブロックとの接続を維持します。複製された操作部はフィルターと項目数を共有します。
