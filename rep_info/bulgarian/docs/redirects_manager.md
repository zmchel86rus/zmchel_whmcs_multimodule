# Пренасочвания

Въведете стария и новия URL адрес. Използвайте 301 за постоянни и 302 за временни промени; проверете източника и избягвайте пренасочване към същия адрес.

## HTTP

Правилата поддържат HTTP кодове `301`, `302`, `303`, `307`, `308` и се прилагат само за заявки `GET`/`HEAD`, достигнали WHMCS. Източникът се сравнява точно по път и, ако са зададени, по параметри; параметрите на дестинацията заменят старите. Мениджърът съхранява правилата в `zm_pb_redirects`, но не създава таблицата при заявка: използвайте **База данни на модула**. Съществуващите URL колони са ограничени до 128 байта.

Ръчните правила имат предимство пред автоматичните. Промяна на slug на публикувана страница може след зададеното изчакване да създаде автоматично `301` за всеки активен език; публикуването на чернова не го създава. Следващите преименувания обновяват целите на старите правила. Правило с параметри на заявката има предимство пред правило само за пътя. Изходният URL трябва да принадлежи на този сайт и да не съдържа фрагмент `#`.
