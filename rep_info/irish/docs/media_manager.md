# Bainisteoir Meán

## Comhad a uaslódáil agus a roghnú

Cliceáil **Uaslódáil comhad meán**, roghnaigh íomhá, fuaim, físeán nó PDF agus líon isteach ainm, téacs malartach, teideal agus cur síos de réir mar is gá. Scríobh téacs malartach a mhíníonn ábhar na híomhá. Tar éis an uaslódála, úsáid an cuardach agus an scagaire cineáil; taispeánann **Luchtaigh tuilleadh** torthaí eile. Sa bhloc íomhá, roghnaigh an comhad ón leabharlann agus sábháil an leathanach.

## Íomhánna a thaispeáint

Cruthaíonn an bainisteoir roinnt méideanna den íomhá. Is féidir **Optamaigh an íomhá** a úsáid tar éis uaslódála; seiceáil an caighdeán ina dhiaidh sin, go háirithe má tá téacs san íomhá. Mura n-oireann na leaganacha oiriúnaitheacha, múch `srcset` sa bhloc. Seiceáil an URL deiridh agus an téacs malartach ar an leathanach poiblí.

## Treoracha

- Uaslódáil comhad meán
- **Ainm (inmheánach)**
- **Teideal (más infheidhme)**
- **Cur síos (más infheidhme)**
- **Aitreabúid alt**
- Cuardaigh de réir ainm
- Cineál comhaid
- Lódáil tuilleadh
- Optamaigh íomhá
- Tá optamú na buníomhá agus a leaganacha críochnaithe.
- Roghnaigh comhad meán
