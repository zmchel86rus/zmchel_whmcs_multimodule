# Socruithe an mhodúil

## WHMCS

Roghnaigh na teangacha is féidir leis an modúl a úsáid. Ní scriosann díchumasú teanga a hábhar. Má úsáideann tú URLanna so-léite ar Apache, nuashonraigh na rialacha sa Bhainisteoir Athscríofa tar éis teangacha a athrú.

- [aistriú sonraí](module_settings_transfer.md)

## Treoracha

- **URLanna so-léite** — Cumasaigh URLanna so-léite, lena n-áirítear URLanna córais.
- **Ródú teangacha** — Cumasaigh nó díchumasaigh bealaí teanga. Nuair atá siad cumasaithe, bíonn leathanaigh ar fáil faoi /de/, /en/, /es/ agus faoi réimíreanna teanga tacaithe eile. Nuair atá siad díchumasaithe, taispeánann URL amháin an t-ábhar i dteanga chumraithe an úsáideora.
- **Bealach don teanga réamhshocraithe** — Tabhair réimír URL dá cuid féin don teanga réamhshocraithe agus atreoraigh leathanaigh an mhodúil gan réimír chuici.
- **Mód cothabhála (modúl)** — Cumasaigh nó díchumasaigh mód cothabhála an mhodúil. Ligeann an mód níos éadroime seo do chrúcaí WHMCS agus do chomhpháirteanna eile rith, murab ionann agus mód cothabhála an chórais.
- **Bailigh athróga Smarty** — Cumasaigh nó díchumasaigh bailiú athróg Smarty.
- **Úsáid athróga Smarty a bailíodh** — Cumasaigh nó díchumasaigh úsáid athróg Smarty a bailíodh san eagarthóir leathanach.
- **Sáruithe leathanaigh** — Cumasaigh nó díchumasaigh sáruithe leathanaigh.
- **Minicíocht nuashonraithe** — Mura roghnaítear rud ar bith, nuashonraítear léarscáil an tsuímh gach lá.
- **Léarscáil HTML an tsuímh** — Nuair atá sé cumasaithe, taispeánann /html-sitemap léarscáil an tsuímh mar ghnáthleathanach HTML; ní dhéantar aon athrú ar sitemap.xml.
- **Ceanntásc an tsuímh** — HTML saincheaptha don rannán <head>, lena n-áirítear <script> agus <style>.
- **Buntásc an tsuímh** — HTML saincheaptha roimh </body>, lena n-áirítear <script> agus <style>.
- **Cuir robots.txt in eagar**
