# Atreoruithe

Seoltaí beachta: foinse → ceann scríbe. Is conair ó fhréamh an tsuímh nó URL ar an suíomh seo í an fhoinse. Is conair nó URL iomlán HTTP(S) é an ceann scríbe. Meaitseálann riail gan pharaiméadair iarratais iarratais a bhfuil siad iontu freisin; úsáidtear an ceann scríbe díreach mar a iontráladh é. Baineann na rialacha le hiarratais GET/HEAD a shroicheann WHMCS.

Réamhshocrú: 14 lá. Ríomhtar é ón athrú deireanach ar an leathanach foilsithe nó ar a aistriúcháin ghníomhacha; mura n-athraíodh riamh é, ón dáta cruthaithe. Socraigh 0 chun gan mhoill a bheith ann. Úsáideann rialacha uathoibríocha HTTP 301.

Atreoraítear seoltaí leathanaigh sáraithe go huathoibríoch chuig na leathanaigh chórais a gcuirtear ina n-ionad iad. Má tá roinnt ceann scríbe ag sárú, úsáidtear an chéad cheann atá cumraithe. Oibríonn na hatreoruithe seo aon uair a bhíonn sáruithe cumasaithe, beag beann ar rialacha an Bhainisteora Atreoruithe.

Iontráil conair bhailí a thosaíonn le / nó URL iomlán HTTP(S). Ní mór don fhoinse a bheith ar an suíomh seo; ní thacaítear le blúirí #.

## HTTP

Tacaíonn rialacha leis na cóid HTTP `301`, `302`, `303`, `307` agus `308` agus ní bhaineann siad ach le hiarratais `GET`/`HEAD` a shroicheann WHMCS. Meaitseáiltear an fhoinse go beacht de réir an chosáin agus aon pharaiméadair fhiosrúcháin; tagann paraiméadair an chinn scríbe in áit na seanchinn. Coinnítear rialacha in `zm_pb_redirects`, ach ní chruthaítear an tábla le linn iarratais: úsáid **Bunachar sonraí an mhodúil**. Tá teorainn 128 beart ar na colúin URL atá ann.

Tá tosaíocht ag rialacha láimhe ar rialacha uathoibríocha. D'fhéadfadh athrú ar slug leathanaigh fhoilsithe `301` uathoibríoch a chruthú do gach teanga ghníomhach tar éis na moille socraithe; ní dhéanann foilsiú dréachta amhlaidh. Nuashonraíonn athainmniú eile na seanspriocanna. Bíonn tosaíocht ag riail le paraiméadair iarratais ar riail don chonair amháin. Caithfidh an URL foinse a bheith ar an suíomh seo agus gan blúire `#` a bheith ann.
