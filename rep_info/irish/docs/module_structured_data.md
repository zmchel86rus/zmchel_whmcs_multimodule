# Sonraí struchtúrtha

- **Eagarthóir Leathanach → Socruithe meiteashonraí → Cineál Schema → Sábháil.**

## An méid a mharcálann an modúl

Is féidir le biachláir agus clár ábhair `SiteNavigationElement` a chruthú, le ceisteanna agus freagraí infheicthe `FAQPage` a chruthú, agus le blúiríní aráin ilchéime `BreadcrumbList` a chruthú. Ní fhaigheann bloic leagain amach, cnaipí ná scagairí cineál ábhair go huathoibríoch. Rialaíonn cineál Schema roghnaithe an leathanaigh a JSON-LD; má dhíchumasaítear é ní aschuirtear an mharcáil sin.

## Seiceáil tar éis foilsithe

Ar an leathanach poiblí, seiceáil JSON-LD, an URL canónach, an teanga agus an t-ábhar atá le feiceáil i ndáiríre. Ní ráthaíonn marcáil bhailí toradh saibhir cuardaigh.

## Schema.org

Úsáideann `SiteNavigationElement` na naisc agus teidil roghchláir atá infheicthe i ndáiríre; is féidir leis an gclár ábhair `WebPageElement` a chur le ceannteidil atá ar an leathanach. Ní chuireann `FAQPage` san áireamh ach ceisteanna agus freagraí iomlána a fheiceann cuairteoir: fágtar bloic fholaithe agus gnáth-accordions ar lár. Ní chruthaítear `BreadcrumbList` ach le dhá mhír ar a laghad. Tagann sonraí na heagraíochta ó WHMCS; tá teangacha teagmhála i `ContactPoint.availableLanguage` i bhformáid BCP 47. Ní chumtar cineál Schema do scagairí, leathanachú, foirmeacha ná HTML saincheaptha.

- **Íomhá Open Graph** — Má tá sé folamh, úsáidtear íomhá an leathanaigh.
