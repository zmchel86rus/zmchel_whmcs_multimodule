# Менеджар медыяфайлаў

## Загрузка і выбар файла

Націсніце **Загрузіць медыяфайл**, выберыце выяву, аўдыё, відэа або PDF і запоўніце назву, alt-тэкст, загаловак і апісанне, калі яны патрэбныя. Для выяў пішыце змястоўны alt-тэкст. Пасля загрузкі карыстайцеся пошукам і фільтрам тыпу файла; **Загрузіць яшчэ** паказвае наступныя вынікі. У блоку выявы выберыце файл з бібліятэкі і захавайце старонку.

## Паказ выяў

Менеджар стварае некалькі памераў выявы. Для загружанай выявы можна запусціць **Аптымізаваць выяву**; пасля праверце якасць, асабліва калі на ёй ёсць тэкст. Калі адаптыўныя варыянты не падыходзяць, выключыце `srcset` у адпаведным блоку. Праверце канчатковы URL і alt-тэкст на публічнай старонцы.

## Інструкцыі

- Загрузіць медыяфайл
- **Назва (унутраная)**
- **Загаловак (калі патрэбны)**
- **Апісанне (калі патрэбна)**
- **Атрыбут alt**
- Пошук па назве
- Тып файла
- Загрузіць яшчэ
- Аптымізаваць выяву
- Аптымізацыя арыгінальнай выявы і яе варыянтаў завершана.
- Выбраць медыяфайл
