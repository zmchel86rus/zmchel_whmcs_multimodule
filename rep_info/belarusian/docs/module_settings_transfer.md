# Перанос даных

Адзін файл JSON для ўсіх або выбраных раздзелаў памерам да 32 МіБ (таксама дзейнічаюць абмежаванні PHP на загрузку). Старонкі, што супадаюць, абнаўляюцца паводле slug і тыпу доступу, меню — паводле назвы. Астатнія запісы застаюцца без змен. Пры імпарце меню на новы сайт дадайце таксама старонкі. Выбраныя раздзелы, якіх няма ў файле, будуць прапушчаны.

CSS/JS экспартуюцца разам са старонкамі, выявы і іншыя загружаныя файлы — разам з медыябібліятэкай. Гісторыя версій, сабраныя зменныя Smarty і сакрэтныя даныя WHMCS не экспартуюцца. Пасля імпарту паўторна стварыце карту сайта, а правілы перазапісу URL прымяніце ў менеджары перазапісу.

Старонкі і запісы (пераклады, змесціва, SEO, налады карты сайта, блокі CSS/JS)

Запісы, што супадаюць у выбраных раздзелах, будуць абноўлены з файла. Працягнуць?

## JSON

У экспарт можна ўключыць старонкі і запісы з перакладамі, кантэнтам, SEO і CSS/JS; меню з іерархіяй і пазіцыямі; налады, перанакіраванні, карыстальніцкія правілы і медыятэку разам з файламі. Гісторыя версій, сабраныя зменныя Smarty, уліковыя запісы і сакрэты WHMCS, файлы тэмы не экспартуюцца. Памер JSON абмежаваны 32 MiB; таксама дзейнічаюць ліміты PHP `upload_max_filesize` і `post_max_size`. Пры пераносе меню на іншы сайт імпартуйце і старонкі; загадзя развяжыце канфлікты назваў меню.

Файл экспарту мае фармат `zmchel_whmcs_multimodule` (версія 1). Пры імпарце URL зыходнага сайта замяняюцца адпаведнымі адрасамі паводле `SystemURL` мэтавага сайта; знешнія спасылкі захоўваюцца. Імпарт не стварае табліцы: спачатку падрыхтуйце іх у базе даных модуля. Перад пачаткам з'яўляецца пацвярджэнне; запісы змяняюцца ў транзакцыі, а замененыя файлы пры памылцы аднаўляюцца.

## Інструкцыі

- Меню і іх размяшчэнне
- Налады модуля, замены старонак, загаловак/ніжні калантытул, robots.txt
- Перанакіраванні
- Карыстальніцкія правілы перазапісу URL
- Медыябібліятэка (файлы і апісанні)
