# Налады модуля

## WHMCS

Выберыце мовы, якія можа выкарыстоўваць модуль. Выключэнне мовы не выдаляе яе змесціва. Калі вы карыстаецеся прыгожымі URL на Apache, пасля змены моў абнавіце правілы ў менеджары перазапісу URL.

- [перанос даных](module_settings_transfer.md)

## Інструкцыі

- **Прыгожыя URL** — Уключыць прыгожыя URL, у тым ліку сістэмныя адрасы.
- **Моўная маршрутызацыя** — Уключыць або выключыць моўныя маршруты. Калі ўключана, старонкі даступныя па прэфіксах /de/, /en/, /es/ і іншых моў, якія падтрымліваюцца. Калі выключана, адзін URL старонкі паказвае змесціва на мове, наладжанай карыстальнікам.
- **Маршрут для прадвызначанай мовы** — Надаць прадвызначанай мове ўласны прэфікс URL і перанакіроўваць на яго старонкі модуля без прэфікса.
- **Рэжым тэхнічнага абслугоўвання (модуль)** — Уключыць або выключыць рэжым тэхнічнага абслугоўвання модуля. Гэты больш мяккі рэжым дазваляе працаваць хукам WHMCS і іншым кампанентам, у адрозненне ад сістэмнага рэжыму тэхнічнага абслугоўвання.
- **Збіраць зменныя Smarty** — Уключыць або выключыць збор зменных Smarty.
- **Выкарыстоўваць сабраныя зменныя Smarty** — Уключыць або выключыць выкарыстанне сабраных зменных Smarty ў рэдактары старонак.
- **Замены старонак** — Уключыць або выключыць замены старонак.
- **Частата абнаўлення** — Калі нічога не выбрана, карта сайта абнаўляецца штодня.
- **HTML-карта сайта** — Калі ўключана, /html-sitemap паказвае карту сайта як звычайную HTML-старонку; sitemap.xml не змяняецца.
- **Загаловак сайта** — Карыстальніцкі HTML для раздзела <head>, у тым ліку <script> і <style>.
- **Ніжні калантытул сайта** — Карыстальніцкі HTML перад </body>, у тым ліку <script> і <style>.
- **Рэдагаваць robots.txt**
