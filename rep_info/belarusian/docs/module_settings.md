# Налады модуля

Спачатку ўключыце патрэбныя мовы, потым выберыце фармат URL і моўную маршрутызацыю ды захавайце налады. Калі маршруты змяніліся, абнавіце правілы ў Rewrite Manager для Apache або адпаведную канфігурацыю Nginx. Праверце старонку модуля на мове па змаўчанні і на яшчэ адной актыўнай мове. Перад значнымі зменамі або імпартам экспартуйце рэзервовую копію.

## WHMCS

Выберыце мовы, якія можа выкарыстоўваць модуль. Выключэнне мовы не выдаляе яе змесціва. Калі вы карыстаецеся прыгожымі URL на Apache, пасля змены моў абнавіце правілы ў менеджары перазапісу URL.
