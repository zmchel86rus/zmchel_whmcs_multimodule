# База даных модуля

## WHMCS

- **База даных модуля:** `MISSING` → Выбраць → Выправіць Выбраныя элементы.
- **Выдаліць Выбраныя элементы** — Гэтае дзеянне нельга адмяніць.

Старонка **База даных модуля** паказвае неабходныя табліцы і слупкі ды іх стан. Яна даступная толькі прызначанаму суперадміністратару. Адкрыйце яе, калі іншы раздзел паведамляе пра адсутную табліцу або слупок. Праверце спіс, выберыце толькі патрэбныя для аднаўлення элементы і націсніце **Выправіць выбранае**. Некаторыя слупкі нельга аднавіць аўтаматычна; пасля дзеяння праверце стан яшчэ раз.

**Выдаліць выбранае** незваротна выдаляе выбраныя аб'екты базы даных. Перад выдаленнем экспартуйце даныя модуля і зрабіце рэзервовую копію базы.
