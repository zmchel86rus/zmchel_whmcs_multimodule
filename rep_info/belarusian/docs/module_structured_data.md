# Структураваныя даныя

- **Рэдактар старонак → Налады метаданых → Тып Schema → Захаваць.**

## Якую разметку стварае модуль

Меню і змест могуць ствараць `SiteNavigationElement`, бачныя пытанні і адказы — `FAQPage`, а навігацыйны шлях з некалькіх элементаў — `BreadcrumbList`. Блокі афармлення, кнопкі і фільтры не атрымліваюць тып змесціва аўтаматычна. Выбраны для старонкі тып Schema кіруе яе JSON-LD; калі ён выключаны, такая разметка не выводзіцца.

## Праверка пасля публікацыі

На публічнай старонцы праверце JSON-LD, кананічны URL, мову і сапраўды бачнае змесціва. Правільная разметка не гарантуе пашыраны вынік у пошуку.

## Schema.org

`SiteNavigationElement` выкарыстоўвае сапраўды бачныя спасылкі і назвы меню; змест старонкі можа дадаваць `WebPageElement` для рэальна знойдзеных загалоўкаў. `FAQPage` бярэ толькі поўныя пытанні і адказы, бачныя наведвальніку: схаваныя блокі і звычайныя акордыёны не ўваходзяць. `BreadcrumbList` ствараецца толькі пры двух ці больш пунктах. Даныя арганізацыі бяруцца з WHMCS; мовы кантактаў запісваюцца ў `ContactPoint.availableLanguage` у фармаце BCP 47. Для фільтраў, пагінацыі, формаў і ўласнага HTML тып Schema не выдумляецца.

## Інструкцыі

- **Тып Schema** — Калі выключана, разметка Schema.org JSON для гэтай старонкі не выводзіцца.
- **Навігацыйны ланцужок** — Назва старонкі ў навігацыйным ланцужку
- **Кананічны URL**
- **Загаловак старонкі**
- **Метаапісанне**
- **Загаловак Open Graph** — Калі поле пустое, выкарыстоўваецца загаловак старонкі.
- **Апісанне Open Graph** — Калі поле пустое, выкарыстоўваецца метаапісанне.
- **Выява Open Graph** — Калі поле пустое, выкарыстоўваецца выява старонкі.
