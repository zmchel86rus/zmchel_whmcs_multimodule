# Правілы перазапісу URL

## WHMCS

Правілы для моўных URL, у тым ліку старонак з прэфіксамі /ru/, /en/ і іншымі. Мовы бяруцца з supported_langs.php; правілы ўстаўляюцца ў .htaccess перад правіламі WHMCS.

Nginx не чытае .htaccess, таму гэтыя правілы там не працуюць. Наладзьце адпаведныя правілы ў nginx.

Выяўлена канфігурацыя nginx → Apache. Гэтыя правілы працуюць толькі для запытаў, перададзеных Apache; nginx не чытае .htaccess.

Пасля дадання або выдалення правіла націсніце «Дадаць або абнавіць правілы», каб прымяніць змены ў .htaccess.

## .htaccess

Адкрыйце менеджер і параўнайце правілы з асноўным файлам `.htaccess`. Для ўласнага правіла захавайце шаблон URL, мэту і сцягі, пасля націсніце **Дадаць або абнавіць правілы**: блок будзе запісаны перад правіламі WHMCS. Яшчэ раз праверце стан і адкрыйце апублікаваную старонку на асноўнай і іншай мове. Занадта шырокі шаблон можа закрануць іншыя старонкі. У звязцы Nginx → Apache правілы дзейнічаюць толькі на запыты, перададзеныя Apache.

## Інструкцыі

- Праверыць правілы
- Дадаць або абнавіць правілы
- Выдаліць усе правілы з .htaccess
- Шаблон URL
- Мэтавы адрас
- Сцягі
