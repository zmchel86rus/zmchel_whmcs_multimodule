# Інструкцыя да zmchel WHMCS Multimodule

**Перад выкарыстаннем модуля стварыце ўнікальныя salt-значэнні і запішыце іх у `module_init.php`: `ZM_PB_ADMIN_SALT`, `ZM_PB_SECURE_SALT` і `ZM_PB_NONCE_SALT`.** Модуль распрацаваны і правераны на **WHMCS 8.13.1–8.13.7**. Сумяшчальнасць з **PHP 7.4–8.5** праверана. Apache падтрымліваецца цалкам; для Nginx можа спатрэбіцца дадатковая наладка моўных маршрутаў на галоўнай старонцы. **Модуль бясплатны.**

## Стварэнне старонак

У панэлі адміністратара WHMCS адкрыйце **Addons → zmchel WHMCS Multimodule**. Перад зменай URL, перанакіраванняў або серверных правілаў экспартуйце налады модуля. У спісе старонак стварыце старонку, увядзіце ўнутраную назву і *slug* кшталту `pra-nas`, без дамена і `.php`. Выберыце доступ для ўсіх, толькі для аўтарызаваных карыстальнікаў або змешаны; пасля выберыце чарнавік ці апублікаваны стан, тып старонкі і мовы. Мова WHMCS па змаўчанні павінна быць у `supported_langs.php`.

Пасля захавання запоўніце змесціва, метаданыя і параметры карты сайта для кожнай мовы. Кожны раздзел мае асобную кнопку захавання. Праверце паведамленне пра вынік і публічную старонку. Першае выдаленне пераносіць старонку ў кошык; канчатковае выдаленне адбываецца адтуль.

## Рэдактар і мовы

У раздзеле змесціва выберыце мову і перацягвайце блокі GrapesJS на палатно. Рэдагуйце тэксты, выявы і налады блокаў. Ёсць секцыі, калонкі, табліцы, FAQ, форма сувязі, спісы, разбіўка на старонкі і зоны для гасцей ці карыстальнікаў. Можна скапіяваць структуру на іншую мову, перакласці тэкст і захаваць. Блокі спасылак і кнопак могуць дадаваць мову да ўнутранага URL; адключыце гэта для знешніх спасылак, файлаў, `mailto:` і маршрутаў WHMCS без перакладу.

Калі прыгожыя URL і моўныя маршруты ўключаны, асноўная мова мае кароткі шлях, напрыклад `/be/`; без асобнага маршруту для мовы па змаўчанні прэфікса няма. Рэгіянальныя варыянты выкарыстоўваюць locale BCP 47. Праверце спасылкі на некалькіх мовах.

## SEO, медыя і абслугоўванне

Для кожнай мовы запоўніце загаловак, апісанне, robots, кананічны URL і дадзеныя для сацсетак. Апублікаваная несістэмная старонка можа трапіць у XML-карту сайта. У Media Manager загрузіце выявы, дадайце альтэрнатыўны тэкст і праверце якасць пасля аптымізацыі. У Menu Manager размясціце старонкі і ўласныя спасылкі, задайце подпісы на мовах і месца паказу.

Redirect Manager стварае пастаянныя `301` і часовыя `302` перанакіраванні. Rewrite Manager запісвае `.htaccess` для Apache; для Nginx патрэбныя адпаведныя серверныя правілы. Перад вялікім імпартам экспартуйце JSON.
