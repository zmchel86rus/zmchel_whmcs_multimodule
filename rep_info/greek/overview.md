# Δωρεάν πολυμονάδα για WHMCS

**Το zmchel WHMCS Multimodule είναι δωρεάν.** Από τη διαχείριση WHMCS χειρίζεστε σελίδες και μπλοκ, πολλές γλώσσες, μενού, πολυμέσα, SEO μεταδεδομένα, XML sitemap, ανακατευθύνσεις, rewrite κανόνες και εισαγωγή/εξαγωγή. Για καθημερινή χρήση διαβάστε τις [οδηγίες](instruction.md).

## Πριν από την πρώτη χρήση

**Ανοίξτε Ρυθμίσεις μονάδας → Υποστηριζόμενες γλώσσες και ενεργοποιήστε τις γλώσσες που χρειάζεστε.**

Σε κάθε ενεργοποίηση δημιουργούνται νέες τιμές για ZM_PB_ADMIN_SALT, ZM_PB_SECURE_SALT και ZM_PB_NONCE_SALT στο module_init.php. Ελέγξτε ότι συμπληρώθηκαν και οι τρεις.

Η μονάδα αναπτύχθηκε και δοκιμάστηκε σε **WHMCS 8.13.0–9.1.0**. Ο **Apache υποστηρίζεται πλήρως (100%)**. Το Nginx μπορεί επίσης να λειτουργήσει, αλλά η δρομολόγηση γλώσσας στην αρχική σελίδα μπορεί να απαιτήσει πρόσθετη ρύθμιση και έλεγχο.

**Ελεγμένες εκδόσεις PHP:** 7.4, 8.0, 8.1, 8.2, 8.3, 8.4 και 8.5. Όλα τα PHP αρχεία πέρασαν έλεγχο σύνταξης και εκτελέστηκαν αυτόνομα τεστ.
