# Βάση δεδομένων μονάδας

## WHMCS

Η σελίδα «Βάση δεδομένων μονάδας» εμφανίζει τους πίνακες και τις στήλες που απαιτούνται και την τρέχουσα κατάστασή τους. Είναι διαθέσιμη μόνο στον καθορισμένο Super Administrator. Χρησιμοποιήστε την όταν κάποιο άλλο τμήμα αναφέρει ότι λείπει πίνακας ή στήλη, όχι ως γενικό εργαλείο διαχείρισης ολόκληρης της βάσης WHMCS.

Εξετάστε πρώτα τον πίνακα κατάστασης. Επιλέξτε μόνο τις εγγραφές με MISSING που θέλετε να επιδιορθώσετε και πατήστε «Fix Selected items». Φορτώστε ξανά τη σελίδα και ελέγξτε αν η επιδιόρθωση πέτυχε. Μια στήλη μπορεί να μην έχει αυτοματοποιημένη συνταγή δημιουργίας· τότε ο διαχειριστής θα δείξει το πρόβλημα, αλλά δεν μπορεί να την προσθέσει μόνος του.

Η επιλογή «Delete Selected items» αφαιρεί τα επιλεγμένα αντικείμενα της μονάδας και δεν αναιρείται. Πριν τη χρησιμοποιήσετε, εξαγάγετε τα δεδομένα της μονάδας και κρατήστε αντίγραφο ασφαλείας της βάσης. Μην επιλέγετε άσχετες γραμμές απλώς για να εξαφανιστεί μια προειδοποίηση.
