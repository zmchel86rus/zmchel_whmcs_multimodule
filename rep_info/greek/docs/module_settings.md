# Ρυθμίσεις μονάδας

Αρχίστε ενεργοποιώντας τις γλώσσες που θα χρησιμοποιήσετε. Έπειτα επιλέξτε τη μορφή URL και τη γλωσσική δρομολόγηση, αποθηκεύστε και δοκιμάστε δημόσιες σελίδες. Όταν αλλάζουν οι διαδρομές, ενημερώστε τους κανόνες Apache στον Rewrite Manager ή τη σχετική ρύθμιση Nginx. Πριν από σημαντικές αλλαγές, εξαγάγετε αντίγραφο των δεδομένων.

## Διαθέσιμες καρτέλες

- **Εισαγωγή / εξαγωγή:** δημιουργήστε ZIP για επιλεγμένα δεδομένα ή εισαγάγετε ZIP ή JSON. Διαβάστε τον [οδηγό μεταφοράς](module_settings_transfer.md) πριν από εισαγωγή.
- **Επεξεργάσιμες σταθερές:** ρυθμίστε URL, γλώσσες, εμφάνιση, πολυμέσα, συντήρηση και Smarty. Διαβάστε την περιγραφή κάθε πεδίου πριν το αλλάξετε.
- **Υποστηριζόμενες γλώσσες:** ενεργοποιήστε τις απαραίτητες γλώσσες. Διατηρήστε ενεργή την προεπιλεγμένη γλώσσα του WHMCS έως ότου την αλλάξετε στον πίνακα ελέγχου.
- **Ανακατευθύνσεις και sitemap:** ορίστε αυτόματες ανακατευθύνσεις και χρονισμό XML· οι μεμονωμένοι κανόνες βρίσκονται στους αντίστοιχους διαχειριστές.
- **Header, Footer, Robots:** εισαγάγετε κώδικα ή κείμενο και ελέγξτε το πραγματικό αποτέλεσμα στον ιστότοπο.

Οι ρυθμίσεις που εξαρτώνται από το web server χρειάζονται αντίστοιχους κανόνες εκεί. Ο Apache χρησιμοποιεί .htaccess, ενώ στο Nginx πρέπει να ρυθμίσετε τις διαδρομές στο αρχείο του server.
