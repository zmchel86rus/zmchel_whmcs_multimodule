# Διαχείριση κανόνων rewrite

## WHMCS

Ο Rewrite Manager ελέγχει και εγκαθιστά τους κανόνες Apache της μονάδας στο κύριο αρχείο .htaccess του ιστότοπου. Εδώ διατηρούνται και προσαρμοσμένοι κανόνες. Οι απλές ανακατευθύνσεις από ένα URL σε άλλο δημιουργούνται ξεχωριστά στον [Διαχειριστή ανακατευθύνσεων](redirects_manager.md), ώστε να μη συγχέονται οι δύο λειτουργίες.

## Έλεγχος και εφαρμογή κανόνων

Ανοίξτε τον διαχειριστή και ελέγξτε την κατάσταση των διαδρομών για τις ενεργές γλώσσες. Η ενέργεια «Add or update rules» γράφει το μπλοκ κανόνων της μονάδας στο .htaccess. Ελέγξτε ξανά την κατάσταση και δοκιμάστε μια δημοσιευμένη σελίδα στην προεπιλεγμένη γλώσσα και σε μια δεύτερη. Η ενέργεια «Remove all rules» αφαιρεί ολόκληρο το μπλοκ, όταν υπάρχει.

Για προσαρμοσμένο κανόνα εισαγάγετε το μοτίβο URL, τον προορισμό και τα flags, αποθηκεύστε και εφαρμόστε εκ νέου τους κανόνες. Ελέγξτε ιδιαίτερα τα γενικά μοτίβα, γιατί μπορεί να επηρεάσουν άσχετες διαδρομές. Ο Apache διαβάζει .htaccess· το nginx χρειάζεται ισοδύναμη ρύθμιση στο επίπεδο του διακομιστή.
