# Ανακατευθύνσεις και γλώσσες sitemap

## HTTP

Ο Διαχειριστής ανακατευθύνσεων αποθηκεύει ακριβείς κανόνες πηγή → προορισμός με HTTP 301, 302, 303, 307 ή 308. Μπορείτε να τους επεξεργαστείτε, να τους απενεργοποιήσετε ή να τους διαγράψετε. Η λίστα δείχνει 50 κανόνες ανά σελίδα. Οι πηγές είναι διαδρομές που αρχίζουν με / ή απόλυτα URL του ίδιου ιστότοπου· οι προορισμοί είναι διαδρομές ή HTTP(S) URL.

Η τελική κάθετος θεωρείται ισοδύναμη κατά την αντιστοίχιση, αλλά ο προορισμός κρατά τη δική του. Κανόνας για συγκεκριμένο query υπερισχύει απλού κανόνα διαδρομής· ένας κανόνας διαδρομής ισχύει και όταν το αίτημα έχει παραμέτρους. Οι παράμετροι προορισμού αντικαθιστούν τις αρχικές. Οι κανόνες αφορούν αιτήματα GET και HEAD που φτάνουν στο WHMCS πριν από τον page builder, χωρίς να αλλάζουν .htaccess, συνεδρία ή προφίλ. Το ZM_PB_ENABLE_REDIRECTS_MANAGER ελέγχει τους αποθηκευμένους κανόνες.

Αυτόματο 301 δημιουργείται όταν αλλάζει το slug δημοσιευμένης σελίδας που παραμένει δημοσιευμένη. Η δημιουργία πρώτης δημοσίευσης δεν παράγει ανακατεύθυνση. Η καθυστέρηση ελέγχεται από ZM_PB_AUTO_REDIRECT_DAYS, προεπιλογή 14 ημέρες, ενώ 0 την καταργεί. Οι παλιές διευθύνσεις ενημερώνονται μετά από επόμενη μετονομασία· ένας αυτοαναφορικός κανόνας αφαιρείται. Οι χειροκίνητοι κανόνες προηγούνται. Αν μια σελίδα WHMCS αντικαθίσταται, η διεύθυνση alias δείχνει στην αρχική συστημική σελίδα.

Οι κανόνες αποθηκεύονται στο zm_pb_redirects. Ο χειρισμός αιτήματος δεν δημιουργεί τον πίνακα· χρησιμοποιήστε τη Βάση δεδομένων μονάδας αν λείπει. Τα υπάρχοντα πεδία URL έχουν όριο 128 bytes. Τα sitemap_pages.xml και sitemap_posts.xml περιλαμβάνουν εναλλακτικές γλώσσες και x-default, ενώ αποκλείουν πηγές ανακατευθύνσεων. Δημιουργήστε ξανά τα XML αρχεία μετά από αλλαγές URL.
