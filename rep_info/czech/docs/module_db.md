# Databáze modulu

## WHMCS

- **Databáze modulu:** `MISSING` → Vybrat → Opravit Vybrané položky.
- **Smazat Vybrané položky** — Tuto akci nelze vrátit zpět.

Stránka **Databáze modulu** zobrazuje požadované tabulky a sloupce i jejich stav. Přístup k ní má pouze určený superadministrátor. Otevřete ji, když jiná sekce hlásí chybějící tabulku nebo sloupec. Projděte seznam, vyberte jen položky k opravě a klikněte na **Opravit vybrané**. Některé sloupce nelze opravit automaticky; po operaci stav znovu zkontrolujte.

**Smazat vybrané** nevratně odstraní vybrané databázové objekty. Před odstraněním exportujte data modulu a vytvořte zálohu databáze.
