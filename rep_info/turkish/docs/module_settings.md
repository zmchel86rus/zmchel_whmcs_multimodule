# Modül ayarları

Önce gerekli dilleri etkinleştirin, ardından URL biçimini ve dil yönlendirmesini seçip ayarları kaydedin. Rotalar değiştiyse Apache kurallarını Rewrite Manager üzerinden veya ilgili Nginx yapılandırmasını güncelleyin. Bir modül sayfasını varsayılan dilde ve başka bir etkin dilde kontrol edin. Büyük değişikliklerden ya da içe aktarmadan önce yedek dışa aktarın.

## WHMCS

Modülün kullanabileceği dilleri seçin. Bir dili kapatmak içeriğini silmez. Apache üzerinde güzel URL kullanıyorsanız dilleri değiştirdikten sonra Rewrite Manager kurallarını güncelleyin.
