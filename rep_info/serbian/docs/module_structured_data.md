# Структурисани подаци

- **Уређивач страница → Подешавања метаподатака → Тип Schema.org шеме → Сачувај.**

Попуните метаподатке и одговарајући тип за сваки језик: WebPage, тип чланка или ContactPage. После објављивања проверите JSON-LD и канонску URL адресу.

## Шта модул означава

Менији и садржај могу да створе `SiteNavigationElement`, видљива питања и одговори `FAQPage`, а навигациона путања са више ставки `BreadcrumbList`. Блокови распореда, дугмад и филтери не добијају аутоматски тип садржаја. Изабрани Schema-тип за страницу управља њеним JSON-LD излазом; када је искључен, та ознака се не приказује.

## Провера после објављивања

На јавној страници проверите JSON-LD, канонски URL, језик и садржај који је стварно видљив. Важећа ознака не гарантује проширени резултат претраге.

## Schema.org

`SiteNavigationElement` користи стварно видљиве везе и називе менија; садржај може додати `WebPageElement` за наслове који заиста постоје на страници. `FAQPage` укључује само потпуна питања и одговоре видљиве посетиоцу: скривени блокови и обични акордеони се изостављају. `BreadcrumbList` настаје тек са најмање две ставке. Подаци о организацији долазе из WHMCS-а; језици контакта су у `ContactPoint.availableLanguage` по BCP 47. За филтере, пагинацију, форме и сопствени HTML не погађа се Schema тип.

## Упутства

- **Тип Schema.org шеме** — Када је онемогућено, Schema.org JSON ознаке се не приказују за ову страницу.
- **Путања навигације** — Назив странице у путањи навигације
- **Канонска URL адреса**
- **Наслов странице**
- **Метаопис**
- **Open Graph наслов** — Ако је празно, користи се наслов странице.
- **Open Graph опис** — Ако је празно, користи се метаопис.
- **Open Graph слика** — Ако је празно, користи се слика странице.
