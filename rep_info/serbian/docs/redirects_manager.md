# Преусмеравања

Унесите стару и нову URL адресу. Користите 301 за трајне и 302 за привремене промене; проверите извор и избегните преусмеравање на исту адресу.

## HTTP

Правила подржавају HTTP кодове `301`, `302`, `303`, `307`, `308` и важе само за захтеве `GET`/`HEAD` који стигну до WHMCS-а. Извор се тачно пореди по путањи и, ако су наведени, по параметрима упита; параметри одредишта замењују старе. Менаџер чува правила у `zm_pb_redirects`, али не прави табелу током захтева: користите **Базу података модула**. Постојеће URL колоне ограничене су на 128 бајтова.

Ручна правила имају предност над аутоматским. Промена slug-а објављене странице може после задатог чекања да направи аутоматски `301` за сваки активни језик; објављивање нацрта га не прави. Каснија преименовања ажурирају стара одредишта. Правило са параметрима упита има предност над правилом само за путању. Изворни URL мора припадати овом сајту и не сме имати фрагмент `#`.

## Упутства

- Тачне адресе: извор → одредиште. Извор је путања од корена сајта или URL адреса на овом сајту. Одредиште је путања или пуна HTTP(S) URL адреса. Правило без параметара упита подудара се и са захтевима који их садрже; одредиште се користи онако како је унето. Правила се примењују на GET/HEAD захтеве који стигну до WHMCS-а.
- Извор
- Одредиште
- Омогућено
- Онемогућено
- Подразумевано: 14 дана. Рачуна се од последње измене објављене странице или њених активних превода; ако није мењана, од креирања. Поставите 0 да не буде одлагања. Аутоматска правила користе HTTP 301.
- Адресе страница које замењују системске странице аутоматски се преусмеравају на системске странице које замењују. Ако замена има више одредишта, користи се прво подешено. Ова преусмеравања раде кад год су замене омогућене, независно од правила Управљача преусмеравањима.
- Унесите важећу путању која почиње са / или пуну HTTP(S) URL адресу. Извор мора припадати овом сајту; фрагменти # нису подржани.
