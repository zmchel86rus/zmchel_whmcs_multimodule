# Bezmaksas WHMCS daudzfunkcionālais modulis

**Pirms lietošanas ģenerējiet unikālus sāļus un ievietojiet ZM_PB_ADMIN_SALT, ZM_PB_SECURE_SALT un ZM_PB_NONCE_SALT failā module_init.php.** Modulis izstrādāts un pārbaudīts ar WHMCS 8.13.1–8.13.7. Apache tiek pilnībā atbalstīts. Nginx var darboties, taču valodu maršrutēšanai sākumlapā var būt vajadzīga papildu konfigurācija.

**Pirms pirmās lietošanas atveriet Moduļa iestatījumi → Atbalstītās valodas un ieslēdziet nepieciešamās valodas.**

**Pārbaudītās PHP versijas:** 7.4, 8.0, 8.1, 8.2, 8.3, 8.4 un 8.5.

**zmchel WHMCS Multimodule ir bezmaksas.** Tas ļauj pārvaldīt lapas un rakstus WHMCS administrācijā, izmantojot vizuālo redaktoru, tulkojumus, izvēlnes, mediju bibliotēku, SEO laukus, XML vietnes kartes, pāradresācijas un URL pārrakstīšanas noteikumus.

## Turpmākā attīstība

- Pievienot ligzdotas lapas un lapu kategorijas.
- Sadalīt pašreizējo monolītu savstarpēji sadarbojošās komponentēs.
- Izveidot moduļa administrācijas piekļuves tiesību pārvaldnieku.
- Paplašināt noklusējuma valodu sarakstu supported_langs.php.
- Pievienot koda redaktoru moduļa veidnēm un klientu tēmām, izņemot administrācijas tēmu.
- Izveidot WHMCS un citu moduļu valodu failu pārvaldnieku.
- Uzlabot mediju pārvaldnieku.
- Izveidot pilnvērtīgu un efektīvu SEO pārvaldnieku, iedvesmojoties no Yoast SEO.
- Pievienot daudzvalodu XML vietnes kartes un HTML kartes lapu.
- Pievienot lietošanas statistiku lapu pārvaldniekam.
- Minificēt JS, CSS un HTML, kešot pilnas lapas un optimizēt moduļa un WHMCS datubāzes tabulas.
- Pievienot uzticamu moduļa atjaunināšanas sistēmu.

Tie ir plāni, nevis stingrs darbu grafiks.
