# Lapu pārvaldnieks

## 2. Lapas veidošana

Atveriet lapu sarakstu un pievienojiet lapu. Norādiet iekšējo nosaukumu un slug ar latīņu burtiem, cipariem un defisēm, piemēram, about-us. Izvēlieties piekļuvi visiem, tikai autorizētiem klientiem vai tikai viesiem. Norādiet statusu un valodas. WHMCS noklusējuma valodai jābūt moduļa atbalstītai.

## URL

Filtrējiet sarakstu pēc nosaukuma, piekļuves, tipa, statusa vai valodas. **Apmeklēt** atver publisko URL. **Dzēst** vispirms pārvieto lapu uz atkritni; neatgriezeniska dzēšana notiek tur. Ja lapa neatveras, pārbaudiet publicēšanu, aktīvo valodu un piekļuves tipu.

## WHMCS

Lai aizstātu WHMCS lapu, izvēlieties esošo sistēmas adresi un publicētu moduļa lapu. Izvēlieties pilnu aizstāšanu, pievienošanu pirms vai pēc parastā satura vai tikai meta/SEO. Saglabājiet un pārbaudiet sākotnējo WHMCS URL kā viesis un kā pieteicies klients.
