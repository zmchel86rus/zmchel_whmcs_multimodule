# Moduļa iestatījumi

Vispirms ieslēdziet vajadzīgās valodas, pēc tam izvēlieties URL formātu un valodu maršrutēšanu un saglabājiet iestatījumus. Ja maršruti mainījās, atjauniniet Apache noteikumus Rewrite Manager vai atbilstošo Nginx konfigurāciju. Pārbaudiet moduļa lapu noklusējuma valodā un vēl vienā aktīvā valodā. Pirms lielām izmaiņām vai importa eksportējiet rezerves kopiju.

- [Imports un eksports](module_settings_transfer.md)

## 1. Uzstādīšana un piekļuve

Aktivizējiet papildmoduli WHMCS un piešķiriet piekļuvi pilnvarotajiem administratoriem. Moduļa datubāzes sadaļā pārbaudiet nepieciešamās tabulas. Pārskatiet glītās URL adreses, valodu maršrutus un izvēļņu vietas. Apache izmanto .htaccess; Nginx gadījumā atbilstošie servera noteikumi jākonfigurē atsevišķi.
