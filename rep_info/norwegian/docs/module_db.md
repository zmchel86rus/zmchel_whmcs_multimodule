# Moduldatabase

## WHMCS

- **Moduldatabase:** `MISSING` → Velg → Rett opp Valgte elementer.
- **Slett Valgte elementer** — Denne handlingen kan ikke angres.

Siden **Moduldatabase** viser nødvendige tabeller og kolonner og statusen deres. Bare den angitte superadministratoren har tilgang. Åpne siden hvis en annen del melder at en tabell eller kolonne mangler. Gå gjennom listen, velg bare elementene som skal repareres, og klikk **Reparer valgte**. Noen kolonner kan ikke repareres automatisk; kontroller statusen igjen etterpå.

**Slett valgte** fjerner de valgte databaseobjektene permanent. Eksporter moduldata og ta sikkerhetskopi av databasen før sletting.

## Instruksjoner

- Tilgang nektet. Bare superadministratoren (ID …) kan bruke modulens databaseside.
- Rett opp
- Valgte elementer
- Slett
- Denne handlingen kan ikke angres.
- Menytabellene er ennå ikke opprettet. Legg dem til i Moduldatabase.
- Legg først til kolonnen optimization_attempted i modulens tabellbehandling.
