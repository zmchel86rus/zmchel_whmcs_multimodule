# 가져오기와 내보내기

## ZIP 아카이브

Module settings → Import / export에서 모든 데이터 또는 원하는 구역을 선택합니다. 내보내기는 manifest.json과 분리된 페이지 CSS/JS 파일을 포함하는 ZIP을 만듭니다. JSON 파일도 가져올 수 있습니다. 다른 사이트로 이동하거나 큰 설정 변경을 하기 전에 원본 아카이브를 보관하세요.

- **페이지와 게시물:** 설정, 모든 번역, GrapesJS 콘텐츠, SEO와 사이트맵 설정을 옮깁니다. 생성된 CSS/JS는 새 페이지 ID에 맞춰 다시 생성됩니다.
- **메뉴:** 계층, 번역 라벨, 위치, 설정을 포함합니다. 페이지는 slug와 auth_type의 조합으로, 메뉴는 이름으로 매칭합니다.
- **설정:** 편집 가능한 상수, 덮어쓰기, 머리말·꼬리말, robots.txt를 포함합니다. URL 모드와 마지막 사이트맵 생성 시간은 현재 사이트에 남습니다.
- **리디렉션과 rewrite:** 수동 규칙, 페이지 연결, 사용자 정의 규칙을 옮깁니다. rewrite 규칙은 가져온 뒤 관리자에서 적용하세요.
- **미디어:** 등록된 파일, 변형, 설명을 옮기고 무관한 WHMCS 첨부 파일은 제외합니다.

가져오기는 일치하는 기록을 갱신하고 새 기록을 더하지만 관계없는 데이터는 유지합니다. 아카이브에 없는 선택 구역은 건너뜁니다. 새 사이트에 메뉴나 자동 리디렉션만 옮길 때는 연결된 페이지도 함께 선택하세요. 원본 사이트의 SystemURL은 대상 사이트 주소로 바꾸고 외부 URL은 유지합니다. 이미지가 필요한 페이지와 미디어는 함께 옮깁니다.

ZIP은 128 MiB, JSON은 32 MiB까지입니다. PHP의 upload_max_filesize와 post_max_size도 고려하고 ZIP 확장을 켜세요. 생성된 CSS/JS 파일이 없거나 읽을 수 없으면 내보내기에서 제외하고 경고를 보여 줍니다. 수정 이력, 수집한 Smarty 변수, WHMCS 계정과 비밀 정보, 테마 파일은 포함하지 않습니다. 가져오기는 기존 테이블을 사용하며 스키마를 만들지 않습니다.

기록 갱신 전에는 확인 창이 표시됩니다. 데이터베이스 변경은 트랜잭션으로 실행하고 실패한 파일 교체는 복원됩니다. 파일 잠금이 동시 가져오기를 막습니다. 성공 후 사이트맵을 다시 만들고 공개 경로를 확인하세요.
