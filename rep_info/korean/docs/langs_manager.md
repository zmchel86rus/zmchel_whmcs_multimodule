# 언어 관리자

언어 관리자는 WHMCS의 고객 및 관리자 언어 파일, 이 모듈, 검색된 다른 모듈의 번역을 관리자 화면에서 편집합니다. 모듈의 Super Administrator 권한과 해당 폴더에 대한 PHP 쓰기 권한이 필요합니다. 기본 흐름은 Sections → Languages → Translations이며 **Save** 버튼은 한 번역만 저장합니다.

## 시작하기

먼저 Module settings → Supported languages에서 필요한 언어를 켭니다. 이 목록은 관리자가 추가할 수 있는 언어와 모듈 페이지에 사용할 언어를 정합니다. Sections에서 WHMCS 고객·관리자, 이 모듈 또는 다른 모듈을 선택하세요. 표에는 기존, 비활성, 추가 가능한 언어 수가 표시됩니다. 새 언어는 처음에 참조 언어의 문자열을 보여 주므로 곧바로 완성된 번역으로 간주하면 안 됩니다. 고유 번역이 없는 카탈로그에는 **Untranslated** 표시가 붙습니다.

## 번역 편집

**Original**은 override 변경을 제외하고 선택한 언어의 원본 파일에 실제로 있는 텍스트입니다. 해당 언어의 원본이 없으면 **Reference**로 기본 언어를 보여 줍니다. 키나 문구로 검색하고 원본 및 추가 키 필터를 사용하세요. 긴 목록은 페이지로 나뉩니다. 각 행을 따로 저장합니다. 사용자가 만든 키는 부모를 선택해 추가하고 나중에 이름을 바꾸거나 삭제할 수 있지만, 원본 키는 그렇게 지울 수 없습니다. 안전하게 저장할 수 없는 다른 모듈 형식은 읽기 전용입니다.

## JSON 내보내기와 가져오기

**Export JSON**은 선택한 언어의 키와 현재 번역을 내려받습니다. 대량 편집 전 복사본을 보관하세요. **Import JSON**은 기존 키만 바꾸며 새로운 키를 만들지 않습니다. 섹션, 언어, 키 경로를 유지해야 합니다. 알 수 없는 키와 중복 키는 건너뛰고 결과에 표시하며 유효한 항목은 계속 처리합니다. 업로드 한도는 8 MiB입니다.

## 언어 파일과 이름

Languages 탭에서 언어 파일을 비활성화하거나 다시 켤 수 있으며 꺼진 언어도 번역 편집은 가능합니다. 영어 기준 파일과 현재 WHMCS 기본 언어는 비활성화할 수 없습니다. 관리자가 만든 WHMCS 파일은 백업되어 업데이트 후 복원할 수 있습니다. 오래된 파일명을 발견하면 Sections의 공통 수정 도구에서 새 이름을 확인하세요. 기본 언어를 바꾸려면 새 언어를 먼저 모듈 설정에서 켠 뒤 WHMCS의 기본값을 변경하고 마지막으로 이전 언어를 끄세요.
