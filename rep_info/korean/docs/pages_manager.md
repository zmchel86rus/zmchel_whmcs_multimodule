# 페이지 관리자

페이지 관리자는 모듈에서 만든 페이지를 보여 줍니다. 새 페이지를 만들거나 기존 페이지를 검색하고 게시 상태를 바꾸며, 공개 주소를 열거나 WHMCS 기본 페이지에 빌더 콘텐츠를 연결할 수 있습니다. 본문과 메타데이터는 [페이지 편집기](pages_editor.md)에서 따로 수정합니다.

## 페이지 만들기

**Add page**에서 내부 이름과 about-us 같은 slug를 입력하세요. 도메인이나 언어 접두사는 넣지 않습니다. 페이지, 게시물 또는 시스템 페이지 유형을 선택하고, 접근 대상을 모든 방문자·로그인 사용자·게스트 중에서 지정합니다. 필요한 언어를 선택하세요. WHMCS의 기본 언어가 모듈 설정에서 활성화되어 있어야 저장할 수 있습니다. 저장한 뒤 편집기에서 언어별 콘텐츠와 메타데이터를 작성합니다. 초안은 공개되지 않으므로 준비가 끝난 뒤 게시하세요.

## 검색, 방문, 삭제

목록 필터로 이름, 접근 유형, 상태, 언어, 페이지 유형을 찾을 수 있습니다. **Visit**은 실제 공개 URL을 엽니다. **Delete**는 먼저 휴지통으로 이동시키며, 영구 삭제는 휴지통에서만 합니다. 주소가 열리지 않으면 라우팅 문제로 판단하기 전에 게시 상태와 해당 언어의 활성 번역을 먼저 확인하세요.

## WHMCS 페이지 덮어쓰기

기존 WHMCS 페이지와 콘텐츠를 제공할 게시된 빌더 페이지를 선택합니다. 덮어쓰기 유형에 따라 원래 내용을 교체하거나 앞뒤에 삽입하고, 메타데이터만 교체하거나 효과를 결합할 수 있습니다. 저장 후 원래 WHMCS 주소를 게스트와 로그인 고객 상태에서 모두 확인하세요. 빌더 slug와 원래 주소가 다르면 리디렉션이 적용될 수 있습니다.
