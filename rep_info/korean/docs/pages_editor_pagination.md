# 페이지 나누기 블록

1. 대상 목록 앞이나 뒤에 블록을 놓고 캔버스에서 Smarty 블록 또는 항목 컨테이너를 선택합니다. 페이지 나누기 블록은 대상의 바깥에 두어야 합니다.
2. Smarty 목록에는 전체 컬렉션을 담은 변수, 예를 들어 $items를 입력합니다. 템플릿의 일반 {foreach}는 유지하고 두 번째 array_slice를 넣지 마세요.
3. 페이지 크기와 시작·끝·현재 위치 양옆에 보일 버튼 수를 PC와 모바일별로 정합니다. 같은 목록을 위한 보조 컨트롤을 추가할 수도 있습니다.

## 링크와 여러 목록

각 블록에서 모듈 기본값, /page/2/ 또는 ?page=2 형식을 선택합니다. 경로형 링크에는 rewrite 규칙이 필요하고 직접 PHP 경로에는 query 방식이 안전합니다. 필터, 정렬, 설치 경로, 언어 접두사는 보존됩니다. 첫 목록은 page, count, sort를 쓰고 다음 목록은 대상 블록 ID가 붙은 매개변수를 사용합니다. /page/N/ 형식에서는 pager가 번호의 소유 목록을 가리킵니다. 컨트롤을 복제해도 목록 자체가 새로 만들어지지는 않습니다.

## 목록의 데이터 원천

Smarty 변수에 연결하면 해당 페이지에 이미 존재하는 컬렉션을 분할합니다. 다른 데이터 원천에서 누락된 항목을 가져오지는 않습니다. 변수가 없으면 선택한 컨테이너의 HTML 항목을 나눕니다. 반복 항목의 클래스나 tr 같은 태그를 지정할 수 있고 thead와 tfoot는 그대로 유지됩니다. 큰 동적 목록에는 전체 HTML을 먼저 렌더링하는 대신 변수를 사용하세요. Smarty 블록에는 total, page, pages, count, offset이 포함된 $zm_pagination이 전달됩니다. 목록이 비었거나 한 페이지에 들어가면 컨트롤은 숨겨집니다.

## 페이지 크기, SEO, 필터

선택 메뉴는 10, 25, 50, 100, 250개를 제공합니다. 크기를 바꾸면 필터는 유지되고 해당 목록만 첫 페이지로 돌아갑니다. 서버는 count와 count_<id> 값을 10–250으로 제한합니다. 다음 페이지의 제목, 설명, 마지막 breadcrumb에는 페이지 번호가 들어가고 canonical은 그 결과 페이지를 가리킵니다. noindex 옵션은 첫 페이지 뒤에만 적용됩니다. 텍스트 필터는 쉼표로 나눈 여러 필드와 배열 키를 검색할 수 있습니다. 날짜 범위는 YYYY-MM-DD를 사용하며 마지막 날짜 전체를 포함합니다.

## YYYY-MM-DD 날짜

필터는 페이지 나누기와 같은 목록에 적용됩니다. 적용하거나 지우면 해당 목록이 첫 페이지로 돌아갑니다. 언어와 정렬 매개변수가 URL에서 그대로 유지되는지 확인하세요.

## Flex / Grid 배치

기기 크기별 필드 너비와 열 수를 정합니다. 페이지 크기 선택 메뉴를 다른 컨테이너로 옮겨도 연결은 유지됩니다. 복제된 컨트롤은 필터와 페이지 크기를 공유합니다.
