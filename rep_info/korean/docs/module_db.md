# 모듈 데이터베이스

## WHMCS

Module database 화면에는 모듈에 필요한 테이블과 열, 현재 존재 여부가 표시됩니다. 설정된 Super Administrator만 사용할 수 있습니다. 다른 모듈 화면에서 필요한 테이블이나 열이 없다고 알릴 때 이 화면을 여세요. WHMCS 전체 데이터베이스를 임의로 편집하는 도구가 아닙니다.

먼저 상태 표를 읽고, 복구할 MISSING 항목만 선택합니다. **Fix Selected items**를 실행한 다음 화면을 새로고침하여 실제로 복구되었는지 확인하세요. 일부 열에는 자동 복구 정의가 없을 수 있습니다. 이런 경우 관리자는 부족한 열을 보여 주지만 직접 추가하지 못합니다.

**Delete Selected items**는 선택한 모듈 데이터베이스 객체를 제거하며 되돌릴 수 없습니다. 실행 전에 모듈 데이터를 내보내고 데이터베이스 백업을 준비하세요. 경고를 없애기 위해 관계없는 행을 선택하지 마세요. 복구를 마쳤다면 오류를 보고했던 기능으로 돌아가 정상 동작을 확인합니다.
