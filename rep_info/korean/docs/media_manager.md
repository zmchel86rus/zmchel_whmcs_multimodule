# 미디어 관리자

미디어 라이브러리는 페이지 블록과 모듈의 다른 콘텐츠가 사용하는 파일을 보관합니다. 파일 업로드, 기존 항목 검색, 이미지 최적화를 여기에서 수행할 수 있으며 WHMCS 테마의 파일을 직접 수정할 필요가 없습니다.

## 파일 업로드와 선택

**Upload**를 눌러 이미지, 오디오, 동영상 또는 PDF를 선택합니다. 사용할 수 있는 이름, 제목, 설명, alt 필드를 입력하세요. 이미지의 alt에는 파일명이 아니라 의미 있는 내용을 적습니다. 검색과 유형 필터로 항목을 찾고, **Load more**로 다음 결과를 불러옵니다. 이미지 블록에서 **Choose image**를 눌러 라이브러리 파일을 선택한 뒤 페이지를 저장하세요. 업로드가 성공했더라도 공개 페이지의 실제 주소를 확인해야 합니다.

## 이미지 출력

관리자는 여러 크기의 이미지 변형을 만듭니다. **Optimize image**를 실행한 뒤, 특히 글자나 가는 선이 포함된 이미지의 품질을 살펴보세요. 특정 이미지에 반응형 변형이 필요 없다면 해당 이미지 블록에서 srcset을 끌 수 있습니다. 최종 공개 페이지에서 URL, 크기, alt가 기대한 대로 출력되는지 확인하세요.
