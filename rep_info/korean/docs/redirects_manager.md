# 리디렉션과 사이트맵 언어

## HTTP

Redirect Manager는 출발지 → 목적지 규칙을 HTTP 301, 302, 303, 307, 308로 만듭니다. 규칙을 편집, 비활성화, 삭제할 수 있으며 목록은 한 페이지에 50개를 표시합니다. 출발지는 /로 시작하는 경로나 같은 사이트의 절대 URL입니다. 목적지는 경로나 HTTP(S) URL일 수 있습니다.

끝 슬래시는 일치 검사에서 같은 것으로 취급하지만 목적지의 슬래시 형태는 유지됩니다. 특정 query가 붙은 규칙이 일반 경로 규칙보다 우선합니다. 경로 규칙은 query가 있는 요청에도 일치하고, 목적지 매개변수는 출발지 매개변수를 교체합니다. 규칙은 WHMCS에 도달하는 GET과 HEAD 요청에서 page builder보다 먼저 적용됩니다. .htaccess, 언어 세션, 사용자 프로필을 변경하지 않습니다. ZM_PB_ENABLE_REDIRECTS_MANAGER가 저장된 규칙을 켭니다.

게시된 페이지의 slug가 바뀌고 게시 상태가 유지되면 자동 301이 만들어집니다. 초안을 처음 게시할 때는 만들지 않습니다. ZM_PB_AUTO_REDIRECT_DAYS의 기본값은 14일이고 0은 지연을 없앱니다. 다음 이름 변경은 과거 규칙의 목적지를 갱신합니다. 예전 slug로 돌아가 자기 자신을 가리키는 규칙은 제거합니다. 수동 규칙이 우선이며 WHMCS 페이지 덮어쓰기 별칭은 원래 주소로 이동할 수 있습니다.

규칙은 zm_pb_redirects에 저장됩니다. 요청 중에 누락된 테이블을 생성하지 않으므로 Module database를 사용하세요. 기존 URL 열은 128바이트로 제한됩니다. sitemap_pages.xml과 sitemap_posts.xml에는 언어별 대체 주소와 x-default가 들어가지만 리디렉션 출발지는 제외됩니다. URL을 바꾼 뒤 XML을 다시 생성하세요.
