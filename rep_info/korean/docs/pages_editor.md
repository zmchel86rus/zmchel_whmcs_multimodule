# 페이지 편집기

[페이지 관리자](pages_manager.md)에서 페이지를 만든 뒤 편집기를 엽니다. 주요 설정, 콘텐츠, 메타데이터, 사이트맵 탭이 분리되어 있습니다. 번역 콘텐츠를 고치기 전에 활성 언어를 선택하세요. 탭마다 저장 동작이 있고 **Save all**은 관련 섹션을 함께 저장합니다. 저장 후 공개 페이지를 열어 실제 결과를 검토합니다.

## 주요 설정

내부 이름, slug, 유형, 게시 상태, 접근 방식, 활성 언어를 확인합니다. 게시된 페이지라도 방문자에게 보여 줄 언어에 콘텐츠가 있어야 합니다. WHMCS 기본 언어가 지원 목록에 없으면 페이지 저장 전에 모듈 설정에서 활성화하세요. 공개 URL이 없을 때는 해당 번역이 활성 상태인지도 확인합니다.

## 콘텐츠 설정

언어를 선택하고 GrapesJS 블록을 캔버스에 끌어다 놓습니다. 블록을 선택해 세부 설정을 바꾸고, 서식 있는 글은 TinyMCE로 편집합니다. 구역, 열, Flex, Grid로 레이아웃을 구성하세요. 언어 도구로 콘텐츠나 구조를 복사해도 대상 언어의 문구는 직접 번역해야 합니다. 추가 설명은 [페이지 나누기와 필터](pages_editor_pagination.md), [Smarty](pages_editor_smarty.md), [구조화 데이터](module_structured_data.md)를 참고하세요.

## 메타데이터와 사이트맵

언어마다 제목과 설명을 입력합니다. 필요에 따라 canonical, robots, 공유 메타데이터, breadcrumbs, Schema 유형을 검토하세요. Sitemap 설정에서는 게시된 일반 페이지의 변경 빈도와 우선순위를 정합니다. [Sitemap Manager](sitemap_manager.md)가 XML 파일을 생성하며, 변경 후 실제 URL과 언어 대체 링크를 확인해야 합니다.

## 문의 양식

**Contact Form** 블록에서 WHMCS ticket과 지원 부서 또는 email과 수신자를 선택합니다. 제목, 설명, 버튼, 각 필드의 이름과 유형, 필수 여부, 검증 규칙을 설정하세요. 비회원 티켓에는 발신자 이름과 이메일 역할을 맡는 필드가 필요합니다. 드롭다운 선택지는 줄마다 하나씩 적고 동의 항목은 별도 필드로 만듭니다. WHMCS에서 설정한 CAPTCHA를 사용하세요. 게스트로 실제 제출을 해 보고 티켓 또는 메일의 도착 여부를 확인합니다. 편집기의 녹색 상태만으로 전송 성공을 보장하지 않으며 PHP mail()이 실패하면 WHMCS SMTP를 설정하세요.
