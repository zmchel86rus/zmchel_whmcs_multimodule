# WHMCS용 무료 멀티모듈

**zmchel WHMCS Multimodule은 무료입니다.** WHMCS 관리 화면에서 시각적 페이지·블록 편집, 다국어 콘텐츠, 메뉴, 미디어, SEO 메타데이터, XML 사이트맵, 리디렉션, rewrite 규칙, 데이터 가져오기와 내보내기를 제공합니다. 실제 사용 방법은 [안내서](instruction.md)를 참고하세요.

## 처음 사용하기 전에

**모듈 설정 → 지원 언어에서 필요한 언어를 먼저 활성화하세요.**

모듈을 활성화할 때마다 module_init.php의 ZM_PB_ADMIN_SALT, ZM_PB_SECURE_SALT, ZM_PB_NONCE_SALT가 새로 생성됩니다. 세 값이 모두 기록되었는지 확인하세요.

**WHMCS 8.13.0–9.1.0**에서 개발하고 테스트했습니다. **Apache를 완전히 지원합니다 (100%)**. Nginx에서도 작동할 수 있지만 홈페이지의 언어 라우팅에는 추가 설정과 검증이 필요할 수 있습니다.

**검증한 PHP 버전:** 7.4, 8.0, 8.1, 8.2, 8.3, 8.4, 8.5. 모든 PHP 파일의 구문 검사와 독립 실행 테스트를 수행했습니다.

## 향후 개발 구상

- 페이지의 계층 구조와 범주 또는 섹션 추가.
- 현재의 단일 구조를 상호 작용하는 구성 요소로 분리.
- 관리자 권한 관리 기능 추가.
- supported_langs.php의 기본 언어 목록 확대.
- 모듈 .tpl 파일과 WHMCS 고객용 테마를 편집하는 코드 편집기 추가. 관리자 테마는 제외.
- ~~이 모듈, 다른 모듈, WHMCS의 언어 파일을 편집하는 언어 관리자 추가.~~
- 미디어 관리 기능 개선.
- Yoast SEO에서 영감을 얻은 효율적인 종합 SEO 관리자 개발.
- ~~다국어 사이트맵 생성과 HTML 사이트맵 페이지 추가.~~
- HTML 사이트맵 페이지 추가.
- 페이지 관리자에 이용 통계 추가.
- JS/CSS/HTML 압축, 전체 페이지 캐시, 모듈과 WHMCS 테이블 최적화 기능 추가.
- 정상적인 모듈 업데이트 체계 추가.

위 항목은 **향후 구상이며 확정된 일정은 아닙니다**.
