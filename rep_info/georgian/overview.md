# უფასო მულტიმოდული WHMCS-ისთვის

**zmchel WHMCS Multimodule უფასოა.** WHMCS-ის ადმინისტრაციიდან შეგიძლიათ მართოთ ვიზუალური გვერდები და ბლოკები, მრავალენოვანი შიგთავსი, მენიუ, მედია, SEO მეტამონაცემები, XML საიტის რუკები, გადამისამართებები, rewrite წესები და იმპორტი/ექსპორტი. ყოველდღიური გამოყენებისთვის იხილეთ [ინსტრუქცია](instruction.md).

## პირველ გამოყენებამდე

**გახსენით მოდულის პარამეტრები → მხარდაჭერილი ენები და ჩართეთ საჭირო ენები.**

ყოველ გააქტიურებაზე module_init.php-ში ახლიდან იქმნება ZM_PB_ADMIN_SALT, ZM_PB_SECURE_SALT და ZM_PB_NONCE_SALT. გადაამოწმეთ, რომ სამივე მნიშვნელობა შევსებულია.

მოდული შეიქმნა და გამოიცადა **WHMCS 8.13.0–9.1.0**-ზე. **Apache სრულად მხარდაჭერილია (100%)**. Nginx-ზეც შეიძლება მუშაობდეს, მაგრამ მთავარ გვერდზე ენის მარშრუტიზაციას დამატებითი კონფიგურაცია და შემოწმება შეიძლება დასჭირდეს.

**შემოწმებული PHP ვერსიები:** 7.4, 8.0, 8.1, 8.2, 8.3, 8.4 და 8.5. ყველა PHP ფაილმა გაიარა სინტაქსური შემოწმება და შესრულდა დამოუკიდებელი ტესტებიც.

## სამომავლო განვითარება

- ჩადგმული გვერდებისა და კატეგორიების ან განყოფილებების დამატება.
- დღევანდელი მონოლითის ურთიერთმოქმედ კომპონენტებად დაშლა.
- მოდულის admin უფლებების მენეჯერის შექმნა.
- supported_langs.php-ის ნაგულისხმევი ენების გაფართოება.
- მოდულის .tpl ფაილებისა და WHMCS კლიენტის თემების კოდის რედაქტორი, admin თემის გარეშე.
- ~~ამ მოდულის, სხვა მოდულებისა და WHMCS-ის ენის ფაილების რედაქტორის დამატება.~~
- მედია მენეჯერის გაუმჯობესება.
- Yoast SEO-ით შთაგონებული უფრო ეფექტიანი სრული SEO მენეჯერის შექმნა.
- ~~მრავალენოვანი sitemap-ის გენერაციისა და HTML რუკის გვერდის დამატება.~~
- HTML რუკის გვერდის დამატება.
- გვერდების მენეჯერში გამოყენების სტატისტიკის დამატება.
- JS/CSS/HTML მინიფიკაცია, სრული გვერდის cache და მოდულისა და WHMCS-ის ცხრილების ოპტიმიზაცია.
- მოდულის სრულყოფილი განახლების სისტემის შექმნა.

ეს არის **სამომავლო იდეები და არა ფიქსირებული გეგმა**.
