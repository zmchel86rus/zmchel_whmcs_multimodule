# მოდულის პარამეტრები

ჯერ ჩართეთ საჭირო ენები, შემდეგ აირჩიეთ URL-ის ფორმატი და ენების მარშრუტიზაცია, შეინახეთ და შეამოწმეთ საჯარო გვერდები. მარშრუტების ცვლილებისას განაახლეთ Apache წესები Rewrite Manager-ში ან შესაბამისი Nginx კონფიგურაცია. დიდი ცვლილების ან იმპორტის წინ გაიტანეთ მონაცემთა სარეზერვო ასლი.

## ხელმისაწვდომი ჩანართები

- **Import / export:** აირჩიეთ მონაცემები ZIP ასლისთვის ან შემოიტანეთ ZIP და JSON. იმპორტამდე წაიკითხეთ [გადატანის ინსტრუქცია](module_settings_transfer.md).
- **Editable constants:** მოაწესრიგეთ URL, მარშრუტები, გამოსატანი მონაცემები, მედია, ტექნიკური რეჟიმი და Smarty. თითოეული ველის აღწერა წაიკითხეთ და ცვლილება საჯარო გვერდზე შეამოწმეთ.
- **Supported languages:** გვერდების შექმნამდე ჩართეთ ენები. WHMCS-ის ნაგულისხმევი ენა ჩართული დატოვეთ, ვიდრე WHMCS-ში ახალ ნაგულისხმევ ენას არ მიუთითებთ.
- **Redirects და Sitemap:** დააყენეთ შენახული და ავტომატური გადამისამართებები, XML-ის შექმნის განრიგი. ცალკეული ჩანაწერები შესაბამის მენეჯერებში შეცვალეთ.
- **Header, Footer, Robots:** ჩაწერეთ კოდი ან ტექსტი და საბოლოო გვერდი ან robots.txt გადაამოწმეთ.

სერვერის მარშრუტებზე დამოკიდებულ პარამეტრებს შესაბამისი სერვერის წესები სჭირდება. Apache იყენებს .htaccess-ს, Nginx-ს კი საკუთარი კონფიგურაცია ესაჭიროება.
