# ენების მენეჯერი

ენების მენეჯერი WHMCS-ის კლიენტისა და ადმინისტრატორის, ამ მოდულისა და სხვა აღმოჩენილი მოდულების თარგმანებს ცვლის. საჭიროა მოდულის Super Administrator უფლებები და PHP-ს ჩაწერის უფლება შესაბამის დირექტორიებში. სამუშაო მიმდევრობაა Sections → Languages → Translations; თითოეული **Save** ღილაკი მხოლოდ ერთ თარგმანს ინახავს.

## დაწყება

ჯერ Module settings → Supported languages-ში ჩართეთ საჭირო ენები. ეს სია განსაზღვრავს, რომელი ენა შეიძლება დაემატოს და რომელი გამოიყენოს მოდულის გვერდმა. Sections-ში აირჩიეთ WHMCS client, WHMCS admin, ეს ან სხვა აღმოჩენილი მოდული. ცხრილში არსებული, გამორთული და დასამატებელი ენების რაოდენობა ჩანს. ახალი ენა თავიდან საცნობარო ენის სტრიქონებს აჩვენებს; იგი დასრულებული თარგმანი არ არის. საკუთარი თარგმანის გარეშე კატალოგს **Untranslated** ნიშანი აქვს.

## თარგმანების რედაქტირება

**Original** აჩვენებს მხოლოდ არჩეული ენის ორიგინალ ფაილში არსებულ ტექსტს, override ცვლილებების გარეშე. თუ ორიგინალი თარგმანი არ არსებობს, სვეტს **Reference** ეწოდება და საბაზო ენის ტექსტს აჩვენებს. მოძებნეთ გასაღებით ან ტექსტით, გაფილტრეთ ორიგინალი და დამატებული გასაღებები; გრძელ სიას გვერდები აქვს. თითოეული სტრიქონი ცალკე შეინახეთ. საკუთარი გასაღები შეგიძლიათ არჩეულ მშობელთან დაამატოთ, გადაარქვათ სახელი ან წაშალოთ; ორიგინალი გასაღები ასე არ იშლება. არასაიმედო ფორმატის სხვა მოდული მხოლოდ წაკითხვისთვის იხსნება.

## JSON იმპორტი და ექსპორტი

**Export JSON** არჩეული ენის გასაღებებსა და მიმდინარე თარგმანებს ჩამოტვირთავს. მასობრივი ცვლილების წინ ასლი შეინახეთ. **Import JSON** მხოლოდ არსებულ გასაღებებს ანახლებს და ახალს არ ქმნის. განყოფილება, ენა და გასაღების გზა უცვლელი დატოვეთ. უცნობი და დუბლირებული გასაღებები გამოტოვება და შედეგში გამოჩნდება, ვარგისი ჩანაწერები კი იმპორტდება. ატვირთვის ზღვარი 8 MiB-ია.

## ფაილები და სახელები

Languages-ში ენის ფაილის გამორთვა და დაბრუნება შეიძლება; გამორთული ენის თარგმანიც რედაქტირდება. ინგლისური ბაზა და WHMCS-ის მოქმედი ნაგულისხმევი ენა არ ითიშება. მენეჯერის მიერ შექმნილ WHMCS ფაილებს სარეზერვო ასლები აქვთ განახლების შემდეგ აღსადგენად. თუ ძველი ფაილის სახელი გამოვლინდა, Sections-ის საერთო შესწორებაში ნახეთ ახალი სახელი. ნაგულისხმევი ენის შეცვლისას ჯერ ახალი ჩართეთ მოდულში, შემდეგ შეცვალეთ WHMCS-ში და ბოლოს ძველი გამორთეთ.
