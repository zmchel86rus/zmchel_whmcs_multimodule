# Rewrite Manager

## WHMCS

Rewrite Manager ამოწმებს და აყენებს მოდულის Apache წესებს საიტის მთავარ .htaccess ფაილში. აქვე ინახება საკუთარი rewrite წესები. ჩვეულებრივი ერთი URL-დან მეორეზე გადამისამართება ცალკე იმართება [გადამისამართებების მენეჯერში](redirects_manager.md), რადგან ამ ორ მექანიზმს განსხვავებული დანიშნულება აქვს.

## წესების შემოწმება და გამოყენება

გახსენით მენეჯერი და ნახეთ აქტიური ენების მარშრუტების მდგომარეობა. **Add or update rules** მოდულის წესების ბლოკს .htaccess-ში წერს. კიდევ ერთხელ შეამოწმეთ სტატუსი და გახსენით გამოქვეყნებული გვერდი ნაგულისხმევ და მეორე აქტიურ ენაზე. **Remove all rules** არსებობისას მთლიანად წაშლის მოდულის ბლოკს.

საკუთარი წესისთვის მიუთითეთ URL-ის შაბლონი, დანიშნულება და flags, შეინახეთ და ხელახლა გამოიყენეთ წესები. ზედმეტად ფართო შაბლონი სხვა გვერდებსაც შეეხება, ამიტომ გამოყენებამდე გადაამოწმეთ. Apache .htaccess-ს კითხულობს, nginx კი არა. Nginx-ისთვის შესაბამისი წესები სერვერის კონფიგურაციაში ჩაწერეთ და უკვე მოქმედი მისამართებიც გადაამოწმეთ.
