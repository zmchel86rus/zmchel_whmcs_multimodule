# Smarty ბლოკი და ცვლადების კატალოგი

Module settings-ში ჯერ ჩართეთ Smarty ცვლადების შეგროვება და გამოყენება. ZM_PB_COLLECT_VARS კატალოგს ქმნის, ZM_PB_USE_COLLECT_VARS კი ბლოკის გამოსატანად არის საჭირო. მოინახულეთ შესაბამისი საჯარო გვერდები და ხელახლა გახსენით რედაქტორი, რათა ახალი შეთავაზებები გამოჩნდეს.

## კატალოგი

ფაილები თემისა და შაბლონის მიხედვით resources/available_vars/-ში ინახება. ჩაიწერება სახელები, ტიპები, ჩადგმული სტრუქტურა და დაკვირვების ეტაპები, მაგრამ არა რეალური მნიშვნელობები. sampled და truncated აღნიშნავს შეზღუდულ ნიმუშს. პაროლები, token და პირადი მონაცემები redacted ნიშნით იცვლება. კატალოგში ველის არქონა არ ნიშნავს, რომ იგი ყველა მოთხოვნაში აკლია. Getter-ები, მოდელის კავშირები და დამატებითი მონაცემთა ბაზის მოთხოვნები არ სრულდება. დირექტორია .htaccess-ითაა დაცული, თუმცა Nginx-ზეც არ შეიცავს რეალურ მნიშვნელობებს.

## რედაქტორი

ბლოკის ხელსაწყოებიდან დააჭირეთ **Edit code** ან ორჯერ დააწკაპუნეთ Smarty ბლოკს. CodeMirror აჩვენებს კოდს და ცვლადების ძებნას. Ctrl+Space ეძებს, Ctrl+S იყენებს კოდს, F11 ხსნის სრულ ეკრანს, Escape ხურავს. არსებული კოლექციისთვის გამოიყენეთ {foreach $items as $item} და მნიშვნელობა გამოიტანეთ {$item.title|escape} ფორმით. ცარიელი სიის შედეგიც მოამზადეთ და შეამოწმეთ რეალური გვერდი.

## foreach მაგალითი

ამ გვერდზე უკვე არსებულ სიაში გამოიყენეთ {foreach $items as $item} და სათაური გამოიტანეთ {$item.title|escape} ფორმით. ცარიელი სიისთვის შესაბამისი შეტყობინებაც მოამზადეთ. ცვლადების კატალოგი სწორი სახელის პოვნაში გეხმარებათ, მაგრამ სხვა გვერდიდან მონაცემებს არ ტვირთავს.

## შესრულება და შეზღუდვები

კოდი შენახვისას და გამოსატანად გამოყენებამდე მოწმდება. დაშვებულია შეზღუდული if, foreach, ადგილობრივი assign, capture და escape, default, count, date_format მსგავსი modifier. PHP, SQL, ობიექტის მეთოდები, ნებისმიერი ფუნქცია, ფაილის include, ქსელის რესურსები და nofilter აკრძალულია. მნიშვნელობები ავტომატურად escape-დება; განზრახული HTML შაბლონში დაწერეთ. მონაცემის ან შაბლონის შეცდომისას ბლოკი ცარიელი რჩება და შეცდომა PHP log-ში ხვდება. წვდომაშეზღუდული ზონა Smarty-ს შესრულებამდე იშლება.
