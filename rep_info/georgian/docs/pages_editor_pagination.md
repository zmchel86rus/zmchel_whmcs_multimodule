# გვერდებად დაყოფის ბლოკი

1. ბლოკი განათავსეთ სამიზნე სიის წინ ან შემდეგ. ტილოზე აირჩიეთ Smarty ბლოკი ან ელემენტების კონტეინერი; გვერდებად დაყოფა სამიზნის გარეთ უნდა დარჩეს.
2. Smarty-სთვის შეიყვანეთ სრული კოლექციის ცვლადი, მაგალითად $items. შაბლონში ჩვეულებრივი {foreach} შეინარჩუნეთ და მეორე array_slice არ დაამატოთ.
3. მიუთითეთ ელემენტების რაოდენობა და ღილაკები დასაწყისში, ბოლოში და მიმდინარე გვერდის გვერდით, ცალკე კომპიუტერისა და მობილურისთვის. იმავე სიას მეორე მართვის პანელიც შეიძლება ჰქონდეს.

## ბმულები და რამდენიმე სია

თითოეული ბლოკი ირჩევს მოდულის ნაგულისხმევ ფორმას, /page/2/-ს ან ?page=2-ს. გზის ფორმას გამართული rewrite წესები სჭირდება, პირდაპირ PHP მარშრუტზე კი query პარამეტრები გამოიყენება. ბმულები ინარჩუნებს ფილტრებს, დახარისხებას, ინსტალაციის გზასა და ენის პრეფიქსს. პირველი სია იყენებს page, count და sort-ს; შემდეგ სიებს ემატება სამიზნე ბლოკის ID. /page/N/ ფორმაში pager აღნიშნავს, რომელ დამატებით სიას ეკუთვნის ნომერი. მართვის პანელის ასლი ახალ სიას არ ქმნის.

## სიის წყაროები

Smarty ცვლადთან მიბმისას მოდული ანაწილებს მხოლოდ იმ კოლექციას, რომელიც გვერდს უკვე აქვს. სხვა წყაროდან დაკარგულ ჩანაწერებს არ მოიპოვებს. ცვლადის გარეშე არჩეულ კონტეინერში HTML ელემენტებს ყოფს. შეიძლება მიუთითოთ განმეორებადი class ან tr მსგავსი tag; thead და tfoot უცვლელი რჩება. დიდი დინამიკური სიისთვის ცვლადი გამოიყენეთ, რათა ყველა ელემენტის წინასწარი გამოტანა აიცილოთ. Smarty ბლოკი იღებს $zm_pagination-ს ველებით total, page, pages, count, offset. ცარიელ ან ერთგვერდიან სიაში მართვა ქრება.

## მოცულობა, SEO და ფილტრები

შესაძლებელია 10, 25, 50, 100 ან 250 ელემენტის არჩევა. შეცვლა ფილტრებს ინარჩუნებს და მხოლოდ შესაბამის სიას აბრუნებს პირველ გვერდზე. სერვერი count და count_<id>-ს 10–250 ფარგლებში ზღუდავს. შემდეგ გვერდებზე ნომერი ემატება სათაურს, აღწერასა და ბოლო breadcrumb-ს; canonical შესაბამის გვერდზე მიუთითებს. noindex მხოლოდ პირველი გვერდის შემდეგ მოქმედებს. ტექსტური ფილტრი მძიმით გაყოფილ რამდენიმე ველსა და მასივის გასაღებს ამოწმებს. თარიღი იყენებს YYYY-MM-DD-ს და საბოლოო დღეს მთლიანად მოიცავს.

## თარიღი YYYY-MM-DD

ფილტრი იმავე სიაზე მუშაობს, რომელზეც გვერდებად დაყოფა. მისი ჩართვა ან გასუფთავება მხოლოდ ამ სიას აბრუნებს პირველ გვერდზე. გადაამოწმეთ, რომ URL-ში ენა და დახარისხება დარჩა.

## Flex / Grid განლაგება

ველების სიგანე და სვეტები ეკრანის თითოეული ზომისთვის განსაზღვრეთ. რაოდენობის არჩევის ველის სხვა კონტეინერში გადატანისას ბლოკთან კავშირი რჩება. დუბლირებული მართვის ელემენტები საერთო ფილტრსა და მოცულობას იყენებენ.
