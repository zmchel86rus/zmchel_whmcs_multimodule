# საიტის რუკა

## XML

XML აქტიური ენების ორმხრივ ალტერნატიულ URL-ებს და ნაგულისხმევი ენის მისამართისთვის x-default-ს შეიცავს. გადამისამართების საწყისები loc-სა და ენის ალტერნატივებში არ შედის. სარეზერვო შიგთავსი თავის რეალურ ენას ინარჩუნებს. გვერდისა და სტატიის ფაილები XHTML namespace-ს აცხადებენ, რათა URL-ს რამდენიმე ენის ბმული ჰქონდეს.

გენერატორი lib/sitemap.php-შია, დამხმარე ფუნქციები inc/sitemap_manager.php-ში, AfterCronJob hook კი hooks/sitemap.php-ში. ZM_PB_ENABLE_SITEMAP გათიშვისას არც ავტომატური და არც ხელით შექმნა მუშაობს. Cron-ის შემდეგ შეადარება ZM_PB_SITEMAP_LASTUPD და ZM_PB_SITEMAP_UPDFREQ. ცარიელი ან უცნობი სიხშირე ყოველდღიურს ნიშნავს, **Generate** დაუყოვნებლივ მუშაობს. ინახება მხოლოდ ბოლო წარმატებული შექმნის დრო.

საიტის ძირეულ საქაღალდეში იქმნება sitemap_index.xml, sitemap_pages.xml, sitemap_posts.xml. 50,000-ზე მეტი URL ან 50 MB-ზე დიდი კატეგორია დამატებით ფაილებად იყოფა. ინდექსი შეიცავს სხვა ვარგის ძირეულ urlset ფაილებს, მაგრამ არა ჩადგმულ ინდექსებს. მოდული მხოლოდ თავის გვერდისა და სტატიის ფაილებს ცვლის ან შლის. ცარიელ კატეგორიას ფაილი არ ექნება.

შედის მხოლოდ აქტიური, გამოქვეყნებული, საჯაროდ ხელმისაწვდომი გვერდები და სტატიები, რომელთა თარგმანზე lang_active არის ჩართული. WHMCS გვერდის ჩანაცვლება builder-ის slug-ის ნაცვლად თავდაპირველ საჯარო URL-ს იყენებს. ნაგულისხმევი ენის არჩევითი პრეფიქსიც გათვალისწინებულია. საჭიროა ჩაწერა საიტის ძირეულ საქაღალდეში, resources/-სა და inc/editable_consts.php-ში. აკლებული ცხრილები Module database-ში შეაკეთეთ; წარუმატებლობისას ძველი ფაილები აღდგება და წარმატების დრო უცვლელი რჩება.
