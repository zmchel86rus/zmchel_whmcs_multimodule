# გვერდების რედაქტორი

რედაქტორი იხსნება [გვერდების მენეჯერში](pages_manager.md) გვერდის შექმნის შემდეგ. ძირითად პარამეტრებს, შიგთავსს, მეტამონაცემებსა და sitemap-ს ცალკე ჩანართები აქვს. თარგმნილი შიგთავსის შეცვლამდე აირჩიეთ აქტიური ენა. თითოეულ ჩანართს თავისი შენახვა აქვს, **Save all** კი სექციებს ერთად ინახავს. შედეგი საჯარო გვერდზეც შეამოწმეთ.

## ძირითადი პარამეტრები

გადაამოწმეთ შიდა სახელი, slug, ტიპი, გამოქვეყნების სტატუსი, წვდომის რეჟიმი და აქტიური ენები. გამოქვეყნებულ გვერდსაც სჭირდება შიგთავსი იმ ენაზე, რომლითაც უნდა გამოჩნდეს. თუ WHMCS-ის ნაგულისხმევი ენა მოდულში გამორთულია, შენახვამდე მოდულის პარამეტრებში ჩართეთ. დაკარგული URL-ის გამოკვლევისას შესაბამისი თარგმანის აქტიურობაც შეამოწმეთ.

## შიგთავსის პარამეტრები

აირჩიეთ ენა, გადაათრიეთ GrapesJS ბლოკები ტილოზე და მონიშნეთ ბლოკი მისი პარამეტრების შესაცვლელად. ფორმატირებული ტექსტისთვის TinyMCE გამოიყენება. Sections, Columns, Flex და Grid ქმნის განლაგებას. ენის ინსტრუმენტი შიგთავსს ან სტრუქტურას სხვა ენაზე აკოპირებს, მაგრამ კოპირებული ტექსტი მაინც უნდა ითარგმნოს. იხილეთ ცალკე ინსტრუქციები [გვერდებად დაყოფასა და ფილტრებზე](pages_editor_pagination.md), [Smarty-ზე](pages_editor_smarty.md) და [სტრუქტურირებულ მონაცემებზე](module_structured_data.md).

## მეტამონაცემები და sitemap

ყოველ ენაზე ცალკე მიუთითეთ სათაური და აღწერა. საჭიროების მიხედვით გადაამოწმეთ canonical, robots, სოციალური მეტამონაცემები, breadcrumbs და Schema ტიპი. Sitemap ჩანართში გამოქვეყნებული არასისტემური გვერდის განახლების სიხშირე და პრიორიტეტი განისაზღვრება. [Sitemap მენეჯერი](sitemap_manager.md) ქმნის XML ფაილებს; შენახვის შემდეგ საჯარო URL შეამოწმეთ.

## საკონტაქტო ფორმა

დაამატეთ **Contact Form** ბლოკი და აირჩიეთ WHMCS ticket მხარდაჭერის განყოფილებით ან email მიმღებით. დააყენეთ სათაური, აღწერა, თემა, ღილაკი, თითოეული ველის სახელი, ტიპი, აუცილებლობა და ვალიდაცია. სტუმრის ticket-ს სჭირდება გამომგზავნის სახელისა და email-ის როლების მქონე ველები. ჩამოსაშლელ სიაში თითო ვარიანტი ცალკე ხაზზე ჩაწერეთ, თანხმობებისთვის ცალკე ველები შექმენით. გამოიყენეთ WHMCS-ის CAPTCHA. როგორც სტუმარმა, რეალურად გაგზავნეთ საცდელი ფორმა და შეამოწმეთ მიღება. რედაქტორის მწვანე სტატუსი მიწოდებას არ ადასტურებს; თუ PHP mail() ვერ მუშაობს, WHMCS SMTP დააყენეთ.
