# მენიუების მენეჯერი

menu_manager მხარს უჭერს რამდენიმე დამოუკიდებელ მენიუს, გვერდებისა და სტატიების ძებნას, საკუთარ ბმულებსა და სათაურებს # URL-ით. გადაიტანეთ ელემენტები რიგის შესაცვლელად და მიუთითეთ მშობელი ჩადგმისთვის. თითოეულ ელემენტს შეიძლება ჰქონდეს თარგმნილი წარწერა, სათაური, აღწერა, CSS კლასები, rel, ხატულა, ახალ ჩანართში გახსნა და ხილვადობა სტუმრისთვის ან კლიენტისთვის. ახალი გამოქვეყნებული გვერდი შეიძლება ავტომატურად დაემატოს. მენიუ WHMCS-ის ნავიგაციას ცვლის ან აფართოებს კომპიუტერზე, მობილურზე ან ორივეზე.

## ადგილები და ჩამრთველები

WHMCS-ის ClientAreaPrimaryNavbar, ClientAreaSecondaryNavbar, ClientAreaPrimarySidebar და ClientAreaSecondarySidebar შესაბამისი ZM_PB_ENABLE_MAINNAV, ZM_PB_ENABLE_SECONDARYNAV, ZM_PB_ENABLE_MAINSIDEBAR და ZM_PB_ENABLE_SECONDARYSIDEBAR პარამეტრებით იმართება. გამორთული ადგილის დამმუშავებელი არ იტვირთება. აქტიური დანიშვნის გარეშე ორიგინალი WHMCS მენიუ უცვლელია. თითოეულ ადგილს ერთი მენიუ აქვს, მაგრამ იგივე მენიუ რამდენიმე ადგილას შეიძლება იყოს. დაკავებული ადგილის ახალ მენიუზე დანიშვნა ძველ დანიშვნას გადაადგილებს.

## ენები და წვდომა

ჩვეულებრივ WHMCS სისტემურ მარშრუტებზე წარწერებს მომხმარებლის შენახული ენა განსაზღვრავს. მოდულის გვერდებზე URL-ის ენა გამოიყენება და პროფილი არ იცვლება. საკუთარი ბმულის **Link URL language**-ის გათიშვით შეყვანილი URL უცვლელი რჩება, წარწერა კი ითარგმნება. მნიშვნელობა ინახება zm_pb_menu_items.localize_url-ში. გვერდის ელემენტის URL ახლიდან ითვლება slug-ის, გამოქვეყნებული თარგმანებისა და pretty URL პარამეტრების მიხედვით. ჩვეულებრივი ფორმაა ?m=zmchel_whmcs_multimodule&slug=...&lang=.... ცარიელი წარწერა იყენებს breadcrumb-ს, meta title-ს ან გვერდის სახელს. მონახაზი, წაშლილი და მიუწვდომელი გვერდები არ ჩანს. გარე URL, mailto, tel და anchor ენის პრეფიქსს არ იღებს.

## ცხრილები და კოდი

zm_pb_menus ინახავს პარამეტრებს, zm_pb_menu_items იერარქიას, zm_pb_menu_locations ადგილებს. ცხრილების შექმნა და შეკეთება Module database-ში ხდება; მენიუს მენეჯერი მხოლოდ ჩანაწერებს ცვლის. მშობლის წაშლისას შვილები მის დონეზე გადადის. მაქსიმუმ 10 ჩადგმული დონე და 300 ელემენტია; შენახვა ერთ ტრანზაქციაში ხდება. საბოლოო მენიუ გადაამოწმეთ კომპიუტერზე და მობილურზე, როგორც სტუმარმა და კლიენტმა.
