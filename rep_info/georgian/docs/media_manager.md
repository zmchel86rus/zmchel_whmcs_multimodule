# მედიამენეჯერი

მედიათეკა ინახავს ფაილებს, რომლებსაც იყენებენ გვერდის ბლოკები და მოდულის სხვა ნაწილები. აქ შესაძლებელია ფაილის ატვირთვა, უკვე არსებული ჩანაწერის მოძებნა და სურათის ოპტიმიზაცია WHMCS-ის თემის ფაილების ხელით შეცვლის გარეშე.

## ფაილების ატვირთვა და არჩევა

დააჭირეთ **Upload**, აირჩიეთ სურათი, აუდიო, ვიდეო ან PDF და შეავსეთ ხელმისაწვდომი სახელის, სათაურის, აღწერისა და alt ტექსტის ველები. სურათის alt უნდა აღწერდეს მნიშვნელოვან გამოსახულებას და არა უბრალოდ იმეორებდეს ფაილის სახელს. ძებნა და ტიპის ფილტრი დაგეხმარებათ ჩანაწერის პოვნაში; **Load more** აჩვენებს მომდევნო შედეგებს. Image ბლოკში **Choose image**-ით აირჩიეთ მედიათეკის ფაილი და შეინახეთ გვერდი. ატვირთვის შემდეგ შეამოწმეთ საჯარო გვერდზე ფაილის რეალური URL.

## სურათების გამოტანა

მენეჯერი სურათის რამდენიმე ზომას ქმნის. გაუშვით **Optimize image** და გადაამოწმეთ შედეგი, განსაკუთრებით თუ სურათი შეიცავს ტექსტს ან წვრილ ხაზებს. თუ კონკრეტულ სურათს ადაპტური ვარიანტები არ სჭირდება, მისი Image ბლოკის srcset გამორთეთ. ბოლოს საჯარო გვერდზე URL, ზომა და alt ტექსტი გადაამოწმეთ.
