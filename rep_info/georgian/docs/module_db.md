# მოდულის მონაცემთა ბაზა

## WHMCS

Module database გვერდი აჩვენებს მოდულისთვის საჭირო ცხრილებსა და სვეტებს და მათ მიმდინარე მდგომარეობას. მასზე წვდომა მხოლოდ მითითებულ Super Administrator-ს აქვს. გახსენით, როდესაც მოდულის სხვა განყოფილება აკლებული ცხრილის ან სვეტის შესახებ იუწყება; ეს WHMCS-ის მთელი მონაცემთა ბაზის თავისუფალი რედაქტორი არ არის.

ჯერ მდგომარეობის ცხრილი შეამოწმეთ. მონიშნეთ მხოლოდ ის MISSING ელემენტები, რომელთა აღდგენაც გსურთ, შემდეგ დააჭირეთ **Fix Selected items**. გვერდი თავიდან ჩატვირთეთ და გადაამოწმეთ შედეგი. ზოგ აკლებული სვეტისთვის ავტომატური გამოსწორების წესი არ არსებობს; მენეჯერი პრობლემას აჩვენებს, მაგრამ ასეთ სვეტს თვითონ ვერ დაამატებს.

**Delete Selected items** შლის არჩეულ მოდულის მონაცემთა ბაზის ობიექტებს და მოქმედება შეუქცევადია. მანამდე გაიტანეთ მოდულის მონაცემები და შექმენით მონაცემთა ბაზის სარეზერვო ასლი. გაფრთხილების გასაქრობად არ მონიშნოთ შეუსაბამო რიგები. შემდეგ დაუბრუნდით იმ ფუნქციას, რომელმაც თავდაპირველი შეცდომა აჩვენა.
