# Configuració del mòdul

Primer activeu els idiomes necessaris; després trieu el format dels URL i l'encaminament lingüístic i deseu els canvis. Si canvieu les rutes, actualitzeu les regles al Rewrite Manager per a Apache o la configuració equivalent de Nginx. Comproveu una pàgina del mòdul en l'idioma predeterminat i en un altre idioma actiu. Abans de canvis importants o d'importar dades, exporteu una còpia de seguretat.

- [Importació i exportació](module_settings_transfer.md)

## 1. Instal·lació i accés

Activeu el complement a WHMCS i doneu accés als administradors autoritzats. Comproveu les taules necessàries a la base de dades del mòdul. Reviseu els URL amigables, les rutes d'idioma i les ubicacions dels menús. Apache utilitza .htaccess; amb Nginx cal configurar les regles equivalents al servidor.
