# Gestor multimèdia

## Càrrega i selecció d'un fitxer

Feu clic a **Puja un fitxer multimèdia**, trieu una imatge, un fitxer d'àudio, un vídeo o un PDF i empleneu el nom, el text alternatiu, el títol i la descripció quan pertoqui. Per a les imatges, escriviu un text alternatiu descriptiu. Després de pujar-lo, feu servir la cerca i el filtre de tipus; **Carrega'n més** mostra més resultats. Al bloc d'imatge, trieu el fitxer de la biblioteca i deseu la pàgina.

## Presentació de les imatges

El gestor crea diverses mides de cada imatge. Podeu executar **Optimitza la imatge** després de pujar-la; reviseu-ne la qualitat, sobretot si conté text. Si les variants adaptatives no són adequades, desactiveu `srcset` al bloc corresponent. Comproveu l'URL final i el text alternatiu a la pàgina pública.

## Instruccions

- Puja un fitxer multimèdia
- **Nom (intern)**
- **Títol (si escau)**
- **Descripció (si escau)**
- **Atribut alt**
- Cerca per nom
- Tipus de fitxer
- Carrega'n més
- Optimitza la imatge
- S'ha completat l'optimització de la imatge original i de les seves variants.
- Selecciona un fitxer multimèdia
