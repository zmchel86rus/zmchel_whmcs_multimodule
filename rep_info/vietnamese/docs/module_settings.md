# Cài đặt mô-đun

Trước tiên hãy bật các ngôn ngữ cần dùng, sau đó chọn định dạng URL và định tuyến ngôn ngữ rồi lưu cài đặt. Nếu tuyến đường thay đổi, hãy cập nhật quy tắc Apache trong Rewrite Manager hoặc cấu hình Nginx tương ứng. Kiểm tra một trang của mô-đun bằng ngôn ngữ mặc định và một ngôn ngữ đang bật khác. Xuất bản sao lưu trước khi thay đổi lớn hoặc nhập dữ liệu.

## WHMCS

Chọn những ngôn ngữ mà mô-đun được phép sử dụng. Tắt một ngôn ngữ sẽ không xóa nội dung của ngôn ngữ đó.

Nếu sử dụng URL thân thiện trên Apache, hãy cập nhật các quy tắc trong Trình quản lý quy tắc viết lại URL sau khi thay đổi ngôn ngữ.
