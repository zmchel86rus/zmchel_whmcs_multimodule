# Definições do módulo

Primeiro ative os idiomas necessários; depois escolha o formato dos URL e as rotas de idioma e guarde as definições. Se as rotas mudarem, atualize as regras do Apache no Rewrite Manager ou a configuração equivalente do Nginx. Verifique uma página do módulo no idioma predefinido e noutro idioma ativo. Exporte uma cópia de segurança antes de alterações importantes ou de uma importação.

## WHMCS

Escolha os idiomas que o módulo pode utilizar. Desativar um idioma não elimina o seu conteúdo. Se utilizar URLs amigáveis no Apache, atualize as regras no gestor de reescrita depois de alterar os idiomas.
