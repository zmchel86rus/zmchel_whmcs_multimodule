# Base de dados do módulo

## WHMCS

- **Base de dados do módulo:** `MISSING` → Selecionar → Corrigir Itens selecionados.
- **Eliminar Itens selecionados** — Esta ação não pode ser anulada.

A página **Base de dados do módulo** mostra as tabelas e colunas necessárias e o respetivo estado. Só o Superadministrador designado pode aceder-lhe. Abra-a se outra secção indicar que falta uma tabela ou coluna. Verifique a lista, selecione apenas os itens a corrigir e clique em **Corrigir selecionados**. Algumas colunas não têm correção automática; volte a verificar o estado depois da operação.

**Eliminar selecionados** remove definitivamente os objetos escolhidos da base de dados. Antes de eliminar, exporte os dados do módulo e faça uma cópia de segurança da base.
