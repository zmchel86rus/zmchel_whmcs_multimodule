# Configurações do módulo

Primeiro ative os idiomas necessários; depois escolha o formato das URLs e as rotas de idioma e salve as configurações. Se as rotas mudarem, atualize as regras do Apache no Rewrite Manager ou a configuração equivalente do Nginx. Verifique uma página do módulo no idioma padrão e em outro idioma ativo. Exporte um backup antes de grandes mudanças ou de uma importação.

## WHMCS

Escolha os idiomas que o módulo pode usar. Desativar um idioma não exclui seu conteúdo. Se você usa URLs amigáveis no Apache, atualize as regras no gerenciador de reescrita após alterar os idiomas.
