# Banco de Dados do módulo

## WHMCS

- **Banco de Dados do módulo:** `MISSING` → Selecionar → Corrigir Itens selecionados.
- **Excluir Itens selecionados** — Esta ação não pode ser desfeita.

A página **Banco de dados do módulo** mostra as tabelas e colunas necessárias e seu estado. Apenas o Superadministrador designado pode acessá-la. Abra a página se outra seção informar que falta uma tabela ou coluna. Confira a lista, selecione somente os itens que precisam de reparo e clique em **Corrigir selecionados**. Algumas colunas não têm correção automática; confira o estado novamente após a operação.

**Excluir selecionados** remove definitivamente os objetos escolhidos do banco de dados. Antes de excluir, exporte os dados do módulo e faça um backup do banco.
