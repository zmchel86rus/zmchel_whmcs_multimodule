# Менеджер мов

Менеджер мов дає змогу редагувати мовні рядки WHMCS і модулів в адмінці. Функція ще розробляється. Доступ має суперадміністратор модуля; PHP також потрібен дозвіл на запис у відповідні мовні каталоги.

## Вибір розділу й мови

Спершу ввімкніть потрібні мови в **Налаштування модуля → Підтримувані мови**. Потім у **Менеджер мов → Розділи** виберіть клієнтські чи адміністративні мови WHMCS, цей модуль або інший знайдений модуль. Таблиця показує наявні, вимкнені та доступні для додавання мови. На вкладці **Мови** виберіть файл або додайте відсутню мову. Новий файл спочатку використовує тексти мови-референса; це ще не готовий переклад. Позначка «не перекладено» означає, що власних перекладів немає.

## Редагування перекладів

На вкладці **Переклади** колонка **Оригінал** показує текст із початкового файлу вибраної мови без ваших змін. Якщо власного перекладу немає, колонка називається **Референс**. Шукайте за ключем або текстом, фільтруйте всі, оригінальні або додані ключі та зберігайте кожен рядок окремо. Можна додати власний ключ у вибраному розділі, а згодом перейменувати чи видалити його. Деякі каталоги інших модулів доступні лише для перегляду, якщо їхній формат неможливо безпечно зберегти.

**Експорт JSON** завантажує ключі й переклади вибраного розділу та мови. **Імпорт JSON** оновлює лише наявні ключі. Невідомі й повторні ключі пропускаються та перелічуються в результаті. Не змінюйте ідентифікатори розділу й мови або шляхи ключів. Граничний розмір файлу — 8 МіБ.

## Файли та мова за замовчуванням

Мовний файл можна вимкнути й знову ввімкнути; він залишається доступним для редагування й після вимкнення. Базовий англійський файл і поточну мову WHMCS за замовчуванням вимкнути не можна. Для клієнтських та адміністративних мов WHMCS, доданих менеджером, зберігаються копії для відновлення після оновлення. Якщо на вкладці **Розділи** є виправлення назви файлу, перевірте нову назву й натисніть **Виправити**; дія охоплює знайдені розділи.

Щоб змінити мову за замовчуванням, спочатку ввімкніть нову в налаштуваннях модуля, потім змініть мову за замовчуванням у WHMCS і лише після цього вимкніть стару. Перевірте тексти в адмінці та клієнтській частині.
