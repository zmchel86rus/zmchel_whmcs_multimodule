# Карта сайту

## XML

XML містить взаємні посилання для активних мов і `x-default` для адреси мови за замовчуванням. Джерела перенаправлень не потрапляють до `loc` і мовних альтернатив; резервний вміст позначається своєю фактичною мовою. Файли сторінок і записів оголошують простір імен XHTML.

Генератор розміщено в `lib/sitemap.php`, допоміжні функції — у `inc/sitemap_manager.php`, хук `AfterCronJob` — у `hooks/sitemap.php`. Якщо `ZM_PB_ENABLE_SITEMAP` вимкнено, хук не реєструється й ручний запуск також недоступний.

Після кожного cron порівнюються поточний час, `ZM_PB_SITEMAP_LASTUPD` і `ZM_PB_SITEMAP_UPDFREQ`. Порожній або невідомий період означає добу. Час останнього **успішного** створення зберігається в `inc/editable_consts.php`. Кнопка **Створити** в `sitemap_manager` запускає процес одразу.

У корені сайту створюються `sitemap_index.xml`, `sitemap_pages.xml` і `sitemap_posts.xml`. Після 50 000 URL або 50 МБ для категорії додаються файли з `_2`, `_3` тощо. Індекс містить також інші чинні `urlset`-файли кореня, але не вкладає індекси один в один. Модуль змінює лише власні файли сторінок/статей і спільний індекс; чужі файли не чіпає.

Додаються лише активні опубліковані сторінки й статті, доступні без авторизації та з активними мовними версіями. Публікація визначається через `page.status = publish`, мова — через `lang_active`. Редактор не публікує `lang_status`, тому генератор його не перевіряє. Для підміни використовується публічна адреса вихідної системної сторінки, а власний slug макета пропускається. Основна мова має префікс лише за ввімкненого необов’язкового маршруту; інші мови залежать від мовної маршрутизації.

Порожня категорія не створює файлу; окремого спільного `sitemap.xml` генератор не робить. Якщо після оновлення лишився тільки індекс, запустіть генерацію з менеджера. Потрібен запис у корінь сайту, `resources/` модуля та `inc/editable_consts.php`. Відсутні таблиці слід відновити через **Базу даних модуля**. При помилці файли відновлюються з тимчасових копій, а дата останньої успішної генерації не змінюється. Ізольований тест із залежностями проєкту й XML, mbstring, SQLite: `php -d extension=pdo_sqlite tests/sitemap.php`.

## Інструкція

- Автоматичне створення запускається після cron WHMCS, коли настає час оновлення. Ручний запуск починається одразу.
- Додаються активні сторінки та статті, доступні гостям, разом з опублікованими мовними версіями. Для замін використовуються публічні адреси замінюваних сторінок.
- Створити карти сайту
- Файли в корені сайту
- Останнє успішне створення
- Наступне оновлення — не раніше
- Якщо нічого не вибрано, карта сайту оновлюється щодня.
- Якщо ввімкнено, за адресою /html-sitemap показується звичайна HTML-карта сайту; sitemap.xml не змінюється.
- **Частота оновлення** — Якщо не вказано, використовується 'monthly' (щомісяця).
- **Пріоритет оновлення** — Якщо не вказано, використовується '0.5'.
