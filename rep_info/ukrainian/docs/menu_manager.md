# Менеджер меню

У розділі `menu_manager` можна створити кілька незалежних меню, знайти й додати сторінки або статті, власні посилання та пункти-заголовки з адресою `#`. Пункти перетягуються, вкладаються й упорядковуються. Для кожного доступні назва та її переклади, `title`, опис, CSS-класи, `rel`, іконка, нова вкладка й видимість для гостей чи авторизованих користувачів. Нові опубліковані сторінки можна додавати автоматично. Меню доповнює або замінює навігацію WHMCS на комп’ютері, телефоні чи обох.

Після видалення батьківського пункту його дочірні пункти переходять на той самий рівень. Дозволено до 10 рівнів і 300 пунктів. Меню та дерево зберігаються однією транзакцією.

## Розміщення й перемикачі

| Місце WHMCS | Перемикач |
| --- | --- |
| `ClientAreaPrimaryNavbar` | `ZM_PB_ENABLE_MAINNAV` |
| `ClientAreaSecondaryNavbar` | `ZM_PB_ENABLE_SECONDARYNAV` |
| `ClientAreaPrimarySidebar` | `ZM_PB_ENABLE_MAINSIDEBAR` |
| `ClientAreaSecondarySidebar` | `ZM_PB_ENABLE_SECONDARYSIDEBAR` |

Перемикачі є в налаштуваннях модуля. Для вимкненого місця обробник не завантажується й не звертається до БД. Без активного призначення стандартне меню WHMCS не змінюється. Одне місце займає одне меню; те саме меню можна призначити кільком місцям. Нове призначення переносить зайняте місце до нового меню.

Комп’ютерний режим починається від 768 px, мобільний закінчується на 767 px. Якщо заміну ввімкнено лише для одного розміру, інший використовує штатне меню. Стандартні теми WHMCS показують один рівень підменю; ресурси модуля додають глибші рівні navbar. Бічне меню має вкладені списки. Батьківське посилання залишається активним і має окрему кнопку розгортання.

## Мови, адреси й доступ

На системних маршрутах поза `ZM_PB_MAINSYSTEM_DEFAULT_PAGES`, наприклад `clientarea.php`, використовується збережена мова користувача. Відсутність мовного префікса не змінює її; профіль і сесія теж не змінюються. Сторінки модуля та сторінки із заміною використовують мову URL.

Для власного посилання параметр **Мова URL** може залишити адресу на кшталт `/clientarea.php` без змін, тоді як назва й далі перекладається. Параметр зберігається в `zm_pb_menu_items.localize_url` та експортується. На старій інсталяції колонку слід додати через **Базу даних модуля**.

Адреси сторінок під час виведення перераховуються за актуальним slug, налаштуваннями URL і опублікованими перекладами. Мова за замовчуванням не має префікса. Звичайні адреси мають вигляд `?m=zmchel_whmcs_multimodule&slug=...&lang=...` і не змінюють мову профілю. За відсутності перекладу використовується опублікований переклад основною мовою. Порожня назва береться з перекладеного breadcrumb або метазаголовка, потім із назви сторінки. Зовнішні адреси, `mailto:`, `tel:`, якорі й системні ресурси не отримують префікса.

Чернетки, видалені й недоступні сторінки не показуються. Прихований батьківський пункт приховує всю гілку. Небезпечні схеми URL та HTML у назвах відхиляються сервером.

## Таблиці

`zm_pb_menus` містить налаштування, `zm_pb_menu_items` — пункти й дерево, `zm_pb_menu_locations` — призначення. Схема в `inc/menu_schema.php`; створення, відновлення та видалення виконуються через **Базу даних модуля**, а не редактор меню. Під час деактивації таблиці видаляються лише за ввімкненого `db_action`. Виведення: `lib/menu.php`; допоміжний код: `inc/menu_manager.php`; хуки: `hooks/menu.php`. Для перевірки з WHMCS і PDO SQLite: `tests/menu.php` та `tests/menu.php --plain`.
