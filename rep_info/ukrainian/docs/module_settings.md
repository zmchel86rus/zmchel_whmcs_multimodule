# Налаштування модуля

Спочатку увімкніть потрібні мови, потім виберіть формат URL і мовні маршрути та збережіть налаштування. Якщо маршрути змінилися, оновіть правила Apache у Менеджері перезапису або відповідну конфігурацію Nginx. Перевірте сторінку модуля мовою за замовчуванням і ще однією активною мовою. Перед великими змінами або імпортом експортуйте резервну копію.

## WHMCS

Виберіть мови, які може використовувати модуль. Вимкнення мови не видаляє її вміст. Якщо на Apache ввімкнено красиві URL, після зміни мов оновіть правила в менеджері rewrite.
