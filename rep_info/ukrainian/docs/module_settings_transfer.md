# Імпорт та експорт

## JSON

Відкрийте **Налаштування модуля → Імпорт / експорт**. Один JSON-файл (`zmchel_whmcs_multimodule`, версія формату 1) може містити всі або вибрані розділи:

- **Сторінки й статті:** параметри, переклади, вміст GrapesJS, SEO та карта сайту. Згенеровані CSS/JS експортуються як код і під час імпорту створюються з новим ID сторінки.
- **Меню:** вкладеність, переклади назв, місця та налаштування. Сторінки зіставляються за `slug + auth_type`, меню — за назвою. Однакові назви меню на цільовому сайті слід усунути заздалегідь.
- **Налаштування:** редаговані константи, параметри модуля, підміни, header/footer та `robots.txt`. Режим системних URL і дата останньої генерації карти залишаються місцевими.
- **Перенаправлення:** ручні правила й зв’язки автоматичних правил зі сторінками.
- **Rewrite:** власні правила; після імпорту застосуйте їх у менеджері перезапису.
- **Медіа:** лише зареєстровані файли, варіанти розмірів, описи й атрибути, без інших вкладень WHMCS. Конфліктні назви замінюються, посилання в імпортованих даних оновлюються.

Імпорт оновлює збіги, додає нові записи й не чіпає інші. Вибрані розділи, яких немає у файлі, пропускаються. Якщо переносите лише меню чи автоматичні перенаправлення, імпортуйте їхні сторінки заздалегідь або водночас. Адреси початкового сайту змінюються на SystemURL цільового; зовнішні адреси зберігаються. Для перенесення зображень обирайте медіатеку разом зі сторінками.

Розмір JSON обмежено 32 МіБ; діють також `upload_max_filesize` та `post_max_size`. Великий експорт може вимагати більше пам’яті PHP. Ревізії, зібрані Smarty-змінні, облікові записи й секрети WHMCS та файли тем не експортуються. Таблиці БД мають існувати до імпорту.

Перед імпортом показується підтвердження оновлення. Зміни БД відбуваються в транзакції, перезаписані файли відновлюються при помилці. Константи імпортуються тільки повним вибраним набором. На час операції використовується файлове блокування, після успіху вкладка оновлюється. Карту сайту потрібно створити окремо. Перевірка з тимчасовими каталогами й SQLite без робочої БД: `tests/transfer.php`.

## Інструкція

- Один JSON-файл для всіх або вибраних розділів, до 32 МіБ (також діють обмеження завантаження PHP). Сторінки, що збігаються, оновлюються за slug і типом доступу, меню — за назвою. Інші записи зберігаються. Для імпорту меню на новий сайт додайте також сторінки. Вибрані розділи, яких немає у файлі, пропускаються.
- CSS/JS імпортуються разом зі сторінками, зображення та інші завантажені файли — з медіатекою. Історія версій, зібрані змінні Smarty й секрети WHMCS не експортуються. Після імпорту оновіть sitemap; правила rewrite застосовуються через менеджер перезапису.
- Сторінки та статті (переклади, вміст, SEO, налаштування sitemap, блоки CSS/JS)
- Меню та розміщення
- Налаштування модуля, заміни, head/footer, robots.txt
- Перенаправлення
- Власні правила rewrite
- Медіатека (файли й описи)
- Записи вибраних розділів, що збігаються, буде оновлено даними з файлу. Продовжити?
