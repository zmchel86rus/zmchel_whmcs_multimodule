# База даних модуля

## WHMCS

- **База даних модуля:** `MISSING` → Вибрати → Виправити Вибране.
- **Видалити Вибране** — Цю дію неможливо скасувати.

Сторінка **База даних модуля** показує потрібні таблиці та стовпці і їхній стан. Вона доступна лише призначеному суперадміністратору. Відкрийте її, коли інший розділ повідомляє про відсутню таблицю або стовпець. Перегляньте список, виберіть лише елементи для відновлення і натисніть **Виправити вибране**. Деякі стовпці не можна відновити автоматично; після операції перевірте стан ще раз.

**Видалити вибране** безповоротно видаляє вибрані об'єкти бази даних. Перед видаленням експортуйте дані модуля та створіть резервну копію бази.
