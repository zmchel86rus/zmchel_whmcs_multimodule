# Блок пагінації

Розмістіть блок перед списком або після нього. У налаштуваннях натисніть **Вибрати блок на полотні** та вкажіть Smarty-блок або контейнер записів; Esc скасовує вибір. Пагінація має бути поза цільовим блоком. Для Smarty вкажіть змінну повного списку, наприклад `$items`; символ `$` необов’язковий. Залиште звичайний `{foreach}` без додаткового `array_slice`. Кількість елементів і кнопок на початку, в кінці та обабіч поточної сторінки задається окремо для комп’ютера й телефона. За потреби друга панель з’являється з іншого боку того самого списку.

## Посилання й кілька списків

У кожному блоці обирається налаштування модуля (`ZM_PB_PRETTY_URLS`), `/page/2/` або `?page=2`. Для адрес у шляху потрібні дієві rewrite-правила. Прямі PHP-адреси використовують GET-параметри. Посилання зберігають фільтри, сортування, каталог інсталяції та мовний префікс; після зміни формату попередній номер сторінки прибирається.

Перший список використовує `page`, `count`, `sort`; наступні — параметри з ID цільового блока. Для `/page/N/` параметр `pager` визначає, якому додатковому списку належить номер. Копія панелі не створює окремого списку. Поля сортування залежать від вибраного списку; префікс `-` означає спадання. Непідтримувані поля ігноруються.

## Джерела даних

Для прив’язаної Smarty-змінної модуль розбиває на сторінки колекцію, уже доступну на цій сторінці. Незалежні блоки з тією самою змінною отримують власні зрізи в ізольованому контексті. Пагінація не завантажує відсутні записи з іншого джерела.

Без змінної діляться HTML-елементи вибраного контейнера. Можна вказати клас або тег повторюваного запису, наприклад `tr`; `thead` і `tfoot` зберігаються. Для великих списків краще вказати змінну, щоб не виводити весь список до поділу. Пов’язаний Smarty-блок отримує `$zm_pagination` з `total`, `page`, `pages`, `count`, `offset`, наприклад `{$zm_pagination.offset + $v@iteration}`. Для порожнього списку або однієї сторінки панель на сайті приховується.

## Кількість, SEO і фільтри

Додатковий перемикач пропонує 10/25/50/100/250 записів. Його можна перемістити біля кнопок чи в інший контейнер; зміна кількості зберігає фільтри й повертає список на першу сторінку. Сервер обмежує налаштування й `count`/`count_<id>` діапазоном 10–250 до формування вибірки. Починаючи з другої сторінки, номер додається до title, наявного description та останньої крихти; canonical вказує на поточну сторінку. Перемикач **Не індексувати наступні сторінки** додає `noindex` лише до них.

Текстовий фільтр шукає в кількох полях, перелічених через кому. Доступні Flex/Grid, відступи, вирівнювання, положення кнопок та колонки для різних пристроїв. Дати мають формат `YYYY-MM-DD`; верхня межа охоплює весь останній вибраний день. Перевірка з DOM і залежностями WHMCS: `tests/pagination.php`, `tests/pagination.php query`, `tests/smarty_blocks.php`.

## YYYY-MM-DD

Фільтри діють на той самий список, що й пагінація. Текстовий пошук може перевіряти кілька полів, розділених комами; діапазон дат використовує `YYYY-MM-DD` і охоплює весь останній день. Застосування або скидання фільтра повертає список на першу сторінку.

## Flex / Grid

Виберіть Flex або Grid та налаштуйте ширину полів і колонки для різних пристроїв. Селектор кількості можна переміщати, не втрачаючи зв'язку з блоком пагінації. Дубльована панель керує тим самим списком, включно з фільтрами й розміром сторінки.
