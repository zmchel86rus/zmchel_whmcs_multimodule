# Moduldatenbank

## WHMCS

- **Moduldatenbank:** `MISSING` → Auswählen → Reparieren Ausgewählte Elemente.
- **Löschen Ausgewählte Elemente** — Diese Aktion kann nicht rückgängig gemacht werden.

Die Seite **Moduldatenbank** zeigt die benötigten Tabellen und Spalten sowie ihren Status. Nur der festgelegte Superadministrator kann sie aufrufen. Öffnen Sie die Seite, wenn ein anderer Bereich eine fehlende Tabelle oder Spalte meldet. Prüfen Sie die Liste, wählen Sie nur die zu reparierenden Einträge und klicken Sie auf **Ausgewählte reparieren**. Für manche Spalten gibt es keine automatische Reparatur; prüfen Sie den Status anschließend erneut.

**Ausgewählte löschen** entfernt die gewählten Datenbankobjekte unwiderruflich. Exportieren Sie vorher die Moduldaten und erstellen Sie eine Datenbanksicherung.

## Anleitung

- Zugriff verweigert. Nur der Superadministrator (ID …) darf die Moduldatenbank verwalten.
- Reparieren
- Ausgewählte Elemente
- Löschen
- Diese Aktion kann nicht rückgängig gemacht werden.
- Menütabellen wurden noch nicht erstellt. Erstellen Sie sie unter „Moduldatenbank“.
- Fügen Sie zuerst die Spalte optimization_attempted im Tabellenmanager des Moduls hinzu.
