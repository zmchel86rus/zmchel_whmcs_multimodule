# Medienmanager

## Datei hochladen und auswählen

Klicken Sie auf **Mediendatei hochladen**, wählen Sie ein Bild, eine Audio- oder Videodatei oder eine PDF-Datei und füllen Sie bei Bedarf Name, Alternativtext, Titel und Beschreibung aus. Bilder sollten einen aussagekräftigen Alternativtext haben. Nach dem Hochladen helfen Suche und Dateitypfilter beim Auffinden; **Mehr laden** zeigt weitere Treffer. Wählen Sie im Bildblock die Datei aus der Bibliothek und speichern Sie die Seite.

## Bilder ausgeben

Der Medienmanager erzeugt mehrere Bildgrößen. Für ein hochgeladenes Bild können Sie **Bild optimieren** ausführen und danach die Qualität prüfen, besonders bei Bildern mit Text. Wenn die responsiven Varianten ungeeignet sind, schalten Sie `srcset` im betreffenden Block aus. Prüfen Sie die endgültige URL und den Alternativtext auf der öffentlichen Seite.

## Anleitung

- Mediendatei hochladen
- **Name (intern)**
- **Titel (falls zutreffend)**
- **Beschreibung (falls zutreffend)**
- **Alt-Attribut**
- Nach Namen suchen
- Dateityp
- Mehr laden
- Bild optimieren
- Die Optimierung des Originalbilds und seiner Varianten ist abgeschlossen.
- Mediendatei auswählen
