# Moduleinstellungen

Aktivieren Sie zuerst die benötigten Sprachen, wählen Sie dann URL-Format und Sprachrouting und speichern Sie die Einstellungen. Wenn sich Routen ändern, aktualisieren Sie die Apache-Regeln im Rewrite Manager oder die entsprechende Nginx-Konfiguration. Prüfen Sie eine Modulseite in der Standardsprache und einer weiteren aktiven Sprache. Exportieren Sie vor größeren Änderungen oder einem Import eine Sicherung.

## WHMCS

Wählen Sie die Sprachen aus, die das Modul verwenden kann. Beim Deaktivieren bleiben die Inhalte erhalten. Wenn Sie sprechende URLs mit Apache verwenden, aktualisieren Sie nach Sprachänderungen die Regeln im Rewrite Manager.
