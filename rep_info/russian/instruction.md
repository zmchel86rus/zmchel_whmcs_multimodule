# Инструкция по работе с ZMChel WHMCS Multimodule

**ZMChel WHMCS Multimodule — бесплатный модуль** для управления содержимым сайта из админки WHMCS. Он объединяет визуальный редактор страниц и блоков, мультиязычный контент, меню, медиатеку, метаданные SEO, XML-карту сайта, редиректы, rewrite-правила и импорт/экспорт.

## Перед первым использованием

**Перед первым использованием обязательно откройте Настройки модуля → Поддерживаемые языки и включите все необходимые вам языки.**

При каждой активации модуль автоматически генерирует новые соли и записывает их в `module_init.php` (`ZM_PB_ADMIN_SALT`, `ZM_PB_SECURE_SALT`, `ZM_PB_NONCE_SALT`). Рекомендуется проверить, что все три соли заполнены.

## Проверенная совместимость и работоспособность

- **PHP:** 7.4, 8.0, 8.1, 8.2, 8.3, 8.4, 8.5
- **WHMCS:** 8.13 – 9.1
- **Smarty:** 3, 4

## Совместимость с веб-серверами

Apache поддерживается полностью (100%). С Nginx модуль тоже может работать, но языковая маршрутизация на главной странице может потребовать дополнительной настройки и проверки.

## Настройки модуля

Выберите языки, которые может использовать модуль. Отключение языка не удаляет его содержимое.

- **Настройки модуля → Поддерживаемые языки → Включить**
- **База данных модуля → Исправить Выбранное**
- **Правила перезаписи → Проверить правила → Добавить или обновить правила**

Nginx не читает .htaccess: эти правила в нём не работают. Аналогичные правила нужно настроить в конфигурации nginx.

## Менеджер страниц

- **Добавить страницу → Название страницы → Slug страницы → Сохранить**
- **Редактор страниц → Настройки контента → Настройки Meta данных → Настройки страницы для карты сайта → Сохранить все**
- **Менеджер страниц → Посетить**
- **Карта сайта → Сгенерировать карты сайта**

Допускаются только латинские символы, тире и цифры

Для авторизованных: страница доступна только авторизованным пользователям; Для неавторизованных: страница доступна только неавторизованных пользователям; Смешанный: страница доступна всем, ограничения видимости действуют только на контент внутри самой страницы;

Автоматическая генерация запускается после cron WHMCS, когда наступает срок обновления. Ручной запуск не ждёт этого срока.
