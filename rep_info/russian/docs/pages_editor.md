# Редактор страниц

Редактор открывается для страницы, созданной в [Менеджере страниц](pages_manager.md). В нём есть вкладки основных настроек, содержимого, метаданных и карты сайта. Перед редактированием переводимого содержимого выберите язык. У вкладок отдельные кнопки сохранения; **Сохранить всё** сохраняет разделы страницы вместе. После сохранения проверьте публичную страницу.

## Основные настройки

Проверьте название, slug, тип, статус, доступ и выбранные языки. Для опубликованной страницы нужен контент на языке, который вы собираетесь показывать. Если язык по умолчанию в WHMCS не поддерживается, сначала включите его в **Настройках модуля → Поддерживаемые языки**.

## Содержимое

Выберите язык, перетащите блок GrapesJS на холст и нажмите на блок, чтобы изменить его настройки. Обычный текст можно править на месте; для форматированного текста используется TinyMCE. Для раскладки есть секции, колонки, Flex и Grid. Инструменты над редактором позволяют скопировать содержимое, скопировать структуру или клонировать холст в другой язык. После копирования переведите текст, сохраните язык и проверьте результат через **Посетить**.

Для некоторых блоков есть отдельные руководства:

- [Пагинация и фильтры](pages_editor_pagination.md) связываются со списком записей и меняют его результаты при переходе между страницами.
- [Блок Smarty и каталог переменных](pages_editor_smarty.md) требуют соответствующей настройки модуля и допускают только разрешённый синтаксис шаблона.
- [Микроразметка вывода](module_structured_data.md) описывает разметку, которую создают страницы и другие компоненты модуля.

## Метаданные и карта сайта

Во вкладке метаданных задайте заголовок и описание для каждого языка. При необходимости проверьте canonical, robots, социальные метаданные, хлебные крошки и тип Schema. Сохраните каждый язык. Во вкладке карты сайта настройте частоту изменения и приоритет опубликованной несистемной страницы. Итоговые URL и XML-файлы видны в [Менеджере карты сайта](sitemap_manager.md).

## Контактная форма

Добавьте блок **Контактная форма**. Выберите отправку **тикета WHMCS** в отдел поддержки или **письма** указанному получателю; заполните заголовок, описание, тему и текст кнопки. Для каждого поля задайте имя, тип, обязательность и проверку. Гостевому тикету нужны поля с ролями имени и адреса отправителя. В выпадающем списке указывайте по одному варианту в строке, например `sales : Продажи`. Для отдельных согласий создайте отдельные поля, настройте расположение и CAPTCHA из WHMCS. Сохраните форму и отправьте настоящий тестовый запрос как гость: проверьте тикет или доставку письма, ошибки и очистку формы. Зелёная отметка редактора не подтверждает доставку; если `mail()` не работает, настройте SMTP в WHMCS.

## Инструкция

- Вложенный контейнер с flex-раскладкой. Перетащите внутрь другие блоки.
- Вложенный контейнер с CSS Grid раскладкой. Перетащите внутрь другие блоки.
- Вложенный контейнер-карусель (Bootstrap). Перетащите внутрь блоки — каждый станет слайдом.
- Все блоки ниже данного блока - будут выводиться только для авторизованных пользователей. Работает только для смешанного "Тип авторизации" страницы
- Все блоки ниже данного блока - будут выводиться только для неавторизованных пользователей. Работает только для смешанного "Тип авторизации" страницы
- **Заголовок страницы (Title)**
- **Мета описание страницы**
- **Канонический URL**
- **Robots** — index, follow / noindex, nofollow. Нужно для управления индексацией.
- **Тип Schema** — Если выключено, json схемы по разметке Schema.org не выводятся для страницы
