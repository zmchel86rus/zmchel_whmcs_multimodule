# Менеджер страниц

Здесь находятся страницы, созданные модулем. В менеджере можно добавить страницу, найти существующую, изменить её статус или назначить её содержимое для страницы WHMCS. Контент и метаданные редактируются отдельно в [Редакторе страниц](pages_editor.md).

## Создание страницы

Откройте **Добавить страницу**. Укажите внутреннее название и slug, например `about-us`, без домена и языкового префикса. Выберите доступ (**Смешанный**, **Для авторизованных** или **Для неавторизованных**) и тип (**Страница**, **Статья** или **Системная страница**). Отметьте нужные языки. Язык по умолчанию в WHMCS должен быть включён в **Настройках модуля → Поддерживаемые языки**. Сохраните страницу и откройте её в редакторе, чтобы добавить содержимое и метаданные. Черновик не виден посетителям; публикуйте страницу после проверки.

## Поиск, просмотр и удаление

Список можно фильтровать по названию, доступу, типу, статусу и языку. Кнопка **Посетить** открывает публичный адрес. **Удалить** сначала перемещает страницу в корзину; окончательное удаление доступно в корзине. Если публичная страница не открывается, проверьте её статус и язык.

## Подмены страниц WHMCS

Во вкладке подмен выберите существующую страницу WHMCS и опубликованную страницу модуля. Тип подмены определяет, будет ли содержимое заменено целиком, добавлено до или после штатного содержимого, затронет только метаданные либо совместит эти действия. Сохраните и проверьте исходный публичный адрес WHMCS как гость и как авторизованный клиент. Если внутренний slug отличается, он может перенаправлять на исходный адрес.

## Инструкция

- Добавить страницу
- **Название страницы** — Системное название страницы
- **Slug страницы** — Допускаются только латинские символы, тире и цифры
- **Тип авторизации** — Для авторизованных: страница доступна только авторизованным пользователям; Для неавторизованных: страница доступна только неавторизованных пользователям; Смешанный: страница доступна всем, ограничения видимости действуют только на контент внутри самой страницы;
- **Тип страницы** — Системная страница не учитывается в карте сайта и недоступна обычным пользователям
- **Поддерживаемые языки страницы** — Язык "по умолчанию" вносится всегда, независимо от выбора.
- Полное переопределение - замена выводимого содержимого (контент, метаданные) Добавление (до) - вывод содержимого перед уже определенным содержимым страницы Добавление (после) - вывод содержимого после уже определенного содержимого страницы Только мета/SEO данные - вывод мета/SEO содержимого вместо уже определенных для страницы
- Страницы списка
