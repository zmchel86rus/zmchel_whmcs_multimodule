# Блок Smarty и каталог переменных

`ZM_PB_COLLECT_VARS` включает сбор каталога; `ZM_PB_USE_COLLECT_VARS === true`
включает блок Smarty и его вывод. После включения коллектора откройте нужные
страницы сайта, затем перезагрузите редактор страницы.

## Каталог

Файлы: `resources/available_vars/<тема>__<шаблон>_smarty_vars.json`.
Каталог содержит имена, типы, вложенную структуру, искусственные примеры
и этапы, на которых переменная наблюдалась:

- `ClientAreaPage:9999`;
- `ClientAreaHeadOutput:9999`;
- `ClientAreaFooterOutput:9999`.

Это этап доступности, а не доказательство, какой хук создал переменную.
Типы и структура объединяются при следующих посещениях страницы.
`children.[]` описывает элемент списка. Читаются несколько элементов,
глубина и объём каталога ограничены; соответствующие узлы помечены
`sampled` / `truncated`. Отсутствие поля в каталоге не доказывает его отсутствие
во всех запросах.

Реальные значения не сохраняются вообще. Поля с паролями, токенами,
персональными данными дополнительно помечаются `redacted`. Для коллекций
и моделей читаются только уже загруженные `items` / `attributes`, без
сериализации, геттеров, связей и запросов. Другие объекты непрозрачны.
Старые JSON-дампы обезличиваются при следующем сборе. Старые вложенные
каталоги не показываются в редакторе: для подсказок посетите страницу заново.
Каталог защищён `.htaccess`; значения отсутствуют и на серверах, которые
не поддерживают `.htaccess`.

## Редактор

Кнопка «Редактировать код» в верхней панели настроек блока или двойной клик
по блоку Smarty открывает CodeMirror внутри GrapesJS.
Код находится сверху, сведения о выбранной переменной — под ним; обе области
занимают половину высоты. Справа можно выбрать тему/шаблон и найти переменную.
Кнопка вставки для коллекции создаёт заготовку `foreach`, для скаляра — выражение.

- `Ctrl+Space`: поиск переменных;
- `Ctrl+S` / `Cmd+S`: применить код к блоку;
- `F11`: полный экран;
- `Escape`: выйти из полного экрана / закрыть без применения.

Пример для уже загруженной коллекции:

```smarty
{foreach $registered_domains as $item}
    <div class="domain">{$item.domain|escape}</div>
{foreachelse}
    <p>Нет доменов.</p>
{/foreach}
```

## Выполнение

Код компилируется и проверяется на сервере при сохранении и перед выводом.
Изолированный Smarty получает снимок уже определённых переменных в виде
массивов и скаляров. Методы моделей и коллекций недоступны; используйте
`foreach`, доступ к полям массива и `count`.

Разрешены условия, `foreach`, локальный `assign`, `capture`, `literal`,
`strip`, `break` / `continue` и ограниченный набор модификаторов
(`escape`, `default`, `count`, `nl2br`, `upper`, `lower`, `capitalize`,
`truncate`, `replace`, `cat`, `date_format`).

PHP, статические обращения, методы объектов, произвольные функции,
SQL/плагины WHMCS, подключения файлов, сетевые ресурсы, глобальный `assign`,
суперглобальные переменные и `nofilter` запрещены. Значения при выводе
экранируются автоматически; HTML-разметку пишите непосредственно в шаблоне.
Секретные и персональные поля исключаются также из снимка для рендера.

Блоки разрешаются в `ClientAreaFooterOutput:10000`, затем
[фильтр результата Smarty](https://www.smarty.net/docs/en/api.register.filter.tpl)
помещает результат на исходное место в HTML до формирования HTTP-ответа.
Отдельно загружаемые шаблоны используют также уже определённые переменные
своего контекста. Общий буфер вывода не создаётся и данные в него не выводятся.
Запрещённые
авторизацией зоны удаляются до постановки Smarty-блоков в очередь.
Если нужные данные отсутствуют или шаблон падает, блок остаётся пустым,
внутренний маркер не выводится; ошибка или предупреждение шаблона записывается
в PHP error log и не становится частью HTML страницы.

Каталог не является источником данных. Он не делает переменные другой
страницы доступными на текущей. При полной подмене страницы переменные,
которые создаёт только её штатный контроллер, могут отсутствовать.

Нужны зависимости проекта и PHP с расширениями WHMCS. Проверка использует
