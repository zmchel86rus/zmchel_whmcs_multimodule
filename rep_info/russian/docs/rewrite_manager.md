# Менеджер правил перезаписи

## WHMCS

Менеджер проверяет и устанавливает правила Apache в основной `.htaccess` сайта. Здесь же добавляются пользовательские правила перезаписи. Редиректы с одного URL на другой настраиваются отдельно в [Менеджере редиректов](redirects_manager.md).

## Проверка и применение

Откройте менеджер и проверьте состояние правил для языковых маршрутов. Кнопка **Добавить или обновить правила** записывает блок модуля в `.htaccess`. Проверьте состояние повторно и откройте опубликованную страницу на языке по умолчанию и ещё на одном языке. Кнопка удаления всего блока правил доступна, когда блок найден.

Для своего правила заполните шаблон URL, назначение и флаги, сохраните правило, затем снова примените правила. Проверьте шаблон перед применением: слишком широкий шаблон может затронуть другие страницы. Apache читает `.htaccess`; для Nginx нужна соответствующая настройка сервера.
