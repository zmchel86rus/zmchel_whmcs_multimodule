# Карта сайта

Генератор находится в `lib/sitemap.php`, вспомогательные функции — в `inc/sitemap_manager.php`. Хук `AfterCronJob` зарегистрирован в `hooks/sitemap.php` и подключается из `hooks.php`. Когда `ZM_PB_ENABLE_SITEMAP` выключен, хук не регистрируется и генерация, включая ручной запуск, недоступна.

После каждого запуска cron хук сравнивает текущее время с `ZM_PB_SITEMAP_LASTUPD` и периодом `ZM_PB_SITEMAP_UPDFREQ`. Пустой или неизвестный период означает сутки. Время последней **успешной** генерации сохраняется в `inc/editable_consts.php`. Кнопка «Сгенерировать» на странице `sitemap_manager` запускает генерацию сразу, без ожидания очередного периода.

В корне сайта создаются `sitemap_index.xml`, `sitemap_pages.xml`, `sitemap_posts.xml`. Если категория превышает 50 000 URL или 50 МБ, появляются дополнительные файлы с суффиксом `_2`, `_3` и так далее. Индекс включает также другие корректные sitemap-файлы формата `urlset` из корня, но не вкладывает индексы друг в друга. Модуль обновляет и удаляет только собственные файлы страниц и статей, а также обновляет общий `sitemap_index.xml`; остальные файлы не меняются.

В карту попадают активные опубликованные страницы и статьи с активными языковыми версиями, доступные без авторизации. Публикация определяется через `page.status = publish`, доступность языка — через `lang_active`, как и при выводе страницы. Поле `lang_status` редактор не публикует, поэтому генератор его не проверяет. Для страницы-переопределения публикуется URL исходной системной страницы, а slug самой страницы-переопределения пропускается. URL для языка по умолчанию идёт без языкового префикса; остальные языки зависят от языковой маршрутизации.

Если после обновления остался только индекс, запустите генерацию кнопкой в менеджере карты сайта. Файлы с адресами называются `sitemap_pages.xml` и `sitemap_posts.xml`; отдельный общий `sitemap.xml` этот генератор не создаёт. Пустая категория не создаёт файл.

Генерация требует записи в корень сайта, `resources/` модуля и `inc/editable_consts.php`. Если нужных таблиц нет, менеджер показывает ссылку на `module_db`; сам генератор таблицы не создаёт и не исправляет. При ошибке файлы восстанавливаются из временных копий, дата последней успешной генерации остаётся прежней.

Проверка без WHMCS: `php -d extension=pdo_sqlite tests/sitemap.php` (нужны установленные зависимости проекта и расширения XML, mbstring, SQLite). Тест использует отдельный временный корень и базу SQLite в памяти.
