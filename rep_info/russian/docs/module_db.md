# База данных модуля

## WHMCS

- **База данных модуля:** `MISSING` → Выбрать → Исправить Выбранное.
- **Удалить Выбранное** — Данное действие необратимо.

Страница показывает необходимые таблицы и столбцы модуля и их текущее состояние. Она доступна назначенному суперадминистратору. Откройте её, если другой раздел сообщает об отсутствующей таблице или колонке.

Сначала проверьте таблицу состояния. Выберите только те отсутствующие элементы, которые нужно восстановить, и нажмите **Исправить выбранное**. Для некоторых колонок автоматический способ восстановления не предусмотрен — это видно в таблице. После операции перезагрузите страницу и проверьте результат.

На странице также есть **Удалить выбранное**. Эта операция удаляет выбранные объекты базы данных модуля и необратима; перед ней выгрузите данные модуля и сделайте резервную копию базы. Не отмечайте другие строки только ради того, чтобы убрать предупреждение.

## Инструкция

- Доступ запрещен. Страница Базы данных модуля доступна только Супер Администратору (ID …).
- Исправить
- Выбранное
- Удалить
- Данное действие необратимо.
- Таблицы меню ещё не созданы. Добавьте их в разделе «База данных модуля».
- Сначала добавьте столбец optimization_attempted через менеджер таблиц модуля.
