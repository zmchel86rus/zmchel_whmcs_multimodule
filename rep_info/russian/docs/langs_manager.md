# Менеджер языков

- **Разделы → Языки → Переводы.** Каждая кнопка сохраняет только один перевод.

Менеджер языков помогает редактировать языковые строки WHMCS и модулей из админки. Функция находится в разработке. Работать с ней может суперадминистратор модуля; при изменении файлов у PHP должны быть права на запись в соответствующие каталоги.

## С чего начать

1. В **Настройках модуля → Поддерживаемые языки** включите нужные языки. Этот список определяет, какие языки можно добавить в менеджере и использовать для страниц модуля. Сам менеджер не включает язык в настройках модуля автоматически.
2. Откройте **Менеджер языков → Разделы**. Выберите языковые файлы клиентской или админской части WHMCS, самого модуля либо другого найденного модуля. Таблица показывает, сколько языков есть в разделе, сколько отключено и сколько ещё можно добавить.
3. На вкладке **Языки** выберите существующий язык или нажмите **Добавить** рядом с доступным. Добавленный язык сначала получает строки из языка-референса. Это не готовый перевод: новые строки нужно заполнить самостоятельно. Пометка **Не переведено** показывает каталог без собственных переводов.

## Редактирование переводов

Откройте язык на вкладке **Переводы**. Таблица показывает путь к ключу, источник и редактируемый перевод. **Оригинал** — строки, которые действительно есть в исходном файле выбранного языка, без ваших override-правок. Если у нового языка своего перевода ещё нет, колонка называется **Референс** и показывает текст базового языка. Пустое поле перевода в таком каталоге означает, что пока используется референс.

Найдите строку поиском по ключу или тексту, при необходимости выберите **Показать все**, **Показать оригинальные** или **Показать добавленные**. Длинный список разбит на страницы. Измените текст и нажмите **Сохранить** в этой строке: каждый перевод сохраняется отдельно. Если очистить перевод у языка, созданного менеджером, снова будет использоваться текст референса.

Чтобы добавить собственный ключ, выберите родительский раздел в поле **Внутри**, введите имя ключа и перевод, затем нажмите **Добавить**. Добавленный таким образом ключ можно переименовать или удалить рядом с его строкой. Исходные ключи удалять этим способом нельзя. Некоторые каталоги сторонних модулей доступны только для просмотра, если менеджер не может безопасно сохранять их формат.

## Экспорт и импорт JSON

Кнопка **Экспорт JSON** выгружает ключи и текущие переводы выбранного раздела и языка. Сохраните файл перед массовой правкой. После изменения значений загрузите его через **Импорт JSON**. Импорт обновляет только уже существующие ключи: новые ключи через него не создаются. Не меняйте в файле идентификаторы раздела и языка или пути к ключам. Неизвестные и повторяющиеся ключи пропускаются и перечисляются в сообщении о результате; остальные подходящие строки импортируются. Максимальный размер загружаемого файла — 8 МиБ.

## Включение языков и исправление имён файлов

На вкладке **Языки** можно выключить языковой файл раздела или включить его обратно. Выключенный язык остаётся доступен для редактирования. Английский базовый файл и текущий язык WHMCS по умолчанию выключить нельзя. Для добавленных в WHMCS клиентских и админских языков менеджер хранит служебные копии, чтобы восстановить их после обновления WHMCS.

Если менеджер обнаружил старое имя файла, на вкладке **Разделы** появится общий селектор исправления. Проверьте показанное новое имя и нажмите **Исправить**. Исправление применяется к найденным разделам и спискам языков модуля; совместимые старые имена продолжают поддерживаться.

Чтобы сменить язык по умолчанию, сначала включите новый язык в **Настройках модуля → Поддерживаемые языки**, затем смените язык по умолчанию в WHMCS. После этого можно выключить старый язык. Если перевод ещё пуст, интерфейс будет показывать строки референса, поэтому проверьте админку и клиентскую часть перед использованием нового языка.
