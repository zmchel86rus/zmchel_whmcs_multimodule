# Менеджер медиафайлов

Менеджер хранит файлы, которые используются в блоках страниц и другом содержимом модуля. Здесь можно загрузить файл, найти уже добавленный или оптимизировать изображение.

## Загрузка и выбор файла

Нажмите **Загрузить**, выберите изображение, аудио, видео или PDF и заполните доступные поля названия, alt, заголовка и описания. Для изображений укажите осмысленный alt. После загрузки используйте поиск и фильтр типа; кнопка **Загрузить ещё** показывает следующие результаты. В блоке «Изображение» нажмите **Выбрать изображение**, укажите файл из библиотеки и сохраните страницу.

## Вывод изображений

Менеджер создаёт несколько размеров изображения. Для загруженного изображения можно запустить **Оптимизировать изображение** и затем проверить качество, особенно если на нём есть текст. Если адаптивные варианты не подходят конкретному изображению, отключите `srcset` в его блоке. Проверьте итоговый URL и alt на публичной странице.

## Инструкция

- Загрузить медиафайл
- **Название (системное)**
- **Заголовок (если применим)**
- **Описание (если применимо)**
- **Атрибут Alt**
- Поиск по названию
- Тип файла
- Загрузить ещё
- Оптимизировать изображение
- Оптимизация исходного изображения и его вариантов завершена.
- Выбрать медиафайл
