# Настройки модуля

Здесь задаётся поведение модуля для всего сайта. Откройте нужную вкладку, измените параметры, сохраните их и проверьте страницу, которая использует эту возможность.

## Вкладки

- **Импорт / экспорт:** выгрузка выбранных данных модуля в JSON и их загрузка. Перед импортом прочитайте [руководство по импорту и экспорту](module_settings_transfer.md).
- **Редактируемые константы:** настройки URL, маршрутизации, вывода, медиафайлов, режима обслуживания, Smarty и других доступных функций. Ориентируйтесь на описание конкретного поля и проверяйте публичный результат после сохранения.
- **Поддерживаемые языки:** включите нужные языки перед созданием страниц. Язык по умолчанию в WHMCS должен оставаться включённым; прежде чем выключать старый, смените язык по умолчанию в WHMCS.
- **Редиректы:** настройки хранимых правил и автоматических перенаправлений после изменения slug опубликованной страницы. Отдельные правила находятся в [Менеджере редиректов](redirects_manager.md).
- **Карта сайта:** включение генерации и её расписание. Файлы и адреса проверяйте в [Менеджере карты сайта](sitemap_manager.md).
- **Header**, **Footer** и **Robots:** содержимое, добавляемое в шапку и подвал сайта, и настройки `robots.txt`. После сохранения проверьте получившуюся страницу или файл.

Для маршрутизации нужны соответствующие правила сервера. На Apache установите правила через [Менеджер правил перезаписи](rewrite_manager.md). Nginx требует собственной конфигурации маршрутов.

## Инструкция

- Выберите языки, которые может использовать модуль. Отключение языка не удаляет его содержимое.
- Если на Apache включены красивые URL, после изменения языков обновите правила в менеджере rewrite.
- **Красивые ссылки** — Включает режим ЧПУ, включая системные ссылки
- **Языковая маршрутизация** — Включает/выключает языковую маршрутизацию. Если включено - страницы становятся доступны по адресам /(de/en/es)/ (и прочим поддерживаемым языкам). Если выключено - доступен только один адрес страницы, который отдает язык страницы в зависимости от настройки пользователя (из поддерживаемых)
- **Маршрут языка по умолчанию** — Добавляет языку по умолчанию свой префикс и перенаправляет страницы модуля без префикса на него.
- **Режим профилактики (модуль)** — Включает/выключает режим профилактики модуля. Режим профилактики модуля делает более мягкий режим профилактики (системный не дает выполняется хукам и многому другому)
- **Сбор Smarty переменных** — Включает/выключает сбор Smarty переменных.
- **Использование Smarty переменных** — Включает/выключает использование Smarty переменных в редакторе страниц.
- **Переопределение страниц** — Включает/выключает переопределение страниц.
- **Частота обновлений** — Если ничего не выбрано - обновление происходит раз в день
- **HTML карта сайта** — Если включено, по адресу /html-sitemap будет выдаваться карта сайта как обычная HTML страница (sitemap.xml не затрагивается)
- **Шапка сайта** — Произвольный HTML-код для секции <head> (включая <script> и <style>)
- **Подвал сайта** — Произвольный HTML-код перед </body> (включая <script> и <style>)
- **Редактирование Robots.txt**
