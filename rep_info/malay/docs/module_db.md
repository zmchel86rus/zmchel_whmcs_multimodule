# Pangkalan data modul

## WHMCS

- **Pangkalan data modul:** `MISSING` → Pilih → Baiki Item terpilih.
- **Padam Item terpilih** — Tindakan ini tidak boleh dibuat asal.

Halaman **Pangkalan data modul** menunjukkan jadual dan lajur yang diperlukan serta statusnya. Hanya Super Pentadbir yang ditetapkan boleh mengaksesnya. Buka halaman ini jika bahagian lain melaporkan jadual atau lajur yang hilang. Semak senarai, pilih hanya item yang perlu dibaiki, kemudian klik **Baiki yang dipilih**. Sesetengah lajur tidak boleh dibaiki secara automatik; semak status semula selepas tindakan.

**Padam yang dipilih** membuang objek pangkalan data terpilih secara kekal. Eksport data modul dan buat sandaran pangkalan data sebelum memadam.

- Akses ditolak. Hanya Pentadbir Super (ID …) boleh menggunakan halaman Pangkalan Data modul.

- Tambah lajur optimization_attempted terlebih dahulu melalui pengurus jadual modul.
