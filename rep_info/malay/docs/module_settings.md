# Tetapan modul

Aktifkan bahasa yang diperlukan dahulu, kemudian pilih format URL dan penghalaan bahasa serta simpan tetapan. Jika laluan berubah, kemas kini peraturan Apache dalam Rewrite Manager atau konfigurasi Nginx yang sepadan. Semak halaman modul dalam bahasa lalai dan satu lagi bahasa aktif. Eksport sandaran sebelum perubahan besar atau import data.

## WHMCS

Pilih bahasa yang boleh digunakan oleh modul. Menyahaktifkan bahasa tidak akan memadam kandungannya. Jika anda menggunakan URL mesra pengguna pada Apache, kemas kini peraturan melalui Pengurus Tulis Semula selepas menukar bahasa.
