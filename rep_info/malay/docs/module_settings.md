# Tetapan modul

## WHMCS

Pilih bahasa yang boleh digunakan oleh modul. Menyahaktifkan bahasa tidak akan memadam kandungannya. Jika anda menggunakan URL mesra pengguna pada Apache, kemas kini peraturan melalui Pengurus Tulis Semula selepas menukar bahasa.

- [pemindahan data](module_settings_transfer.md)

## Arahan

- **URL mesra pengguna** — Aktifkan URL mesra pengguna, termasuk URL sistem.
- **Penghalaan bahasa** — Aktifkan atau nyahaktifkan laluan bahasa. Apabila diaktifkan, halaman tersedia di bawah /de/, /en/, /es/ dan awalan bahasa lain yang disokong. Apabila dinyahaktifkan, satu URL halaman memaparkan kandungan dalam bahasa pilihan pengguna.
- **Laluan untuk bahasa lalai** — Berikan bahasa lalai awalan URL tersendiri dan alihkan halaman modul tanpa awalan kepadanya.
- **Mod penyelenggaraan (modul)** — Aktifkan atau nyahaktifkan mod penyelenggaraan modul. Mod yang lebih ringan ini membenarkan cangkuk WHMCS dan komponen lain terus berfungsi, tidak seperti mod penyelenggaraan sistem.
- **Kumpul pemboleh ubah Smarty** — Aktifkan atau nyahaktifkan pengumpulan pemboleh ubah Smarty.
- **Gunakan pemboleh ubah Smarty yang dikumpulkan** — Aktifkan atau nyahaktifkan penggunaan pemboleh ubah Smarty yang dikumpulkan dalam penyunting halaman.
- **Penggantian halaman** — Aktifkan atau nyahaktifkan penggantian halaman.
- **Kekerapan kemas kini** — Jika tiada pilihan dibuat, peta laman dikemas kini setiap hari.
- **Peta laman HTML** — Apabila diaktifkan, /html-sitemap memaparkan peta laman sebagai halaman HTML biasa; sitemap.xml tidak terjejas.
- **Pengepala laman web** — HTML tersuai untuk bahagian <head>, termasuk <script> dan <style>.
- **Pengaki laman web** — HTML tersuai sebelum </body>, termasuk <script> dan <style>.
- **Sunting robots.txt**
