# Stillingar einingar

Virkjaðu fyrst tungumálin sem þú þarft, veldu síðan snið vefslóða og tungumálaleiðir og vistaðu stillingarnar. Ef leiðirnar breytast skaltu uppfæra Apache-reglurnar í Rewrite Manager eða samsvarandi Nginx-stillingar. Prófaðu síðu einingarinnar á sjálfgefna tungumálinu og öðru virku tungumáli. Flyttu út öryggisafrit áður en þú gerir stórar breytingar eða flytur inn gögn.

## WHMCS

Veldu hvaða tungumál einingin má nota. Ef tungumál er gert óvirkt eyðist efni þess ekki. Ef þú notar snyrtilegar vefslóðir á Apache skaltu uppfæra reglurnar í Umsjón með endurskrifunarreglum eftir að tungumálum er breytt.
