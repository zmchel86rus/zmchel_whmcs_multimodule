# Stillingar einingar

## WHMCS

Veldu hvaða tungumál einingin má nota. Ef tungumál er gert óvirkt eyðist efni þess ekki. Ef þú notar snyrtilegar vefslóðir á Apache skaltu uppfæra reglurnar í Umsjón með endurskrifunarreglum eftir að tungumálum er breytt.

- [gagnaflutningur](module_settings_transfer.md)

## Leiðbeiningar

- **Snyrtilegar vefslóðir** — Virkjar snyrtilegar vefslóðir, þar á meðal kerfisvefslóðir.
- **Tungumálastýring vefslóða** — Virkja eða óvirkja tungumálaleiðir. Þegar þær eru virkar eru síður aðgengilegar undir /de/, /en/, /es/ og öðrum studdum tungumálaforskeytum. Þegar þær eru óvirkar sýnir ein vefslóð síðuna á því tungumáli sem notandinn hefur valið.
- **Leið fyrir sjálfgefið tungumál** — Gefðu sjálfgefna tungumálinu eigið vefslóðarforskeyti og endurbeindu síðum einingarinnar án forskeytis þangað.
- **Viðhaldsstilling (eining)** — Virkja eða óvirkja viðhaldsstillingu einingarinnar. Þessi vægari stilling leyfir WHMCS-krókum og öðrum hlutum að keyra, ólíkt viðhaldsstillingu kerfisins.
- **Safna Smarty-breytum** — Virkja eða óvirkja söfnun Smarty-breyta.
- **Nota safnaðar Smarty-breytur** — Virkja eða óvirkja notkun safnaðra Smarty-breyta í síðaritlinum.
- **Yfirskrifanir síðna** — Virkja eða óvirkja yfirskrifanir síðna.
- **Tíðni uppfærslna** — Ef ekkert er valið er vefkortið uppfært daglega.
- **HTML-vefkort** — Þegar þetta er virkt sýnir /html-sitemap vefkortið sem venjulega HTML-síðu; sitemap.xml helst óbreytt.
- **Haus vefs** — Sérsniðið HTML fyrir <head>-hlutann, þar á meðal <script> og <style>.
- **Fótur vefs** — Sérsniðið HTML á undan </body>, þar á meðal <script> og <style>.
- **Breyta robots.txt**
