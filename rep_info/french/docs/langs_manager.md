# Gestionnaire de langues

- **Sections → Langues → Traductions.** Chaque bouton Enregistrer ne sauvegarde qu'une traduction.

## Choisir une section et une langue

Activez d'abord les langues nécessaires dans les paramètres du module. Dans **Sections**, choisissez les langues de l'espace client ou de l'administration WHMCS, ce module ou un autre module. Dans **Langues**, choisissez un fichier existant ou ajoutez une langue. Un nouveau fichier affiche les textes de la langue de référence tant que vous n'avez pas saisi ses traductions.

## Modifier les traductions

Dans **Traductions**, la colonne **Original** montre le texte du fichier d'origine de la langue choisie ; si ce fichier ne contient pas de traduction, elle devient **Référence**. Recherchez une clé ou un texte, utilisez les filtres et enregistrez chaque ligne séparément. Vous pouvez renommer ou supprimer les clés que vous avez ajoutées.

## Exporter et importer du JSON

Exportez les clés et les traductions de la langue choisie avant une modification en masse. L'import ne met à jour que les clés existantes ; les clés inconnues ou répétées sont ignorées et indiquées dans le résultat. Conservez les identifiants de section et de langue ainsi que les chemins des clés. La limite est de 8 Mio.

## Fichiers de langue et langue par défaut

Un fichier désactivé reste modifiable. Le fichier anglais de base et la langue par défaut actuelle de WHMCS sont protégés. Pour changer de langue par défaut, activez la nouvelle dans le module, changez-la dans WHMCS, puis désactivez l'ancienne. Les anciens noms de fichiers se corrigent dans **Sections**.
