# Paramètres du module

Activez d'abord les langues nécessaires, puis choisissez le format des URL et le routage des langues avant d'enregistrer. Si les routes changent, mettez à jour les règles Apache dans Rewrite Manager ou la configuration Nginx équivalente. Vérifiez une page du module dans la langue par défaut et dans une autre langue active. Exportez une sauvegarde avant un changement important ou un import.

## WHMCS

Choisissez les langues utilisables par le module. Désactiver une langue ne supprime pas son contenu.

Si vous utilisez des URL conviviales sur Apache, mettez à jour les règles dans Rewrite Manager après toute modification des langues.
