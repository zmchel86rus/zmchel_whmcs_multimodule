# Gestionnaire de médias

## Téléverser et choisir un fichier

Cliquez sur **Téléverser un fichier multimédia**, choisissez une image, un fichier audio, une vidéo ou un PDF, puis renseignez le nom, le texte alternatif, le titre et la description selon le cas. Pour les images, écrivez un texte alternatif descriptif. Après le téléversement, utilisez la recherche et le filtre de type de fichier ; **Charger plus** affiche les résultats suivants. Dans le bloc Image, choisissez le fichier de la bibliothèque et enregistrez la page.

## Affichage des images

Le gestionnaire crée plusieurs tailles d'image. Vous pouvez lancer **Optimiser l'image** après le téléversement, puis vérifier le rendu, surtout si l'image contient du texte. Si les variantes adaptatives ne conviennent pas, désactivez `srcset` dans ce bloc. Vérifiez l'URL finale et le texte alternatif sur la page publique.

## Instructions

- Téléverser un fichier multimédia
- **Nom (interne)**
- **Titre (le cas échéant)**
- **Description (le cas échéant)**
- **Attribut alt**
- Rechercher par nom
- Type de fichier
- Charger plus
- Optimiser l’image
- L’optimisation de l’image d’origine et de ses variantes est terminée.
- Sélectionner un fichier multimédia
