# Base de données du module

## WHMCS

- **Base de données du module:** `MISSING` → Sélectionner → Corriger Éléments sélectionnés.
- **Supprimer Éléments sélectionnés** — Cette action est irréversible.

La page **Base de données du module** indique les tables et colonnes requises ainsi que leur état. Seul le superadministrateur désigné peut y accéder. Ouvrez-la si une autre section signale une table ou une colonne manquante. Vérifiez la liste, sélectionnez uniquement les éléments à réparer, puis cliquez sur **Corriger la sélection**. Certaines colonnes ne peuvent pas être réparées automatiquement ; contrôlez de nouveau l'état après l'opération.

**Supprimer la sélection** retire définitivement les objets choisis de la base de données. Exportez les données du module et sauvegardez la base avant toute suppression.
