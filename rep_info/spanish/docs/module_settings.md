# Ajustes del módulo

Primero activa los idiomas necesarios; después elige el formato de las URL y las rutas de idioma y guarda los ajustes. Si cambian las rutas, actualiza las reglas de Apache en Rewrite Manager o la configuración equivalente de Nginx. Comprueba una página del módulo en el idioma predeterminado y en otro idioma activo. Exporta una copia de seguridad antes de cambios importantes o de importar datos.

## WHMCS

Elige los idiomas que puede usar el módulo. Desactivar un idioma no elimina su contenido. Si usas URL amigables en Apache, actualiza las reglas en Rewrite Manager después de cambiar los idiomas.
