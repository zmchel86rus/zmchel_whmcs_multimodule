# Ajustes del módulo

## WHMCS

Elige los idiomas que puede usar el módulo. Desactivar un idioma no elimina su contenido. Si usas URL amigables en Apache, actualiza las reglas en Rewrite Manager después de cambiar los idiomas.

- [Importación y exportación](module_settings_transfer.md)

## Instrucciones

- **URL amigables** — Activa URL amigables, incluidas las del sistema.
- **Rutas de idiomas** — Activa o desactiva las rutas de idiomas. Al activarlas, las páginas están disponibles en /de/, /en/, /es/ y otros prefijos admitidos. Si se desactivan, una sola URL muestra la página en el idioma configurado por el usuario.
- **Ruta del idioma predeterminado** — Añade un prefijo al idioma predeterminado y redirige a él las páginas del módulo sin prefijo.
- **Modo mantenimiento (módulo)** — Activa o desactiva el modo mantenimiento del módulo. Este modo más suave permite que sigan funcionando los hooks de WHMCS y otros componentes.
- **Recopilar variables Smarty** — Activa o desactiva la recopilación de variables Smarty.
- **Usar variables Smarty recopiladas** — Activa o desactiva el uso de variables Smarty recopiladas en el editor de páginas.
- **Sustituciones de páginas** — Activa o desactiva las sustituciones de páginas.
- **Frecuencia de actualización** — Si no se selecciona nada, el sitemap se actualiza a diario.
- **Sitemap HTML** — Al activarlo, /html-sitemap muestra un sitemap HTML normal; sitemap.xml no se modifica.
- **Cabecera del sitio** — HTML personalizado para la sección <head>, incluidos <script> y <style>.
- **Pie de página del sitio** — HTML personalizado antes de </body>, incluidos <script> y <style>.
