# Gestor multimedia

## Subir y seleccionar un archivo

Haz clic en **Subir archivo multimedia**, elige una imagen, un audio, un vídeo o un PDF y rellena el nombre, el texto alternativo, el título y la descripción cuando corresponda. Para las imágenes, escribe un texto alternativo descriptivo. Tras subirlo, usa la búsqueda y el filtro por tipo de archivo; **Cargar más** muestra otros resultados. En el bloque de imagen, elige el archivo de la biblioteca y guarda la página.

## Mostrar imágenes

El gestor crea varios tamaños de cada imagen. Puedes ejecutar **Optimizar imagen** después de subirla y comprobar la calidad, especialmente si contiene texto. Si las variantes adaptativas no sirven para esa imagen, desactiva `srcset` en el bloque correspondiente. Comprueba la URL final y el texto alternativo en la página pública.
