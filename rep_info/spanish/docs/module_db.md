# Base de datos del módulo

## WHMCS

- **Base de datos del módulo:** `MISSING` → Seleccionar → Corregir Elementos seleccionados.
- **Eliminar Elementos seleccionados** — Esta acción no se puede deshacer.

La página **Base de datos del módulo** muestra las tablas y columnas necesarias y su estado. Solo puede usarla el superadministrador designado. Ábrela cuando otra sección avise de una tabla o columna ausente. Revisa la lista, selecciona solo lo que debas reparar y pulsa **Corregir seleccionados**. Algunas columnas no tienen reparación automática; vuelve a comprobar el estado después.

**Eliminar seleccionados** borra de forma irreversible los objetos elegidos de la base de datos. Antes de hacerlo, exporta los datos del módulo y crea una copia de seguridad de la base.
