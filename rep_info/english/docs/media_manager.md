# Media Manager

Media Manager stores files used by page blocks and other module content. Open it to upload a file, find an existing item, or optimize an image.

## Upload and select files

Click **Upload**, choose an image, audio, video, or PDF file, and complete the available name, alt text, title, and description fields. Give images meaningful alt text. After upload, use search and the type filter to find the item; **Load more** retrieves additional results. In an Image block, use **Choose image** to select a file from the library, then save the page.

## Image output

The manager creates several image sizes. You can run **Optimize image** on an uploaded image and inspect the result afterward, especially if it contains text. If a particular image should not use responsive variants, turn off `srcset` in that Image block. Confirm the final URL and `alt` text on the public page.

## Instructions

- Upload media file
- **Name (internal)**
- **Title (if applicable)**
- **Description (if applicable)**
- **Alt attribute**
- Search by name
- File type
- Load more
- Optimize image
- Optimization of the original image and its variants is complete.
- Select media file
