# WHMCS-д зориулсан үнэгүй мультимодуль

**zmchel WHMCS Multimodule үнэгүй.** WHMCS-ийн удирдлагаас хуудас ба блокийн визуал редактор, олон хэлний агуулга, цэс, медиа сан, SEO мета мэдээлэл, XML sitemap, чиглүүлэлт, rewrite дүрэм, импорт болон экспортыг ашиглана. Өдөр тутмын ажиллагааг [заавар](instruction.md)-аас үзээрэй.

## Анх ашиглахын өмнө

**Модулийн тохиргоо → Дэмжигдэх хэл хэсэгт хэрэгтэй хэлээ идэвхжүүлээрэй.**

Идэвхжүүлэх бүрд module_init.php дахь ZM_PB_ADMIN_SALT, ZM_PB_SECURE_SALT, ZM_PB_NONCE_SALT шинээр үүснэ. Гурвууланд утга бичигдсэнийг шалга.

Модулийг **WHMCS 8.13.0–9.1.0** дээр хөгжүүлж, туршсан. **Apache бүрэн дэмжигдэнэ (100%)**. Nginx дээр ч ажиллаж болох боловч нүүр хуудасны хэлний маршрут нэмэлт тохиргоо болон туршилт шаардаж магадгүй.

**Шалгасан PHP хувилбарууд:** 7.4, 8.0, 8.1, 8.2, 8.3, 8.4, 8.5. Бүх PHP файл синтакс шалгалтад тэнцэж, тусдаа тестүүдийг ч ажиллуулсан.

## Цаашдын хөгжүүлэлт

- Давхар хуудас болон хуудасны ангилал эсвэл хэсэг нэмэх.
- Одоогийн нэгдмэл системийг харилцан ажиллах бүрэлдэхүүнүүдэд хуваах.
- Админы эрхийн менежер хийх.
- supported_langs.php-ийн анхдагч хэлний жагсаалтыг өргөжүүлэх.
- Модулийн .tpl болон WHMCS клиент theme-ийг засах кодын редактор хийх; admin theme-ийг оруулахгүй.
- ~~Модуль, бусад модуль, WHMCS-ийн хэлний файлыг засах хэлний менежер нэмэх.~~
- Медиа менежерийг сайжруулах.
- Yoast SEO-оос санаа авсан, илүү оновчтой бүрэн SEO менежер хийх.
- ~~Олон хэлний sitemap болон HTML sitemap хуудас нэмэх.~~
- HTML sitemap хуудас нэмэх.
- Хуудасны менежерт ашиглалтын статистик нэмэх.
- JS/CSS/HTML жижигрүүлэлт, бүтэн хуудасны cache, модулийн болон WHMCS хүснэгтийн оновчлол хийх.
- Модулийн шинэчлэлтийн бүрэн систем нэмэх.

Эдгээр нь **ирээдүйн санаа болохоос тогтсон төлөвлөгөө биш**.
