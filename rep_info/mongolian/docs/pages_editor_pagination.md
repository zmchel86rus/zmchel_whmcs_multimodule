# Хуудаслалтын блок

1. Блокийг зорилтот жагсаалтын өмнө эсвэл дараа байрлуул. Canvas дээр Smarty блок эсвэл элементүүдийн container-ийг сонго; хуудаслалт зорилтын гадна байх ёстой.
2. Smarty-д бүх жагсаалтыг агуулсан $items шиг хувьсагч оруул. Template-ийн ердийн {foreach}-ийг үлдээгээд хоёр дахь array_slice битгий хий.
3. Хуудасны хэмжээ болон эхлэл, төгсгөл, одоогийн хуудасны хоёр талын товчны тоог desktop, mobile-д тусад нь тохируул. Нэг жагсаалтад нөгөө талын нэмэлт удирдлага гаргаж болно.

## Холбоос ба олон жагсаалт

Блок бүр модулийн анхдагч загвар, /page/2/ эсвэл ?page=2-ыг сонгоно. Зам хэлбэрт rewrite дүрэм шаардлагатай; шууд PHP маршрут query параметр ашиглана. Шүүлтүүр, эрэмбэ, суулгалтын зам, хэлний угтвар хадгалагдана. Эхний жагсаалт page, count, sort ашигладаг. Дараагийн жагсаалт зорилтот блокийн ID-г параметрт залгана; /page/N/ үед pager нь дугаар аль жагсаалтад хамаарахыг заана. Удирдлагыг хуулсан ч шинэ жагсаалт үүсэхгүй.

## Жагсаалтын эх сурвалж

Smarty хувьсагчтай үед модуль энэ хуудсанд аль хэдийн байгаа цуглуулгыг хэсэгчлэн харуулдаг. Өөр эх үүсвэрээс дутуу мөр татахгүй. Хувьсагчгүй үед сонгосон container-ийн HTML элементүүдийг хуваана. Давтагдах class эсвэл tr мэт tag-ийг зааж болно; thead, tfoot хэвээр үлдэнэ. Том динамик жагсаалтад бүх HTML-ийг эхлээд гаргахгүйн тулд хувьсагч ашигла. Smarty блок $zm_pagination дотор total, page, pages, count, offset авна. Жагсаалт нэг хуудсанд багтвал удирдлага харагдахгүй.

## Хуудасны хэмжээ, SEO, шүүлтүүр

Сонголтод 10, 25, 50, 100, 250 элемент бий. Хэмжээ солиход шүүлтүүр хадгалагдаж тухайн жагсаалт эхний хуудас руу буцна. Сервер count болон count_<id>-ийг 10–250-д хязгаарлана. Дараагийн хуудсуудын гарчиг, тайлбар, сүүлийн breadcrumb-д дугаар нэмэгдэж canonical нь тухайн үр дүн рүү заана. noindex зөвхөн эхнийхээс хойших хуудсанд нөлөөлнө. Текстийн шүүлтүүр таслалаар тусгаарласан олон талбар болон массивын түлхүүрийг хайж чадна. Огноо YYYY-MM-DD хэлбэртэй бөгөөд сүүлийн өдрийг бүхэлд нь хамарна.

## YYYY-MM-DD огноо

Шүүлтүүр хуудаслалттай ижил жагсаалтад ажилладаг. Хэрэглэх эсвэл арилгахад зөвхөн тэр жагсаалт эхний хуудас руу буцна. URL дахь хэл, эрэмбэ хэвээр үлдсэн эсэхийг шалга.

## Flex / Grid байрлал

Төхөөрөмжийн хэмжээ бүрт талбарын өргөн, баганын тоог тусад нь тохируул. Хуудасны хэмжээ сонгогчийг өөр container руу зөөсөн ч холболт хэвээр. Давхар удирдлагууд ижил шүүлтүүр, хэмжээг ашигладаг.
