# Гаралт дахь бүтэцтэй өгөгдөл

## Schema.org

Page Editor-ийн мета тохиргооноос Schema төрлийг сонгож нийтлэгдсэн үр дүнг шалга. Цэс бодит шошго, хэл, хандаж болох URL-тай SiteNavigationElement гаргаж болно. Агуулгын хүснэгт бодит гарчгийн anchor-аас SiteNavigationElement болон WebPageElement үүсгэнэ. Харагдах, хоосон биш асуулт-хариулт л FAQPage-д орно. Client theme-д хоёроос олон breadcrumb байвал BreadcrumbList гарна.

Байгууллага, холбоо барих мэдээлэл WHMCS-ээс ирдэг. Хуудасны хэл WebPage эсвэл ContactPage дээр, харин холбоо барих боломжтой хэл BCP 47-оор ContactPoint.availableLanguage дээр бичигдэнэ. Organization-д таамгаар inLanguage нэмж болохгүй. Шүүлтүүр, талбар, хуудасны хэмжээ сонгогч, холбоо барих маягт нь автоматаар бүтээгдэхүүн эсвэл үйлчилгээ болохгүй. Flex/Grid, товч, энгийн accordion нь зөвхөн харагдах хэлбэр тул агуулгын төрлийг тогтоохгүй.

JSON-LD нь зочинд үнэхээр харагдах агуулгыг тайлбарлах ёстой. Зөв markup байсан ч хайлтын онцгой үр дүнг батлахгүй. Зохиогчийн Smarty эсвэл HTML-д нэмсэн бүтэцтэй өгөгдөл хадгалагдана. Нийтийн хуудсан дээр холбоос, гарчиг, асуулт, хариултыг эцсийн JSON-LD-тэй харьцуул. Нуугдсан блок нийтэд харагдах FAQ болж гарах ёсгүй.

## JSON-LD шалгах

Нийтлэгдсэн URL-ийг зочин болон нэвтэрсэн хэрэглэгчээр нээ. Цэсний холбоос, breadcrumb болон бодит текст markup-тай таарч байгаа эсэхийг үз. Schema.org бичлэг нь хэрэглэхэд хялбар navigation-ийг орлохгүй.

## ContactPoint.availableLanguage

Холбоо барих хэл WHMCS-ээс авдаг бөгөөд BCP 47 tag ашиглана. Тухайн хуудасны хэл WebPage эсвэл ContactPage-д хамаарна; Organization-д зохиомол inLanguage утга нэмэхгүй.
