# Медиа менежер

Медиа сан нь хуудасны блокууд болон модулийн бусад агуулгад ашиглах файлуудыг хадгалдаг. Энд шинэ файл оруулах, байгаа зүйлээ хайх, зургаа оновчлох боломжтой. WHMCS-ийн theme-ийн файлыг гараар өөрчлөх шаардлагагүй.

## Файл оруулах ба сонгох

**Upload**-ийг дарж зураг, аудио, видео эсвэл PDF сонгоно. Боломжтой бол системийн нэр, гарчиг, тайлбар, alt текстийг бөглө. Зургийн alt-д файлын нэрийг давтахын оронд зургийн утгатай хэсгийг тайлбарла. Хайлт болон төрлийн шүүлтүүрээр файлаа олно; **Load more** дараагийн үр дүнг харуулна. Image блок дотор **Choose image**-ээр медиа сангийн файлыг сонгоод хуудсаа хадгал. Нийтэд харагдах хуудсан дээр файлын жинхэнэ URL-ийг мөн шалгаарай.

## Зураг гаргах

Менежер зургийн хэд хэдэн хэмжээтэй хувилбарыг үүсгэдэг. **Optimize image** ажиллуулсны дараа, ялангуяа үсэг эсвэл нарийн шугамтай зурагт чанарын өөрчлөлт орсон эсэхийг үз. Тухайн зурагт responsive хувилбар хэрэггүй бол Image блокийн srcset-ийг унтраа. Нийтлэгдсэн хуудсанд эцсийн URL, хэмжээ, alt текст зөв гарсныг баталгаажуул.
