# Чиглүүлэлт ба sitemap хэл

## HTTP

Redirect Manager эхлэл → очих хаягийн яг таарах дүрмийг HTTP 301, 302, 303, 307, 308 кодтой үүсгэнэ. Дүрмийг засах, унтраах, устгах боломжтой бөгөөд жагсаалт нэг хуудсанд 50-г харуулна. Эхлэл нь / тэмдэгтэй зам эсвэл өөрийн сайтын бүтэн URL байж болно. Очих хаяг нь зам эсвэл HTTP(S) URL.

Төгсгөлийн налуу зураасыг тааруулахад ижилд тооцох боловч очих хаягийн зураас хэвээр хадгалагдана. Тодорхой query-тэй дүрэм энгийн замын дүрмээс түрүүлнэ; замын дүрэм параметртэй хүсэлтэд ч таарна. Очих хаягийн параметр эхнийхийг орлоно. Дүрэм WHMCS-д хүрсэн GET ба HEAD хүсэлтэд page builder-ээс өмнө ажилладаг. .htaccess, хэлний session, хэрэглэгчийн профайлыг өөрчлөхгүй. ZM_PB_ENABLE_REDIRECTS_MANAGER хадгалсан дүрмийг идэвхжүүлнэ.

Нийтлэгдсэн хуудасны slug өөрчлөгдөж нийтлэгдсэн хэвээр байвал автомат 301 үүснэ. Нооргийг анх нийтлэхэд чиглүүлэлт үүсэхгүй. ZM_PB_AUTO_REDIRECT_DAYS анхдагчаар 14 өдөр; 0 бол хүлээлтгүй. Дараагийн нэр солилт өмнөх дүрмийн очих хаягийг шинэчилнэ, хуучин slug-даа буцахад өөр рүүгээ чиглүүлсэн дүрэм арилна. Гараар үүсгэсэн дүрэм түрүүлнэ. WHMCS хуудсыг орлуулах alias анхны системийн хаяг руу зааж болно.

Дүрмүүд zm_pb_redirects-д хадгалагдана. Хүсэлт дутуу хүснэгт үүсгэдэггүй тул Module database-д зас. Одоогийн URL багана 128 bytes хязгаартай. sitemap_pages.xml ба sitemap_posts.xml хэлний хувилбар, x-default-ийг харуулдаг ч чиглүүлэлтийн эхлэлийг оруулахгүй. URL солигдсоны дараа XML-ийг дахин үүсгэ.
