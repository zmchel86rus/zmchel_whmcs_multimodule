# Sitemap

## XML

XML нь идэвхтэй хэл бүрийн харилцан холбоос болон үндсэн хэлний хаягийн x-default-ийг агуулна. Чиглүүлэлтийн эхлэл loc эсвэл хэлний хувилбарт орохгүй. Fallback агуулга бодит хэлийг нь ашиглана. Хуудас ба нийтлэлийн файл XHTML namespace-ийг зарласнаар URL бүр олон хэлний холбоостой болно.

Үүсгэгч lib/sitemap.php, туслах функц inc/sitemap_manager.php, AfterCronJob hook hooks/sitemap.php-д бий. ZM_PB_ENABLE_SITEMAP унтарсан бол автоматаар болон гараар үүсгэх аль аль нь ажиллахгүй. Cron дууссаны дараа ZM_PB_SITEMAP_LASTUPD болон ZM_PB_SITEMAP_UPDFREQ-ийг харьцуулна. Мэдэхгүй давтамжийг өдөр бүр гэж үзнэ; **Generate** шууд ажиллана. Зөвхөн хамгийн сүүлчийн амжилттай хугацааг хадгална.

Сайтын үндсэн хавтаст sitemap_index.xml, sitemap_pages.xml, sitemap_posts.xml үүснэ. Нэг ангилал 50,000 URL эсвэл 50 MB-аас давбал нэмэлт файлд хуваагдана. Индекс бусад зөв root urlset-ийг оруулдаг ч давхар индекс оруулахгүй. Модуль зөвхөн өөрийн хуудас, нийтлэлийн файлыг шинэчилж устгана; хоосон ангилал файл үүсгэхгүй.

Зөвхөн нийтлэгдсэн, нийтэд нээлттэй, lang_active орчуулгатай хуудас ба нийтлэл орно. WHMCS хуудсыг орлуулах үед builder-ийн slug биш, анхны системийн URL ашиглагдана. Үндсэн хэлний сонголтот угтвар ч мөн тусна. Сайтын үндсэн хавтас, resources/, inc/editable_consts.php-д бичих эрх хэрэгтэй. Хүснэгт дутуу бол Module database-д зас; алдаа гарвал хуучин файлыг түр хуулбараас сэргээж амжилтын хугацааг өөрчлөхгүй.
