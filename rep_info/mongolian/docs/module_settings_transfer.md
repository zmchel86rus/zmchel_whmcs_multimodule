# Импорт ба экспорт

## ZIP архив

Module settings → Import / export дотор бүх эсвэл сонгосон хэсгээ заа. Экспорт manifest.json болон хуудасны тусдаа CSS/JS файлуудтай ZIP үүсгэдэг. JSON файлыг мөн импортолж болно. Өөр сайт руу шилжүүлэх эсвэл олон тохиргоо солихын өмнө эх архивыг хадгал.

- **Хуудас ба нийтлэл:** тохиргоо, бүх орчуулга, GrapesJS агуулга, SEO болон sitemap тохиргоо. CSS/JS нь шинэ хуудасны ID-аар дахин үүснэ.
- **Цэс:** бүтэц, орчуулсан шошго, байрлал, тохиргоо. Хуудас slug ба auth_type-оор, цэс нэрээрээ таарна.
- **Тохиргоо:** засварлагдах констант, орлуулах хуудас, header, footer, robots.txt. URL горим ба sitemap-ийн сүүлийн цаг тухайн сайтад үлдэнэ.
- **Redirect ба rewrite:** гараар оруулсан дүрэм, хуудсын холбоо, өөрийн rewrite дүрэм. Импортын дараа rewrite-ийг менежерт хэрэгжүүл.
- **Медиа:** бүртгэлтэй файл, хувилбар, тайлбар; хамааралгүй WHMCS attachments орохгүй.

Импорт таарсан бичлэгийг шинэчилж, шинэ бичлэг нэмж, бусдыг хэвээр үлдээнэ. Архивт байхгүй сонгосон хэсгийг алгасна. Шинэ сайт руу цэс эсвэл автомат redirect шилжүүлэхдээ холбогдох хуудсыг хамт импортол. Эх сайтын SystemURL нь шинэ хаягаар солигдож, гадаад URL өөрчлөгдөхгүй. Хуудасны зургийг шилжүүлэх бол медиа хэсгийг хамт сонго.

ZIP дээд тал нь 128 MiB, JSON 32 MiB. PHP-ийн upload_max_filesize, post_max_size-ийг тооцож ZIP extension суулга. Үүсгэсэн CSS/JS байхгүй эсвэл уншигдахгүй бол экспорт алгасаж анхааруулна. Өөрчлөлтийн түүх, цуглуулсан Smarty хувьсагч, WHMCS хэрэглэгч ба нууц, theme файлууд орохгүй. Импорт байгаа хүснэгтийг ашигладаг, schema үүсгэдэггүй.

Бичлэг шинэчлэхийн өмнө баталгаажуулалт гарна. Өгөгдлийн сангийн өөрчлөлт transaction ашиглаж, алдаанд солигдсон файлыг сэргээнэ. Файлын түгжээ давхар импорт зогсооно. Амжилттай бол sitemap-ээ дахин үүсгэж нийтэд харагдах URL-үүдийг шалга.
