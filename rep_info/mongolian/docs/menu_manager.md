# Цэсний менежер

menu_manager олон тусдаа цэс, хуудас ба нийтлэл хайлт, өөрийн холбоос, URL нь # байх холбоосгүй гарчгийг дэмждэг. Элементүүдийг чирж эрэмбэлээд эцэг элемент оноож дотор нь байрлуул. Элемент бүр орчуулагдах шошго, гарчиг, тайлбар, CSS class, rel, icon, шинэ tab, зочин болон үйлчлүүлэгчийн харагдах нөхцөлтэй. Шинэ нийтлэгдсэн хуудсыг автоматаар нэмэж болно. Цэс нь desktop, mobile эсвэл аль алинд WHMCS navigation-ийг өргөтгөх эсвэл орлох боломжтой.

## Байрлал ба тохиргоо

WHMCS-ийн ClientAreaPrimaryNavbar, ClientAreaSecondaryNavbar, ClientAreaPrimarySidebar, ClientAreaSecondarySidebar байрлал тус бүрийг ZM_PB_ENABLE_MAINNAV, ZM_PB_ENABLE_SECONDARYNAV, ZM_PB_ENABLE_MAINSIDEBAR, ZM_PB_ENABLE_SECONDARYSIDEBAR удирдана. Унтарсан байрлалын код ачаалагдахгүй. Идэвхтэй оноолт үгүй бол WHMCS-ийн анхны цэс хэвээр. Нэг байрлалд нэг цэс байх боловч нэг цэс хэд хэдэн байрлалд ашиглагдаж болно. Эзлэгдсэн байрлалыг шинэ цэстэй холбоход өмнөх оноолт шилжинэ.

## Хэл ба хандалт

Энгийн WHMCS системийн маршрутад хэрэглэгчийн хадгалсан хэл шошгыг сонгодог. Модулийн хуудсанд URL дахь хэл ашиглагдаж профайл өөрчлөгдөхгүй. Өөрийн холбоосын **Link URL language**-ийг унтраавал URL өөрчлөгдөхгүй, харин шошго орчуулагдана. Энэ тохиргоо zm_pb_menu_items.localize_url-д хадгалагдана. Хуудасны элементийн URL нь одоогийн slug, нийтлэгдсэн орчуулга, pretty URL тохиргооноос дахин тооцогдоно. Энгийн хэлбэр нь ?m=zmchel_whmcs_multimodule&slug=...&lang=.... Шошго хоосон бол breadcrumb, meta title эсвэл нэр авна. Ноорог, устсан, эрхгүй хуудас гарахгүй. Гадаад URL, mailto, tel, anchor-д хэлний угтвар нэмэхгүй.

## Хүснэгт ба код

zm_pb_menus тохиргоо, zm_pb_menu_items бүтэц, zm_pb_menu_locations байрлалыг хадгална. Хүснэгтийн schema-г Module database-т үүсгэж засна; цэсний менежер зөвхөн бичлэг өөрчилнө. Эцэг элементийг устгахад хүүхдүүд нь түүний түвшинд шилжинэ. Нэг цэс 10 давхар, 300 элемент хүртэл байж болно; хадгалалт нэг transaction-д хийгдэнэ. Mobile, desktop болон зочин, үйлчлүүлэгчийн дэлгэц дээр шалга.
