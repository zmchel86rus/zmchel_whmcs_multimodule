# Модулийн өгөгдлийн сан

## WHMCS

Module database хэсэг модульд хэрэгтэй хүснэгт, баганууд болон тэдгээрийн төлөвийг харуулна. Зөвхөн тохируулсан Super Administrator энэ хуудсыг ашиглаж чадна. Модулийн өөр хэсэг хүснэгт эсвэл багана дутуу гэж мэдээлбэл энд орж шалга. Энэ нь WHMCS-ийн бүх өгөгдлийн санг чөлөөтэй засах хэрэгсэл биш.

Эхлээд төлөвийн хүснэгтийг унш. Засах шаардлагатай MISSING мөрүүдийг л сонгоод **Fix Selected items**-ийг дар. Хуудсыг дахин ачаалж засвар үнэхээр амжилттай болсон эсэхийг шалга. Зарим дутуу баганад автоматаар үүсгэх жор байхгүй; менежер асуудлыг харуулна, гэхдээ баганыг өөрөө нэмж чадахгүй.

**Delete Selected items** сонгосон модулийн объектуудыг бүрмөсөн устгадаг. Үүнээс өмнө модулийн өгөгдлөө экспортолж, өгөгдлийн сангийн нөөц хуулбар ав. Зөвхөн анхааруулгыг арилгахын тулд хамааралгүй мөр сонгож болохгүй. Засварын дараа алдаа өгч байсан функцээ дахин шалгаарай.
