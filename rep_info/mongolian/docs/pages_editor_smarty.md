# Smarty блок ба хувьсагчийн жагсаалт

Module settings-д Smarty хувьсагч цуглуулах, ашиглах сонголтуудыг эхлээд асаа. ZM_PB_COLLECT_VARS жагсаалтыг бүрдүүлдэг, ZM_PB_USE_COLLECT_VARS блокийн гаралтыг зөвшөөрдөг. Холбогдох нийтэд харагдах хуудсуудыг нээж, дараа нь редакторыг дахин ачаалбал шинэ санал гарна.

## Жагсаалт

Файлууд resources/available_vars/ дотор theme, template-аар хадгалагдана. Жинхэнэ утга биш, нэр, төрөл, дотоод бүтэц, ажигласан үе шатыг тэмдэглэнэ. sampled болон truncated нь дээж хязгаарлагдсаныг илтгэнэ. Нууц үг, token, хувийн мэдээлэл redacted гэж тэмдэглэгдэнэ. Жагсаалтад талбар алга гэдэг нь бүх хүсэлтэд байхгүй гэсэн үг биш. Объектын getter, model-ийн relation, нэмэлт өгөгдлийн сангийн query ажиллуулахгүй. .htaccess хавтсыг хамгаалдаг ч Nginx дээр бодит утга хадгалагдаагүй хэвээр байна.

## Редактор

Блокийн **Edit code**-ийг дарах эсвэл Smarty блокийг хоёр товшиход CodeMirror нээгдэнэ. Ctrl+Space хувьсагч хайна, Ctrl+S кодыг хэрэгжүүлнэ, F11 бүтэн дэлгэц, Escape хаана. Байгаа цуглуулгад {foreach $items as $item} хэрэглэж, талбарыг {$item.title|escape} хэлбэрээр гарга. Жагсаалт хоосон үед харуулах текст бэлтгээд нийтэд харагдах гаралтыг шалга.

## foreach жишээ

Энэ хуудсанд аль хэдийн байгаа жагсаалтад {foreach $items as $item} хэрэглэж, гарчгийг {$item.title|escape} хэлбэрээр гарга. Жагсаалт хоосон үед үзүүлэх текст мөн бэлтгэ. Хувьсагчийн жагсаалт зөв нэр олоход тусална, гэхдээ өөр хуудасны өгөгдлийг энд татаж ирэхгүй.

## Ажиллагаа ба хязгаар

Код хадгалах болон гаргахын өмнө шалгагдана. Хязгаарлагдсан if, foreach, дотоод assign, capture, мөн escape, default, count, date_format зэрэг modifier зөвшөөрөгдөнө. PHP, SQL, объектын method, дурын function, файл include, сүлжээний эх үүсвэр, nofilter хориглогдоно. Утгууд автоматаар escape хийгддэг; зориудын HTML-ээ template-д бич. Өгөгдөл дутуу эсвэл алдаа гарвал блок хоосон болж PHP error log-д бичигдэнэ. Эрхийн хязгаартай хэсгийг Smarty ажиллахаас өмнө арилгана.
