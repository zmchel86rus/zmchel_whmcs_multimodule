# Модулийн тохиргоо

Эхлээд ашиглах хэлнүүдээ идэвхжүүл. Дараа нь URL хэлбэр, хэлний маршрутыг сонгож хадгалаад нийтлэгдсэн хуудсаар турш. Маршрут өөрчлөгдсөн бол Apache-ийн Rewrite менежерийн дүрэм эсвэл Nginx-ийн ижил тохиргоог шинэчилнэ. Их хэмжээний өөрчлөлт, импорт хийхээсээ өмнө өгөгдлөө экспортолж нөөцөл.

## Боломжтой табууд

- **Import / export:** сонгосон хэсгийн ZIP нөөц үүсгэх эсвэл ZIP, JSON импортлох. Импорт хийхийн өмнө [шилжүүлгийн заавар](module_settings_transfer.md)-ыг унш.
- **Editable constants:** URL, маршрут, гаралт, медиа, засвар үйлчилгээ, Smarty зэрэг тохиргоог өөрчилнө. Талбарын тайлбарыг уншиж нийтийн хуудсанд үр дүнг шалга.
- **Supported languages:** хуудас үүсгэхээсээ өмнө хэрэгтэй хэлээ асаа. WHMCS-ийн үндсэн хэлийг тэнд үндсэн утгыг солих хүртэл идэвхтэй үлдээнэ.
- **Redirects ба Sitemap:** хадгалсан болон автомат чиглүүлэлт, XML үүсгэх хуваарийг тохируулна. Тусгай дүрмийг харгалзах менежерээр засна.
- **Header, Footer, Robots:** сайтын толгой, хөл болон robots.txt-ийг засаж бодит гаралтыг үз.

Веб серверийн маршрутаас хамаарах тохиргоонд сервер дээр ижил дүрэм хэрэгтэй. Apache-д .htaccess, Nginx-д тусдаа серверийн тохиргоо хэрэглэнэ.
