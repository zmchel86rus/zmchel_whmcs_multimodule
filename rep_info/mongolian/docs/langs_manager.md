# Хэлний менежер

Хэлний менежер WHMCS-ийн client, admin, энэ модуль болон илэрсэн бусад модулийн орчуулгын мөрийг засах боломж олгоно. Модулийн Super Administrator эрх, харгалзах хэлний хавтаст PHP бичих эрх шаардлагатай. Sections → Languages → Translations дарааллаар ажиллана; **Save** товч бүр нэг л орчуулгыг хадгална.

## Эхлэх

Module settings → Supported languages дотор хэрэгтэй хэлээ эхлээд асаа. Энэ жагсаалт менежер ямар хэл нэмж болох, модуль хуудас ямар хэл ашиглахыг шийднэ. Sections табаас WHMCS client, WHMCS admin, энэ модуль эсвэл өөр модуль сонго. Байгаа, идэвхгүй, нэмж болох хэлний тоо гарна. Шинэ хэл эхэндээ лавлах хэлний мөрийг харуулдаг учир бүрэн орчуулга гэж үзэж болохгүй. Өөрийн орчуулгагүй файлд **Untranslated** тэмдэглэгээ байна.

## Орчуулга засах

**Original** багана override-оос бус, сонгосон хэлний эх файлаас шууд уншсан мөрийг үзүүлнэ. Тэр хэлэнд эх орчуулга үгүй бол **Reference** багана лавлах хэлийг харуулна. Түлхүүр эсвэл үгээр хайж, эх болон нэмсэн түлхүүрээр шүү. Урт жагсаалт хуудастай. Мөр бүрийг тусад нь хадгал. Өөрийн түлхүүрийг эцэг бүлэг дор нэмж, нэрийг нь сольж эсвэл устгаж болно; эх түлхүүрийг ингэж устгахгүй. Аюулгүйгээр бичих боломжгүй гуравдагч модулийн формат зөвхөн унших горимд үлдэнэ.

## JSON экспорт ба импорт

**Export JSON** сонгосон хэлний түлхүүр ба одоогийн утгуудыг татаж авна. Олон мөр засахаас өмнө хуулбар хадгал. **Import JSON** зөвхөн байгаа түлхүүрийг шинэчилж, шинээр үүсгэхгүй. Хэсэг, хэлний ID, түлхүүрийн замыг өөрчилж болохгүй. Мэдэгдэхгүй эсвэл давхардсан түлхүүр алгасагдаж үр дүнд жагсана; зөв мөрүүд үргэлжлэн импортлогдоно. Оруулах дээд хэмжээ 8 MiB.

## Файл ба нэр

Languages таб хэлний файлыг унтрааж эсвэл буцааж асаана; унтарсан хэлний орчуулгыг ч засаж болно. Англи үндсэн файл болон WHMCS-ийн одоогийн үндсэн хэлийг унтраахгүй. Менежерийн үүсгэсэн WHMCS файлууд шинэчлэлтийн дараа сэргээх нөөц хуулбартай. Хуучин файл нэр олдвол Sections доторх нэгдсэн засвараар шинэ нэрийг шалга. Үндсэн хэлийг солихдоо шинэ хэлийг эхлээд модульд идэвхжүүлж, WHMCS-ийн үндсэн хэлийг сольсны дараа хуучныг унтраа.
