# Rewrite менежер

## WHMCS

Rewrite менежер вебсайтын гол .htaccess файл дахь Apache дүрмийг шалгаж, суулгана. Энд мөн өөрийн rewrite дүрмээ хадгалж болно. Нэг URL-ээс нөгөөд шилжүүлэх энгийн redirect-ийг [Чиглүүлэлтийн менежер](redirects_manager.md)-т тусад нь үүсгэнэ; эдгээр нь өөр өөр үед ажилладаг.

## Дүрэм шалгаж хэрэгжүүлэх

Идэвхтэй хэлний маршрутын төлөвийг шалга. **Add or update rules** нь модульд зориулсан дүрмийн блокийг .htaccess-д бичнэ. Дахин шалгаад үндсэн болон өөр нэг хэл дээрх нийтлэгдсэн хуудсыг нээ. **Remove all rules** нь байгаа бол уг блокийг бүхэлд нь арилгана.

Өөрийн дүрэмд URL загвар, очих хаяг, flags-ийг оруулаад хадгалж дахин хэрэгжүүл. Хэт өргөн загвар нь холбоогүй хуудсыг өөр тийш явуулж болзошгүй тул урьдчилан шалгах хэрэгтэй. Apache .htaccess-ийг уншдаг; nginx үүнийг үл тоодог. Тиймээс Nginx дээр серверийн тохиргоонд ижил дүрэм оруулж, өмнөх маршрутууд хэвийн ажиллаж буйг шалга.
