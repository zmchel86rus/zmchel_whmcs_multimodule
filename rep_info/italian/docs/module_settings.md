# Impostazioni del modulo

Attiva prima le lingue necessarie, poi scegli il formato degli URL e le rotte linguistiche e salva le impostazioni. Se le rotte cambiano, aggiorna le regole Apache in Rewrite Manager o la configurazione Nginx equivalente. Controlla una pagina del modulo nella lingua predefinita e in un'altra lingua attiva. Esporta una copia di sicurezza prima di modifiche importanti o di un'importazione.

## WHMCS

Scegli le lingue utilizzabili dal modulo. Disattivare una lingua non ne elimina i contenuti. Se usi URL semplificati con Apache, aggiorna le regole nel Rewrite Manager dopo aver modificato le lingue.
