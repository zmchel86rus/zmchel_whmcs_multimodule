# Gestione dei file multimediali

## Caricare e scegliere un file

Fai clic su **Carica file multimediale**, scegli un'immagine, un file audio, un video o un PDF e compila, se necessario, nome, testo alternativo, titolo e descrizione. Per le immagini scrivi un testo alternativo significativo. Dopo il caricamento usa la ricerca e il filtro per tipo di file; **Carica altri** mostra i risultati successivi. Nel blocco Immagine scegli il file dalla libreria e salva la pagina.

## Visualizzazione delle immagini

Il gestore crea immagini di diverse dimensioni. Puoi eseguire **Ottimizza immagine** su un'immagine caricata e poi controllarne la qualità, soprattutto se contiene testo. Se le varianti responsive non sono adatte, disattiva `srcset` nel blocco interessato. Controlla l'URL finale e il testo alternativo nella pagina pubblica.

## Istruzioni

- Carica file multimediale
- **Nome (interno)**
- **Titolo (se applicabile)**
- **Descrizione (se applicabile)**
- **Attributo alt**
- Cerca per nome
- Tipo di file
- Carica altri
- Ottimizza immagine
- L’ottimizzazione dell’immagine originale e delle sue varianti è stata completata.
- Seleziona file multimediale
