# Gestore delle lingue

- **Sezioni → Lingue → Traduzioni.** Ogni pulsante Salva salva una sola traduzione.

## Scegliere sezione e lingua

Per prima cosa abilita le lingue necessarie nelle impostazioni del modulo. In **Sezioni** scegli le lingue client o admin di WHMCS, questo modulo oppure un altro modulo. In **Lingue** seleziona un file esistente o aggiungi una lingua. Un nuovo file usa i testi della lingua di riferimento finché non inserisci le traduzioni proprie.

## Modificare le traduzioni

In **Traduzioni**, la colonna **Originale** mostra il testo del file originale della lingua scelta; se non esiste una traduzione originale, compare **Riferimento**. Cerca per chiave o testo, usa i filtri e salva ogni riga separatamente. Puoi rinominare o eliminare le chiavi aggiunte da te.

## Esportazione e importazione JSON

Prima delle modifiche in blocco esporta le chiavi e le traduzioni della lingua selezionata. L'importazione aggiorna solo le chiavi esistenti; quelle sconosciute o duplicate vengono ignorate ed elencate nel risultato. Mantieni gli identificativi di sezione e lingua e i percorsi delle chiavi. Il limite del file è 8 MiB.

## File di lingua e lingua predefinita

Un file disattivato resta modificabile. Il file inglese di base e l'attuale lingua predefinita di WHMCS sono protetti. Per cambiare la lingua predefinita, abilita prima la nuova nel modulo, cambiala in WHMCS e solo dopo disattiva la precedente. I vecchi nomi dei file si correggono in **Sezioni**.
