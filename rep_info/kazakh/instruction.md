# zmchel WHMCS Multimodule нұсқаулығы

**Модульді қолданбас бұрын бірегей salt мәндерін жасап, `module_init.php` файлына енгізіңіз: `ZM_PB_ADMIN_SALT`, `ZM_PB_SECURE_SALT` және `ZM_PB_NONCE_SALT`.** Модуль **WHMCS 8.13.1–8.13.7** нұсқаларында әзірленіп, тексерілді. **PHP 7.4–8.5** үйлесімділігі тексерілген. Apache толық қолдау табады; Nginx-та басты беттегі тілдік бағдарлау қосымша баптауды қажет етуі мүмкін. **Модуль тегін.**

**Алғаш қолданар алдында Модуль баптаулары → Қолдау көрсетілетін тілдер бөлімін ашып, қажет тілдерді қосыңыз.**

## Тілдер менеджері (әзірленуде)

WHMCS әкімшілік панелінде Тілдер менеджерін ашып, бөлімді (WHMCS клиенттік немесе әкімшілік тілдері, осы не басқа модуль) және тілді таңдаңыз. Түпнұсқа немесе анықтамалық мәтінді аудармамен салыстырып, бір жолды өңдеп сақтаңыз; бар кілттерді JSON түрінде экспорттап, импорттауға болады. Жаңа тілдер аударылғанға дейін анықтамалық мәтінді пайдаланады. Менеджер тіл файлдарын қосып-өшіреді және ескі атауларды түзетеді; әдепкі тілді алдымен WHMCS ішінде өзгертіңіз.

## Беттерді жасау

WHMCS әкімші бөлімінде **Addons → zmchel WHMCS Multimodule** ашыңыз. URL, қайта бағыттау немесе сервер ережелерін өзгертпес бұрын модуль параметрлерін экспорттаңыз. Беттер тізімінде ішкі атау мен доменсіз, `.php` жалғауынсыз `biz-turaly` сияқты *slug* енгізіңіз. Барлық келушіге, жүйеге кіргендерге немесе аралас қолжетімділікті таңдаңыз; одан кейін қаралама не жарияланған мәртебені, бет түрін және тілдерді белгілеңіз. WHMCS-тің әдепкі тілі `supported_langs.php` ішінде болуы тиіс.

Сақтағаннан кейін әр тілдің мазмұнын, метадеректерін және сайт картасы параметрлерін толтырыңыз. Әр бөлімнің жеке Сақтау түймесі бар. Нәтиже хабарламасын және ашық бетті тексеріңіз. Бастапқы жою бетті себетке көшіреді; біржола жою себеттен жасалады.

## Редактор және тілдер

Мазмұн қойындысында тілді таңдап, GrapesJS блоктарын жұмыс аймағына сүйреп апарыңыз. Мәтінді, суреттерді және блок параметрлерін өңдеңіз. Бөлімдер, бағандар, кестелер, FAQ, байланыс нысаны, тізімдер, беттеу және қонақтар мен тіркелгендерге арналған аймақтар бар. Құрылымды басқа тілге көшіріп, мәтінін аударуға болады. Сілтеме мен түйме блоктары ағымдағы тілді ішкі URL-ге қоса алады; сыртқы сілтеме, файл, `mailto:` және аудармасыз WHMCS жолдары үшін бұл мүмкіндікті өшіріңіз.

Әдемі URL және тілдік бағдарлау қосылса, негізгі тіл `/kk/` сияқты қысқа жолды пайдаланады; әдепкі тілге жеке жол өшірілсе, префикс болмайды. Аймақтық нұсқалар BCP 47 locale қолданады. Сілтемелерді бірнеше тілде тексеріңіз.

## SEO, медиа және қызмет көрсету

Әр тіл үшін тақырыпты, сипаттаманы, robots параметрін, канондық URL мен әлеуметтік желі деректерін толтырыңыз. Жарияланған жүйелік емес бет XML сайт картасына қосыла алады. Media Manager арқылы сурет жүктеп, балама мәтін беріңіз және оңтайландыру сапасын тексеріңіз. Menu Manager ішінде беттер мен жеке сілтемелерді реттеп, тілдік атауларды, орналасуды және көрінуді баптаңыз.

Redirect Manager тұрақты `301` немесе уақытша `302` қайта бағыттауды жасайды. Rewrite Manager Apache үшін `.htaccess` ережелерін жазады; Nginx үшін баламалы ережелерді серверде орнатыңыз. Ірі импорт алдында JSON экспорттаңыз.
