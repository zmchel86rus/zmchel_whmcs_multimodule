# WHMCS үшін тегін көпқызметті модуль

**zmchel WHMCS Multimodule тегін.** WHMCS әкімші панелінен визуалды редактор арқылы көптілді беттерді, мәзірлерді, медиа кітапхананы, SEO метадеректерін, XML сайт карталарын, қайта бағыттауларды, rewrite ережелерін және импорт пен экспортты басқарыңыз. Алдымен [нұсқаулықты](instruction.md) оқыңыз.

## Алғашқы қолдану алдында

**Алғаш қолданар алдында Модуль баптаулары → Қолдау көрсетілетін тілдер бөлімін ашып, қажет тілдерді қосыңыз.**

Әр белсендірілген сайын модуль жаңа salt мәндерін автоматты түрде жасап, оларды `module_init.php` файлына жазады (`ZM_PB_ADMIN_SALT`, `ZM_PB_SECURE_SALT`, `ZM_PB_NONCE_SALT`). Үш salt мәнінің де толтырылғанын тексеріңіз.

Модуль **WHMCS 8.13.0–9.1.0** нұсқаларында әзірленіп, тексерілді. **PHP 7.4–8.5** үйлесімділігі тексерілген. Apache толық (100%) қолдау табады; Nginx-та басты беттегі тілдік бағдарлау қосымша баптауды қажет етуі мүмкін.

## Болашақ даму

- Ішкі беттер мен бет санаттарын қосу.
- Біртұтас кодты өзара жұмыс істейтін компоненттерге бөлу.
- Әкімші құқықтарын басқару және `supported_langs.php` ішіндегі әдепкі тілдерді көбейту.
- Модульдің `.tpl` файлдары мен WHMCS клиенттік тақырыптарына код редакторын жасау; әкімші тақырыбы кірмейді.
- ~~Модуль мен WHMCS тіл файлдарын басқаруды дамыту.~~
- Медиа менеджерді жақсарту.
- Yoast SEO үлгісінен шабыттанған, оңтайландырылған толық SEO менеджерін жасау.
- ~~Көптілді сайт картасы мен HTML карта бетін қосу.~~
- HTML сайт картасы бетін қосу.
- Беттер менеджеріне пайдалану статистикасын қосу.
- JS, CSS, HTML ықшамдау, толық бет кэші, модуль мен WHMCS кестелерін оңтайландыру менеджерін жасау.
- Модульді толық жаңарту жүйесін қосу.
