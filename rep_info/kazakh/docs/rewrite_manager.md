# Қайта жазу ережелері

## WHMCS

/ru/, /en/ және басқа префикстердегі беттерді қоса, тілдік URL мекенжайларына арналған ережелер. Тілдер supported_langs.php файлынан алынады; ережелер .htaccess файлына WHMCS ережелерінен бұрын енгізіледі.

Nginx .htaccess файлын оқымайды, сондықтан бұл ережелер онда жұмыс істемейді. Баламалы ережелерді nginx ішінде баптаңыз.

nginx → Apache конфигурациясы анықталды. Бұл ережелер тек Apache серверіне жіберілетін сұраулар үшін жұмыс істейді; nginx .htaccess файлын оқымайды.

Ережені қосқаннан немесе жойғаннан кейін өзгерістерді .htaccess файлына қолдану үшін «Ережелерді қосу немесе жаңарту» түймесін басыңыз.

## .htaccess

Менеджерді ашып, ережелерді сайттың негізгі `.htaccess` файлымен салыстырыңыз. Жеке ереже үшін URL үлгісін, мақсатты және жалаушаларды сақтаңыз; кейін **Ережелерді қосу немесе жаңарту** арқылы блокты WHMCS ережелерінен бұрын жазыңыз. Күйді қайта тексеріп, жарияланған бетті әдепкі және тағы бір тілде ашыңыз. Тым кең үлгі басқа беттерге әсер етуі мүмкін. Nginx → Apache байланысында ережелер тек Apache-ке берілген сұрауларға қолданылады.
