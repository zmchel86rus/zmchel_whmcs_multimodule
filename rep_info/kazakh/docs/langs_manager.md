# Тілдер менеджері

- **Бөлімдер → Тілдер → Аудармалар.** Әрбір «Сақтау» түймесі бір аударманы жаңартады.

## Бөлім мен тілді таңдау

Алдымен модуль параметрлерінде қажетті тілдерді қосыңыз. **Бөлімдер** бөлімінде WHMCS клиент немесе әкімші тілдерін, осы модульді не басқа модульді таңдаңыз. **Тілдер** бөлімінде бар файлды таңдаңыз немесе жаңа тіл қосыңыз. Жаңа файл өз аудармаларын енгізгенше анықтамалық тілдің мәтіндерін көрсетеді.

## Аудармаларды өңдеу

**Аудармалар** бөліміндегі **Түпнұсқа** бағаны таңдалған тілдің бастапқы файлындағы мәтінді көрсетеді; ол болмаса **Анықтама** көрсетіледі. Кілт не мәтін бойынша іздеп, сүзгілерді қолданыңыз және әр жолды бөлек сақтаңыз. Қосылған кілттерді қайта атауға немесе жоюға болады.

## JSON экспорттау және импорттау

Жаппай өңдеуден бұрын таңдалған тілдің кілттері мен аудармаларын экспорттаңыз. Импорт тек бар кілттерді жаңартады; белгісіз және қайталанған кілттер өткізіліп, нәтижеде тізіледі. Бөлім мен тіл идентификаторларын және кілт жолдарын сақтаңыз. Файл шегі — 8 MiB.

## Тіл файлдары және әдепкі тіл

Өшірілген тіл файлын да өңдеуге болады. Негізгі ағылшын файлы және WHMCS жүйесінің ағымдағы әдепкі тілі қорғалған. Әдепкі тілді өзгерту үшін жаңасын алдымен модульде қосып, кейін WHMCS жүйесінде ауыстырыңыз; содан соң ғана ескісін өшіріңіз. Ескі файл атауларын **Бөлімдер** бөлімінде түзетуге болады.
