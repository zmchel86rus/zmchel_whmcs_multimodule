# Модуль параметрлері

## WHMCS

Модуль пайдалана алатын тілдерді таңдаңыз. Тілді өшіру оның мазмұнын жоймайды. Apache серверінде ықшам URL мекенжайларын пайдалансаңыз, тілдерді өзгерткеннен кейін Қайта жазу менеджеріндегі ережелерді жаңартыңыз.

- [дерек көшіру](module_settings_transfer.md)

## Нұсқаулықтар

- **Ықшам URL мекенжайлары** — Жүйелік URL мекенжайларын қоса, ықшам URL мекенжайларын қосу.
- **Тілдік бағыттау** — Тілдік маршруттарды қосу немесе өшіру. Қосылғанда беттер /de/, /en/, /es/ және басқа қолдау көрсетілетін тіл префикстері арқылы қолжетімді болады. Өшірілгенде бір URL мекенжайы пайдаланушы таңдаған тілдегі мазмұнды көрсетеді.
- **Әдепкі тіл маршруты** — Әдепкі тілге жеке URL префиксін беріп, префикссіз модуль беттерін соған қайта бағыттау.
- **Техникалық қызмет көрсету режимі (модуль)** — Модульдің техникалық қызмет көрсету режимін қосу немесе өшіру. Жүйелік қызмет көрсету режимінен айырмашылығы, бұл жеңілдетілген режим WHMCS хуктары мен басқа компоненттердің жұмысын жалғастыруға мүмкіндік береді.
- **Smarty айнымалыларын жинау** — Smarty айнымалыларын жинауды қосу немесе өшіру.
- **Жиналған Smarty айнымалыларын пайдалану** — Бет редакторында жиналған Smarty айнымалыларын пайдалануды қосу немесе өшіру.
- **Бет алмастырулары** — Бет алмастыруларын қосу немесе өшіру.
- **Жаңарту жиілігі** — Ештеңе таңдалмаса, сайт картасы күн сайын жаңартылады.
- **HTML сайт картасы** — Қосылғанда /html-sitemap мекенжайында сайт картасы кәдімгі HTML беті ретінде көрсетіледі; sitemap.xml өзгермейді.
- **Сайттың жоғарғы бөлігі** — <head> бөліміндегі пайдаланушы HTML коды, соның ішінде <script> және <style>.
- **Сайттың төменгі бөлігі** — </body> тегінің алдындағы пайдаланушы HTML коды, соның ішінде <script> және <style>.
