# Модуль параметрлері

Алдымен қажетті тілдерді қосыңыз, содан кейін URL пішімін және тілдік бағыттарды таңдап, параметрлерді сақтаңыз. Бағыттар өзгерсе, Rewrite Manager арқылы Apache ережелерін немесе сәйкес Nginx баптауын жаңартыңыз. Модуль бетін әдепкі тілде және тағы бір белсенді тілде тексеріңіз. Ірі өзгеріс не импорт алдында сақтық көшірмені экспорттаңыз.

## WHMCS

Модуль пайдалана алатын тілдерді таңдаңыз. Тілді өшіру оның мазмұнын жоймайды. Apache серверінде ықшам URL мекенжайларын пайдалансаңыз, тілдерді өзгерткеннен кейін Қайта жазу менеджеріндегі ережелерді жаңартыңыз.
