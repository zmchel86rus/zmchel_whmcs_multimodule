# Медиаменеджер

## Файлды жүктеу және таңдау

**Медиафайлды жүктеу** батырмасын басып, сурет, аудио, бейне немесе PDF таңдаңыз; қажет болса атауын, балама мәтінін, тақырыбын және сипаттамасын толтырыңыз. Суреттерге мағыналы балама мәтін жазыңыз. Жүктегеннен кейін іздеу мен файл түрі сүзгісін пайдаланыңыз; **Тағы жүктеу** қосымша нәтижелерді көрсетеді. Сурет блогында кітапханадан файлды таңдап, бетті сақтаңыз.

## Суреттерді көрсету

Менеджер суреттің бірнеше өлшемін жасайды. Жүктелген суретке **Суретті оңтайландыру** әрекетін қолданып, нәтижесінің сапасын тексеріңіз, әсіресе ішінде мәтін болса. Бейімделген нұсқалар жарамаса, тиісті блоктағы `srcset` параметрін өшіріңіз. Ашық беттегі соңғы URL мен балама мәтінді тексеріңіз.
