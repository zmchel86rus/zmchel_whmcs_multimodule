# Сайт картасы

Автоматты жасау жаңарту уақыты келгенде WHMCS cron тапсырмасынан кейін орындалады. Қолмен жасау бірден басталады.

Қонақтарға қолжетімді белсенді беттер мен жазбалар, соның ішінде олардың жарияланған тілдік нұсқалары қосылады. Алмастырулар өздері алмастыратын беттердің жария URL мекенжайларын пайдаланады.


## XML

XML белсенді тілдерге өзара сілтемелерді және әдепкі тіл мекенжайына `x-default` белгісін қосады. Қайта бағыттау көздері `loc` пен тіл баламаларына кірмейді; резерв аударма мазмұнның нақты тілімен белгіленеді. Беттер мен жазбалардың файлдары XHTML атаулар кеңістігін жариялайды.

`AfterCronJob` hook-ы `ZM_PB_SITEMAP_UPDFREQ` аралығын соңғы сәтті жасау уақыты `ZM_PB_SITEMAP_LASTUPD` мәнімен салыстырады; карта сөнсе, қолмен жасау да қолжетімсіз. Тіл нұсқалары `lang_active` бойынша таңдалады. Қосымша бөліктер `_2`, `_3` және келесі жұрнақтарды алады. Қате болса, бұрынғы файлдар қалпына келеді, сәтті уақыт өзгермейді. Сайт түбіріне, `resources/` және `inc/editable_consts.php` файлына жазу құқығын тексеріңіз; кестелер модуль дерекқорында бөлек жөнделеді.

Автоматты жасау WHMCS cron тапсырмасына және бапталған аралыққа тәуелді; түйме оны бірден бастайды. Тек қонақтарға ашық жарияланған беттер мен жазбалар және олардың белсенді аудармалары енгізіледі. Бет жүйелік бетті алмастырса, алмастырушының slug-ы емес, жүйелік беттің ашық URL-і пайдаланылады. 50 000 URL не 50 МБ шегінен асқан файлдар бөліктерге бөлінеді. Индекс басқа жарамды сайт карталарын сақтайды.

Модуль сайт түбіріне `sitemap_index.xml`, `sitemap_pages.xml` және `sitemap_posts.xml` файлдарын жазады; бос санатқа файл жасалмайды. Біріккен `sitemap.xml` құрылмайды. Беттер немесе тілдер өзгергеннен кейін карталарды қайта жасап, индексті браузерде ашыңыз. Қате болса, сайт түбіріне жазу құқығын тексеріңіз; соңғы сәтті жасау уақыты өзгермейді.
