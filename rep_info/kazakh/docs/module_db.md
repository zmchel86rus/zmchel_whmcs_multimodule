# Модуль дерекқоры

## WHMCS

- **Модуль дерекқоры:** `MISSING` → Таңдау → Түзету Таңдалған элементтер.
- **Жою Таңдалған элементтер** — Бұл әрекетті болдырмау мүмкін емес.

**Модуль дерекқоры** беті қажетті кестелер мен бағандарды және олардың күйін көрсетеді. Оған тек тағайындалған суперадминистратор кіре алады. Басқа бөлімде кесте не баған жоқ деген хабар шықса, осы бетті ашыңыз. Тізімді қарап, тек жөнделуі тиіс элементтерді таңдап, **Таңдалғанды түзету** батырмасын басыңыз. Кейбір бағандар автоматты түрде түзелмейді; әрекеттен кейін күйін қайта тексеріңіз.

**Таңдалғанды жою** дерекқордың таңдалған нысандарын қайтарымсыз өшіреді. Жою алдында модуль деректерін экспорттап, дерекқордың сақтық көшірмесін жасаңыз.

## Нұсқаулықтар

- Қолжетімділікке тыйым салынды. Модульдің Дерекқор бетін тек Бас әкімші (ID …) пайдалана алады.
- Түзету
- Таңдалған элементтер
- Жою
- Бұл әрекетті болдырмау мүмкін емес.
- Мәзір кестелері әлі жасалмаған. Оларды Модуль дерекқоры бөлімінде қосыңыз.
- Алдымен модуль кестелерінің менеджерінде optimization_attempted бағанын қосыңыз.
