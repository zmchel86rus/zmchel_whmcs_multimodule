# Қайта бағыттау

Нақты мекенжайлар: бастапқы → мақсатты. Бастапқы мекенжай — сайт түбірінен басталатын жол немесе осы сайттың URL мекенжайы. Мақсатты мекенжай — жол немесе толық HTTP(S) URL мекенжайы. Сұрау параметрлері жоқ ереже олар бар сұрауларға да сәйкес келеді; мақсатты мекенжай енгізілген күйінде пайдаланылады. Ережелер WHMCS жүйесіне жететін GET/HEAD сұрауларына қолданылады.

Әдепкі мән: 14 күн. Жарияланған беттің немесе оның белсенді аудармаларының соңғы өзгерісінен бастап, ал өзгеріс болмаса, жасалған күнінен бастап есептеледі. Кідірісті алып тастау үшін 0 мәнін орнатыңыз. Автоматты ережелер HTTP 301 кодын пайдаланады.

Алмастыру беттерінің мекенжайлары автоматты түрде олар алмастыратын жүйелік беттерге қайта бағытталады. Алмастыру үшін бірнеше мақсатты мекенжай болса, бірінші бапталғаны пайдаланылады. Бұл қайта бағыттаулар Қайта бағыттау менеджерінің ережелеріне тәуелсіз, алмастырулар қосулы болғанда жұмыс істейді.

/ таңбасынан басталатын жарамды жолды немесе толық HTTP(S) URL мекенжайын енгізіңіз. Бастапқы мекенжай осы сайтқа тиесілі болуы керек; # фрагменттеріне қолдау көрсетілмейді.

## HTTP

Ережелер HTTP `301`, `302`, `303`, `307`, `308` кодтарын қолдайды және WHMCS-ке жететін `GET`/`HEAD` сұрауларына ғана қолданылады. Бастапқы мекенжай жол және көрсетілсе сұрау параметрлері бойынша дәл сәйкестенеді; мақсат параметрлері ескілерін ауыстырады. Менеджер ережелерді `zm_pb_redirects` кестесінде сақтайды, бірақ сұрау кезінде кесте жасамайды: **Модуль дерекқоры** бөлімін қолданыңыз. Қолданыстағы URL бағандары 128 байтпен шектелген.

Қолмен жасалған ережелер автоматты ережелерден басым. Жарияланған беттің slug-ы өзгерсе, белгіленген кідірістен кейін әр белсенді тілге автоматты `301` жасалуы мүмкін; нобайды жариялау мұны жасамайды. Кейінгі қайта атаулар ескі ережелердің мақсаттарын жаңартады. Сұрау параметрлері бар ереже тек жолға қатысты ережеден басым. Бастапқы URL осы сайтқа тиесілі болуы және `#` фрагментін қамтымауы керек.
