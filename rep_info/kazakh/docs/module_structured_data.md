# Құрылымдалған деректер

- **Бет редакторы → Метадеректер параметрлері → Schema түрі → Сақтау.**

## Модуль нені белгілейді

Мәзірлер мен мазмұн кестесі `SiteNavigationElement`, көрінетін сұрақтар мен жауаптар `FAQPage`, ал бірнеше элементтен тұратын навигация жолы `BreadcrumbList` деректерін жасай алады. Орналасу блоктары, батырмалар мен сүзгілерге мазмұн түрі автоматты берілмейді. Бетке таңдалған Schema түрі оның JSON-LD шығысын басқарады; өшірілсе, белгілеу шығарылмайды.

## Жариялаудан кейін тексеру

Ашық беттегі JSON-LD, канондық URL, тіл және шынымен көрінетін мазмұнды тексеріңіз. Дұрыс белгілеу іздеуде бай нәтижеге кепіл емес.

## Schema.org

`SiteNavigationElement` тек шынымен көрінетін мәзір сілтемелері мен атауларын пайдаланады; мазмұн тізімі бетте бар тақырыптарға `WebPageElement` қоса алады. `FAQPage` келуші көретін толық сұрақ-жауаптарды ғана қамтиды: жасырын блоктар мен жай аккордеондар кірмейді. `BreadcrumbList` кемінде екі тармақ болғанда ғана жасалады. Ұйым деректері WHMCS-тен алынады; байланыс тілдері `ContactPoint.availableLanguage` өрісінде BCP 47 пішімінде беріледі. Сүзгі, беттеу, пішін және жеке HTML үшін Schema түрі болжанбайды.

## Нұсқаулықтар

- **Schema түрі** — Өшірілгенде бұл бет үшін Schema.org JSON белгілеуі шығарылмайды.
- **Навигациялық тізбек** — Навигациялық тізбектегі бет атауы
- **Канондық URL мекенжайы**
- **Бет тақырыбы**
- **Мета сипаттама**
- **Open Graph тақырыбы** — Бос болса, бет тақырыбы пайдаланылады.
- **Open Graph сипаттамасы** — Бос болса, мета сипаттама пайдаланылады.
- **Open Graph суреті** — Бос болса, бет суреті пайдаланылады.
