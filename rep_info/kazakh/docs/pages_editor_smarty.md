# Smarty

- **Модуль параметрлері → Smarty айнымалыларын жинау → Жиналған Smarty айнымалыларын пайдалану → Бет редакторы.**

## Айнымалылар каталогы

Модуль параметрлерінде Smarty айнымалыларын жинау мен қолдануды қосыңыз, содан кейін сайттың тиісті беттерін ашып, редакторды жаңартыңыз. Каталог айнымалылардың атауын, түрін және құрылымын сақтайды, ал нақты мәндер мен жеке деректерді сақтамайды. Айнымалы жоқ болса, ол қолданылатын бетті қайта ашыңыз.

## Редактор және шектеулер

Бет редакторында Smarty блогын ашып, каталогтан айнымалыларды таңдаңыз. Рұқсат етілген шарттар мен циклдерді қолданыңыз; динамикалық мәтінді шығарғанда `|escape` қосыңыз. PHP, SQL, әдіс шақырулары, файлдарды қосу және `nofilter` рұқсат етілмейді. Бетті сақтап, ашық нәтижені тексеріңіз.

## resources/available_vars/

Каталог тек бетте байқалған айнымалыларды көрсетеді: оларды басқа бетте қолжетімді етпейді. Код сақтау кезінде және көрсетілу алдында тексеріледі; блок рұқсат етілген мәндердің оқшау көшірмесін алады. Шарттар, `foreach`, жергілікті `assign`, сондай-ақ `escape`, `default`, `count`, `date_format` түрлендіргіштері қолданылады. Шығыс мәндері автоматты түрде escaped болады; қажетті HTML кодын шаблонға жазыңыз. Дерек жетіспесе немесе код қате болса, блок бос қалады, қате PHP журналына жазылады.

`resources/available_vars/` каталогы атауларды, түрлерді, құрылымды және жасанды мысалдарды сақтайды, нақты мәндерді сақтамайды. Ол айнымалының қайда байқалғанын көрсетеді, бірақ оны басқа бетте қолжетімді етпейді. Smarty блогын екі рет басып редакторды ашыңыз. `Ctrl+Space` айнымалыны іздейді, `Ctrl+S` кодты қолданады, `F11` толық экранды ашады. Код оқшау орындалады; дерек болмаса блок бос қалады, ескерту PHP журналына жазылады.

## foreach

```smarty
{foreach $your_list as $item}
    <span>{$item.title|escape}</span>
{/foreach}
```
