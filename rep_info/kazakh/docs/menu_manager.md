# Мәзірлер

Мәзір жасап, беттерді немесе жеке сілтемелерді қосыңыз да, элементтерді сүйреп реттеңіз. Ішкі мәзір үшін ата-аналық элементті таңдап, тілдер бойынша атауларды, қонақтар не клиенттерге көрінуін және құрылғыларды баптаңыз. Орналасуды бекітіңіз: әр орында бір ғана мәзір болады. Ішкі сілтемелер URL-і ағымдағы тілге сәйкес өзгеретінін таңдаңыз. Ашық мәзірді компьютер мен телефонда тексеріңіз.

Әр тармаққа тақырып, сипаттама, CSS кластары, `rel`, белгіше және жаңа қойындыда ашу параметрін орнатуға болады; жарияланған беттерді автоматты түрде қосуға да болады. Компьютер мен телефон үшін мәзір WHMCS навигациясын толықтыра ма, әлде алмастыра ма, бөлек таңдаңыз. Модуль бетінің сілтемесі ағымдағы slug, тіл және URL режимі бойынша қайта есептеледі; бос белгі аударылған тақырыпты немесе бет атауын алады. Бетті ашу клиент профилінің тілін өзгертпейді. Сервер қауіпті URL схемаларын және белгілердегі HTML-ді қабылдамайды.

## WHMCS

Модуль баптауларында қажет WHMCS мәзір орындарын қосыңыз. Әр орынға бір мәзір ғана тағайындалады, бірақ бір мәзір бірнеше орында қолданыла алады. Компьютер көрінісі ені 768 px және одан үлкен экрандарға, мобильді көрініс тар экрандарға арналған. Орын өшірілсе, WHMCS-тің әдепкі мәзірі өзгермейді.

| WHMCS | zmchel |
| --- | --- |
| ClientAreaPrimaryNavbar | ZM_PB_ENABLE_MAINNAV |
| ClientAreaSecondaryNavbar | ZM_PB_ENABLE_SECONDARYNAV |
| ClientAreaPrimarySidebar | ZM_PB_ENABLE_MAINSIDEBAR |
| ClientAreaSecondarySidebar | ZM_PB_ENABLE_SECONDARYSIDEBAR |

## URL

Модульдің тілдік маршруты жоқ WHMCS жүйелік жолдарында мәзір белгілері клиенттің сақталған тілін, ал модуль беттері URL тілін пайдаланады. Әдепкі тілдің жеке маршруты қосылса, оған да префикс беріледі. Қарапайым URL түрі: `?m=zmchel_whmcs_multimodule&slug=...&lang=...`. `clientarea.php` сияқты жеке сілтемені тілге бейімдемей қалдыруға болады. Ата-ана тармақ жасырылса, оның барлық ұрпағы жасырылып қалады.

Бет тармағының URL-і ағымдағы slug пен жарияланған аударма бойынша қайта есептеледі. Аударма болмаса, әдепкі тілдегі жарияланған нұсқа қолданылады. Жеке сілтеме енгізілген URL-ді өзгеріссіз сақтай алады; сыртқы мекенжайларға, mailto, tel және якорьлерге тіл префиксі қосылмайды. Нобай, жойылған және қолжетімсіз беттер көрсетілмейді.

## zm_pb_menus

Деректер `zm_pb_menus`, `zm_pb_menu_items` және `zm_pb_menu_locations` кестелерінде сақталады. Кестелерді Модуль дерекқоры бөлімінде жасаңыз немесе түзетіңіз. Ағашта ең көбі 10 деңгей және 300 тармақ болады; ата-аналық тармақ жойылса, оның ішкі тармақтары бір деңгей жоғары көтеріледі.

## Нұсқаулықтар

- Мәзір жасау
- Беттерді, жазбаларды немесе пайдаланушы сілтемелерін қосыңыз.
- Ретін өзгерту үшін элементтерді сүйреңіз. Кірістіру деңгейін негізгі элементті таңдау арқылы немесе жылжыту түймелерімен орнатыңыз.
- Ағымдағы беттің тілін пайдалану
- Енгізілген URL мекенжайын өзгеріссіз пайдалану
- Басқа тілдердегі атаулар
- Кімдерге көрінеді
- Құрылғылар
- Әр орналасу орнына бір ғана мәзір тағайындауға болады. Орналасу орнын таңдау оның басқа мәзірден тағайындалуын осында ауыстырады.
- Жоғарғы деңгейдегі элементтер бағандарға, ал ішкі элементтер сілтемелерге айналады. Сілтемесіз тақырып үшін URL # мәнін пайдаланыңыз.
- Мәзір кестелері әлі жасалмаған. Оларды Модуль дерекқоры бөлімінде қосыңыз.
