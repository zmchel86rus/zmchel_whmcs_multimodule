# Moduldatabas

## WHMCS

- **Moduldatabas:** `MISSING` → Välj → Åtgärda Valda objekt.
- **Ta bort Valda objekt** — Den här åtgärden kan inte ångras.

Sidan **Moduldatabas** visar de tabeller och kolumner som behövs samt deras status. Endast den utsedda superadministratören har åtkomst. Öppna sidan om ett annat avsnitt rapporterar en saknad tabell eller kolumn. Granska listan, markera bara det som ska repareras och klicka på **Reparera markerade**. Vissa kolumner kan inte repareras automatiskt; kontrollera statusen igen efteråt.

**Radera markerade** tar bort de valda databasobjekten permanent. Exportera moduldata och säkerhetskopiera databasen innan du raderar något.

## Instruktioner

- Åtkomst nekad. Endast huvudadministratören (ID …) kan använda modulens databassida.
- Åtgärda
- Valda objekt
- Ta bort
- Den här åtgärden kan inte ångras.
- Menytabellerna har inte skapats ännu. Lägg till dem i Moduldatabas.
- Lägg först till kolumnen optimization_attempted i modulens tabellhanterare.
