# Modulinställningar

Aktivera först de språk du behöver, välj sedan URL-format och språkrutter och spara inställningarna. Om rutterna ändras uppdaterar du Apache-reglerna i Rewrite Manager eller motsvarande Nginx-konfiguration. Kontrollera en modulsida på standardspråket och ett annat aktivt språk. Exportera en säkerhetskopia före större ändringar eller import.

## WHMCS

Välj vilka språk modulen kan använda. Att stänga av ett språk raderar inte innehållet. Om du använder snygga URL:er med Apache, uppdatera reglerna i Rewrite Manager när du ändrar språk.
