# Modul sozlamalari

Avval kerakli tillarni yoqing, so‘ng URL shakli va til marshrutlarini tanlab, sozlamalarni saqlang. Marshrutlar o‘zgargan bo‘lsa, Apache qoidalarini Rewrite Manager orqali yoki mos Nginx konfiguratsiyasini yangilang. Modul sahifasini standart tilda va yana bir faol tilda tekshiring. Katta o‘zgarishlar yoki importdan oldin zaxira nusxani eksport qiling.

## WHMCS

Modul foydalanishi mumkin boʻlgan tillarni tanlang. Tilni oʻchirish uning kontentini oʻchirmaydi. Agar Apache da chiroyli URL manzillaridan foydalansangiz, tillarni oʻzgartirgandan soʻng Qayta yozish qoidalari menejeridagi qoidalarni yangilang.
