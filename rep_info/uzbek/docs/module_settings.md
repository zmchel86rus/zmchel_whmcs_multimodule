# Modul sozlamalari

## WHMCS

Modul foydalanishi mumkin boʻlgan tillarni tanlang. Tilni oʻchirish uning kontentini oʻchirmaydi. Agar Apache da chiroyli URL manzillaridan foydalansangiz, tillarni oʻzgartirgandan soʻng Qayta yozish qoidalari menejeridagi qoidalarni yangilang.

- [ma’lumot ko‘chirish](module_settings_transfer.md)

## Yoʻriqnoma

- **Chiroyli URL manzillari** — Tizim URL manzillarini ham oʻz ichiga olgan chiroyli URL manzillarini yoqish.
- **Til boʻyicha marshrutlash** — Til marshrutlarini yoqish yoki oʻchirish. Yoqilganda sahifalar /de/, /en/, /es/ va boshqa qoʻllab-quvvatlanadigan til prefikslari orqali ochiladi. Oʻchirilganda bitta sahifa URL manzili foydalanuvchi tanlagan tildagi kontentni koʻrsatadi.
- **Standart til uchun marshrut** — Standart tilga alohida URL prefiksi belgilang va prefikssiz modul sahifalarini unga qayta yoʻnaltiring.
- **Texnik xizmat rejimi (modul)** — Modulning texnik xizmat rejimini yoqish yoki oʻchirish. Bu yumshoqroq rejimda, tizimning texnik xizmat rejimidan farqli ravishda, WHMCS hooklari va boshqa komponentlar ishlashda davom etadi.
- **Smarty oʻzgaruvchilarini yigʻish** — Smarty oʻzgaruvchilarini yigʻishni yoqish yoki oʻchirish.
- **Yigʻilgan Smarty oʻzgaruvchilaridan foydalanish** — Sahifa muharririda yigʻilgan Smarty oʻzgaruvchilaridan foydalanishni yoqish yoki oʻchirish.
- **Sahifalarni almashtirish** — Sahifalarni almashtirishni yoqish yoki oʻchirish.
- **Yangilanish davriyligi** — Hech narsa tanlanmasa, sayt xaritasi har kuni yangilanadi.
- **HTML sayt xaritasi** — Yoqilganda /html-sitemap sayt xaritasini oddiy HTML sahifa sifatida koʻrsatadi; sitemap.xml fayliga taʼsir qilmaydi.
- **Saytning yuqori qismi** — <head> boʻlimi uchun maxsus HTML, jumladan <script> va <style>.
- **Saytning pastki qismi** — </body> tegidan oldingi maxsus HTML, jumladan <script> va <style>.
- **robots.txt faylini tahrirlash**
