# Modul maʼlumotlar bazasi

## WHMCS

- **Modul maʼlumotlar bazasi:** `MISSING` → Tanlash → Tuzatish Tanlangan elementlar.
- **Oʻchirish Tanlangan elementlar** — Bu amalni ortga qaytarib boʻlmaydi.

**Modul ma’lumotlar bazasi** sahifasi kerakli jadvallar va ustunlarni hamda ularning holatini ko‘rsatadi. Undan faqat tayinlangan Superadministrator foydalana oladi. Boshqa bo‘lim jadval yoki ustun yo‘qligini bildirsa, shu sahifani oching. Ro‘yxatni tekshiring, faqat tuzatilishi kerak bo‘lganlarini tanlang va **Tanlanganlarni tuzatish** tugmasini bosing. Ayrim ustunlar avtomatik tuzatilmaydi; amaldan keyin holatni qayta tekshiring.

**Tanlanganlarni o‘chirish** tanlangan ma’lumotlar bazasi obyektlarini qaytarib bo‘lmaydigan tarzda o‘chiradi. O‘chirishdan oldin modul ma’lumotlarini eksport qilib, bazaning zaxira nusxasini yarating.
