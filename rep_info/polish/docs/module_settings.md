# Ustawienia modułu

Najpierw włącz potrzebne języki, a następnie wybierz format adresów URL i trasy językowe oraz zapisz ustawienia. Jeśli trasy się zmieniły, zaktualizuj reguły Apache w Rewrite Manager lub odpowiednią konfigurację Nginx. Sprawdź stronę modułu w języku domyślnym i jeszcze jednym aktywnym języku. Przed większymi zmianami lub importem wyeksportuj kopię zapasową.

- [Import i eksport](module_settings_transfer.md)

## 1. Instalacja i dostęp

Włącz dodatek w WHMCS i przyznaj dostęp uprawnionym administratorom. Sprawdź wymagane tabele w sekcji bazy danych modułu. Przejrzyj przyjazne adresy, trasy językowe i miejsca menu. Apache korzysta z .htaccess; w Nginx równoważne reguły trzeba skonfigurować osobno.
