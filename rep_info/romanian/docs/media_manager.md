# Manager media

## Încărcarea și selectarea fișierului

Apăsați **Încarcă fișier media**, alegeți o imagine, un fișier audio, un videoclip sau un PDF și completați numele, textul alternativ, titlul și descrierea, unde este cazul. Pentru imagini, scrieți un text alternativ relevant. După încărcare, folosiți căutarea și filtrul după tipul fișierului; **Încarcă mai multe** afișează alte rezultate. În blocul Imagine, selectați fișierul din bibliotecă și salvați pagina.

## Afișarea imaginilor

Managerul creează mai multe dimensiuni ale imaginii. Pentru o imagine încărcată puteți rula **Optimizează imaginea**; verificați apoi calitatea, mai ales dacă imaginea conține text. Dacă variantele adaptive nu sunt potrivite, dezactivați `srcset` în blocul respectiv. Verificați URL-ul final și textul alternativ pe pagina publică.

## Instrucțiuni

- Încarcă fișier media
- **Nume (intern)**
- **Titlu (dacă este cazul)**
- **Descriere (dacă este cazul)**
- **Atribut alt**
- Caută după nume
- Tip de fișier
- Încarcă mai multe
- Optimizează imaginea
- Optimizarea imaginii originale și a variantelor sale s-a încheiat.
- Selectează fișierul media
