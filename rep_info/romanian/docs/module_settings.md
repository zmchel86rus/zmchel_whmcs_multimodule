# Setările modulului

Activați mai întâi limbile necesare, apoi alegeți formatul URL și rutarea limbilor și salvați setările. Dacă rutele s-au schimbat, actualizați regulile Apache în Rewrite Manager sau configurația Nginx corespunzătoare. Verificați o pagină a modulului în limba implicită și într-o altă limbă activă. Exportați o copie de siguranță înainte de modificări majore sau de import.

- [Import și export](module_settings_transfer.md)

## 1. Instalare și acces

Activați modulul suplimentar în WHMCS și acordați acces administratorilor autorizați. În Baza de date a modulului verificați tabelele necesare. Revizuiți apoi URL-urile prietenoase, rutele lingvistice și pozițiile meniurilor. Apache folosește .htaccess; în Nginx configurați separat regulile echivalente.
