# Pengaturan modul

## WHMCS

Pilih bahasa yang dapat digunakan modul. Menonaktifkan bahasa tidak akan menghapus kontennya. Jika Anda menggunakan URL ramah pengguna di Apache, perbarui aturan di Pengelola Penulisan Ulang setelah mengubah bahasa.

- [transfer data](module_settings_transfer.md)

## Petunjuk

- **URL ramah pengguna** — Aktifkan URL ramah pengguna, termasuk URL sistem.
- **Perutean bahasa** — Aktifkan atau nonaktifkan rute bahasa. Jika diaktifkan, halaman tersedia di bawah /de/, /en/, /es/, dan awalan bahasa lain yang didukung. Jika dinonaktifkan, satu URL halaman menampilkan konten dalam bahasa yang dikonfigurasi pengguna.
- **Rute untuk bahasa bawaan** — Berikan awalan URL tersendiri untuk bahasa bawaan dan alihkan halaman modul tanpa awalan ke URL tersebut.
- **Mode pemeliharaan (modul)** — Aktifkan atau nonaktifkan mode pemeliharaan modul. Mode yang lebih ringan ini memungkinkan hook WHMCS dan komponen lainnya tetap berjalan, tidak seperti mode pemeliharaan sistem.
- **Kumpulkan variabel Smarty** — Aktifkan atau nonaktifkan pengumpulan variabel Smarty.
- **Gunakan variabel Smarty yang dikumpulkan** — Aktifkan atau nonaktifkan penggunaan variabel Smarty yang dikumpulkan di editor halaman.
- **Penggantian halaman** — Aktifkan atau nonaktifkan penggantian halaman.
- **Frekuensi pembaruan** — Jika tidak ada yang dipilih, peta situs diperbarui setiap hari.
- **Peta situs HTML** — Jika diaktifkan, /html-sitemap menampilkan peta situs sebagai halaman HTML biasa; sitemap.xml tidak terpengaruh.
- **Header situs** — HTML khusus untuk bagian <head>, termasuk <script> dan <style>.
- **Footer situs** — HTML khusus sebelum </body>, termasuk <script> dan <style>.
- **Edit robots.txt**
