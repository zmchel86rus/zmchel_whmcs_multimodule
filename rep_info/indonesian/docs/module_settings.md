# Pengaturan modul

Aktifkan bahasa yang diperlukan terlebih dahulu, lalu pilih format URL dan perutean bahasa serta simpan pengaturan. Jika rute berubah, perbarui aturan Apache di Rewrite Manager atau konfigurasi Nginx yang setara. Periksa halaman modul dalam bahasa bawaan dan satu bahasa aktif lainnya. Ekspor cadangan sebelum perubahan besar atau impor data.

## WHMCS

Pilih bahasa yang dapat digunakan modul. Menonaktifkan bahasa tidak akan menghapus kontennya. Jika Anda menggunakan URL ramah pengguna di Apache, perbarui aturan di Pengelola Penulisan Ulang setelah mengubah bahasa.
