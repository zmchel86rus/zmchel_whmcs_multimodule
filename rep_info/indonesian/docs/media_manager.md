# Pengelola Media

## Mengunggah dan memilih berkas

Klik **Unggah berkas media**, pilih gambar, audio, video, atau PDF, lalu isi nama, teks alt, judul, dan deskripsi jika diperlukan. Tulis teks alt yang menjelaskan isi gambar. Setelah diunggah, gunakan pencarian dan filter jenis berkas; **Muat lainnya** menampilkan hasil berikutnya. Pada blok Gambar, pilih berkas dari pustaka dan simpan halaman.

## Menampilkan gambar

Pengelola membuat beberapa ukuran gambar. Anda dapat menjalankan **Optimalkan gambar** pada gambar yang sudah diunggah; periksa hasilnya, terutama jika gambar memuat teks. Jika varian responsif tidak sesuai, nonaktifkan `srcset` pada blok tersebut. Periksa URL akhir dan teks alt di halaman publik.

## Petunjuk

- Unggah berkas media
- **Nama (internal)**
- **Judul (jika ada)**
- **Deskripsi (jika ada)**
- **Atribut alt**
- Cari berdasarkan nama
- Jenis berkas
- Muat lebih banyak
- Optimalkan gambar
- Pengoptimalan gambar asli dan semua variannya selesai.
- Pilih berkas media
