# Modulun verilənlər bazası

## WHMCS

- **Modulun verilənlər bazası:** `MISSING` → Seç → Düzəlt Seçilmiş elementlər.
- **Sil Seçilmiş elementlər** — Bu əməliyyatı geri qaytarmaq mümkün deyil.

**Modulun verilənlər bazası** səhifəsi tələb olunan cədvəl və sütunları, eləcə də onların vəziyyətini göstərir. Bu səhifəyə yalnız təyin edilmiş Superadministrator daxil ola bilər. Başqa bölmə cədvəlin və ya sütunun çatışmadığını bildirəndə onu açın. Siyahını yoxlayın, yalnız bərpa edilməli elementləri seçin və **Seçilənləri düzəlt** düyməsini basın. Bəzi sütunlar avtomatik bərpa edilmir; əməliyyatdan sonra vəziyyəti yenidən yoxlayın.

**Seçilənləri sil** verilənlər bazasının seçilmiş obyektlərini geri qaytarılmadan silir. Silməzdən əvvəl modul məlumatlarını ixrac edin və verilənlər bazasının ehtiyat nüsxəsini alın.
