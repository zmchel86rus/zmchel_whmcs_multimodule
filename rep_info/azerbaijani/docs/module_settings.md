# Modul parametrləri

## WHMCS

Modulun istifadə edə biləcəyi dilləri seçin. Dili deaktiv etmək onun məzmununu silmir. Apache-də qısa və oxunaqlı URL-lərdən istifadə edirsinizsə, dilləri dəyişdikdən sonra Yenidənyazma qaydaları menecerində qaydaları yeniləyin.

- [məlumat ötürülməsi](module_settings_transfer.md)

## Təlimatlar

- **Oxunaqlı URL-lər** — Sistem URL-ləri də daxil olmaqla oxunaqlı URL-ləri aktivləşdirir.
- **Dil üzrə marşrutlaşdırma** — Dil marşrutlarını aktivləşdirin və ya deaktiv edin. Aktiv olduqda səhifələr /de/, /en/, /es/ və digər dəstəklənən dil prefiksləri altında əlçatan olur. Deaktiv olduqda eyni səhifə URL-si istifadəçinin seçdiyi dildə məzmun göstərir.
- **Standart dil üçün marşrut** — Standart dil üçün ayrıca URL prefiksi yaradın və prefikssiz modul səhifələrini həmin ünvana yönləndirin.
- **Texniki xidmət rejimi (modul)** — Modulun texniki xidmət rejimini aktivləşdirin və ya deaktiv edin. Sistem texniki xidmət rejimindən fərqli olaraq bu daha yumşaq rejim WHMCS hook-larının və digər komponentlərin işləməsinə imkan verir.
- **Smarty dəyişənlərini topla** — Smarty dəyişənlərinin toplanmasını aktivləşdirin və ya deaktiv edin.
- **Toplanmış Smarty dəyişənlərindən istifadə et** — Səhifə redaktorunda toplanmış Smarty dəyişənlərindən istifadəni aktivləşdirin və ya deaktiv edin.
- **Səhifə əvəzləmələri** — Səhifə əvəzləmələrini aktivləşdirin və ya deaktiv edin.
- **Yenilənmə tezliyi** — Heç nə seçilmədikdə sayt xəritəsi hər gün yenilənir.
- **HTML sayt xəritəsi** — Aktiv olduqda /html-sitemap sayt xəritəsini adi HTML səhifəsi kimi göstərir; sitemap.xml faylına təsir etmir.
- **Sayt başlığı** — <head> bölməsi üçün xüsusi HTML, o cümlədən <script> və <style>.
- **Saytın aşağı hissəsi** — </body> etiketindən əvvəlki xüsusi HTML, o cümlədən <script> və <style>.
- **robots.txt faylını redaktə et**
