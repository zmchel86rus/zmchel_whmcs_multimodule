# Modul parametrləri

Əvvəlcə lazım olan dilləri aktivləşdirin, sonra URL formatını və dil marşrutlaşdırmasını seçib parametrləri yadda saxlayın. Marşrutlar dəyişibsə, Apache üçün Rewrite Manager qaydalarını və ya Nginx konfiqurasiyasını yeniləyin. Modul səhifəsini həm standart dildə, həm də başqa aktiv dildə yoxlayın. Böyük dəyişiklikdən və ya idxaldan əvvəl ehtiyat nüsxəni ixrac edin.

## WHMCS

Modulun istifadə edə biləcəyi dilləri seçin. Dili deaktiv etmək onun məzmununu silmir. Apache-də qısa və oxunaqlı URL-lərdən istifadə edirsinizsə, dilləri dəyişdikdən sonra Yenidənyazma qaydaları menecerində qaydaları yeniləyin.
