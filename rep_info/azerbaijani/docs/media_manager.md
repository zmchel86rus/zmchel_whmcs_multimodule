# Media meneceri

## Faylın yüklənməsi və seçilməsi

**Media faylını yüklə** düyməsini basın, şəkil, audio, video və ya PDF seçin; uyğun olduqda ad, alt mətn, başlıq və təsviri doldurun. Şəkillər üçün məzmunu izah edən alt mətn yazın. Sonra axtarışdan və fayl növü filtrindən istifadə edin; **Daha çox yüklə** əlavə nəticələri göstərir. Şəkil blokunda kitabxanadan faylı seçib səhifəni yadda saxlayın.

## Şəkillərin göstərilməsi

Menecer şəklin bir neçə ölçüsünü yaradır. Yüklənmiş şəkil üçün **Şəkli optimallaşdır** əməliyyatını başladın və xüsusilə üzərində mətn olan şəkillərdə nəticənin keyfiyyətini yoxlayın. Adaptiv variantlar uyğun gəlmirsə, həmin blokda `srcset` parametrini söndürün. Açıq səhifədə son URL-i və alt mətni yoxlayın.

## Təlimatlar

- Media faylı yüklə
- **Ad (daxili)**
- **Başlıq (tətbiq olunduqda)**
- **Təsvir (tətbiq olunduqda)**
- **Alt atributu**
- Ada görə axtar
- Fayl növü
- Daha çox yüklə
- Şəkli optimallaşdır
- Orijinal şəklin və onun variantlarının optimallaşdırılması tamamlandı.
- Media faylını seç
