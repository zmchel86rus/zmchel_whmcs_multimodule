# Page Manager

Ipinapakita ng Page Manager ang mga pahinang ginawa ng module. Dito ka gagawa ng bago, maghahanap ng dati nang pahina, magbabago ng status, bibisita sa pampublikong URL, o mag-uugnay ng nilalaman sa isang kasalukuyang pahina ng WHMCS. Hiwalay na binabago ang teksto at metadata sa [Page Editor](pages_editor.md).

## Gumawa ng pahina

Buksan ang **Add page**. Maglagay ng panloob na pangalan at slug gaya ng about-us, nang walang domain o unahang code ng wika. Pumili kung pahina, artikulo, o sistemang pahina ito. Itakda ang access para sa lahat, naka-login na gumagamit lamang, o bisita lamang. Piliin ang mga wika; kailangang aktibo sa Module settings ang default na wika ng WHMCS. I-save at saka idagdag ang nilalaman at metadata sa editor. Hindi pa nakikita ng publiko ang draft; i-publish lamang kapag handa na.

## Hanapin, bisitahin, at alisin

Maaaring salain ang listahan ayon sa pangalan, access, uri, status, at wika. Binubuksan ng **Visit** ang tunay na pampublikong URL. Ililipat muna ng **Delete** ang pahina sa Trash, at doon lamang ito permanenteng mabubura. Kung hindi makita ang URL, suriin muna kung published ang pahina at aktibo ang salin bago ipagpalagay na may problema sa routing.

## Palitan ang pahina ng WHMCS

Sa page override, pumili ng kasalukuyang pahina ng WHMCS at isang published na builder page. Maaaring palitan ng napiling mode ang orihinal na nilalaman, ilagay ang bago bago o pagkatapos nito, baguhin lamang ang metadata, o pagsamahin ang mga epekto. I-save at subukan ang orihinal na WHMCS URL bilang bisita at naka-login na customer. Maaaring mag-redirect ang hiwalay na builder slug papunta sa orihinal na URL.
