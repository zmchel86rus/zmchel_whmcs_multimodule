# Media Manager

Iniimbak ng media library ang mga file na ginagamit ng mga block ng pahina at ibang nilalaman ng module. Dito makakapag-upload ka ng bagong file, makakahanap ng dating item, at makakapag-optimize ng larawan nang hindi mano-manong binabago ang mga file ng WHMCS theme.

## Mag-upload at pumili

Pindutin ang **Upload** at pumili ng larawan, audio, video, o PDF. Kumpletuhin ang sistemang pangalan, pamagat, paglalarawan, at alt text kung available. Para sa larawan, ilarawan sa alt ang mahalagang nakikita, hindi lamang ulitin ang filename. Gamitin ang search at filter ng uri upang mahanap ang item; ang **Load more** ay kukuha ng karagdagang resulta. Sa Image block, pindutin ang **Choose image**, pumili sa library, at i-save ang pahina. Tingnan din ang aktuwal na URL sa pampublikong pahina.

## Paglabas ng larawan

Gumagawa ang manager ng ilang sukat para sa mga larawan. Maaari mong patakbuhin ang **Optimize image** at tingnan ang resulta, lalo na kung may teksto o pinong linya ang larawan. Kung ayaw mo ng responsive variants para sa isang item, patayin ang srcset sa Image block nito. Tiyaking tama ang huling URL, sukat, at alt text sa nalathalang pahina.
